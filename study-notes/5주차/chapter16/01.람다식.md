# 01-람다식

---

## 1. 람다식이란?

**하나의 추상 메소드를 가진 함수형 인터페이스의 구현을 간결하게 표현하는 문법.**
JS 화살표 함수(`=>`)와 같은 개념, Java는 `->` 사용.

```java
(a, b) -> a + b
// 입력      실행할 내용
```

---

## 2. 함수형 인터페이스

**추상 메소드가 딱 1개인 인터페이스.** 람다가 담기는 그릇(타입) 역할.

```java
@FunctionalInterface   // 추상 메소드 1개인지 검사 (2개면 컴파일 에러)
public interface Calculator {
    int operate(int a, int b);   // 추상 메소드: 이름·입력·출력 자리만 정함
}
```

| 구성 | 역할 |
|---|---|
| 인터페이스 | 추상 메소드를 담는 틀 |
| 추상 메소드 | 이름·입력·출력 **자리** (몸체 없음) |
| 람다 | 그 자리에 들어갈 **실제 식** |

> 추상 메소드가 여러 개면 람다 사용 불가 → 클래스 implements로 전부 구현
> (람다는 이름 없이 내용만 적어서 어느 메소드 자리인지 구분 못 함)

---

## 3. 익명 클래스 vs 람다식

```java
// 익명 클래스: 이름 없는 클래스로 인터페이스를 바로 구현
Calculator anonymousAdd = new Calculator() {
    @Override
    public int operate(int a, int b) {
        return a + b;
    }
};

// 람다식: 같은 내용을 한 줄로
Calculator lambdaAdd = (int a, int b) -> a + b;
Calculator lambdaAdd2 = (a, b) -> a + b;   // 타입 생략 가능
```

### 람다 문법 모양

```java
() -> "GUEST"                    // 입력 없음
value -> value.length()          // 입력 1개 (괄호 생략 가능)
(a, b) -> a + b                  // 입력 2개, 한 줄이면 자동 return
(a, b) -> {                      // 여러 줄이면 { } + return 필수
    int sum = a + b;
    return sum;
}
```

> 매개변수 타입은 전부 적거나 전부 생략 (섞으면 컴파일 에러)

## 4. 람다를 매개변수로 전달

같은 메소드에 **람다(동작)만 바꿔 넣으면** 다른 결과.

```java
public static int calculate(int first, int second, Calculator calculator) {
    return calculator.operate(first, second);
}

calculate(10, 19, (a, b) -> a + b);   // 29
calculate(10, 19, (a, b) -> a - b);   // -9
calculate(10, 19, (a, b) -> a * b);   // 190
```

> 람다 = 레시피(동작), 값(10, 19) = 재료
> 값은 람다를 만들 때가 아니라 **호출할 때** 들어감
> 비유: 계산기 본체(calculate)에 연산 버튼(람다)만 갈아 끼우기

---

## 5. 람다와 지역변수 (effectively final)

```java
int bonus = 5;
Calculator bonusCalculator = (a, b) -> a + b + bonus;   // 지역변수 읽기 OK
// bonus = 10;   // ❌ 람다가 참조하는 지역변수는 다시 대입 불가
```

- 람다는 선언된 자리에서 지역변수 값을 가져가 **나중에** 실행될 수 있음
- 그 사이 값이 바뀌면 어떤 값을 써야 할지 혼란 → Java가 막음
- 한 번 정해지고 안 바뀌는 변수 = **사실상 final(effectively final)**

## 전체 흐름 정리

    함수형 인터페이스
    └─ 추상 메소드 1개짜리 인터페이스 (@FunctionalInterface로 검사)

    람다식
    └─ 함수형 인터페이스 구현을 한 줄로
    └─ 한 줄이면 자동 return, 여러 줄이면 { } + return
    └─ 매개변수로 넘겨서 동작을 갈아 끼울 수 있음

    자주 헷갈리는 것
    └─ 함수형 인터페이스 = 특별한 문법 X, 그냥 추상 메소드 1개인 인터페이스
    └─ 람다는 여러 개 만들 수 있음 (자리 1개를 각각 다르게 채운 것)
    └─ 람다 안에서 쓰는 지역변수는 바꾸면 안 됨
