# 02-문자스트림

---

## 1. FileReader — 문자 단위로 읽기

바이트 단위인 FileInputStream과 달리 한글처럼 여러 바이트로 된 문자도 깨지지 않고 읽을 수 있다.

```java
try (FileReader fr = new FileReader("chap14-Io/src/com/ohgiraffers/section02/testReader.txt")) {
    int value;
    while ((value = fr.read()) != -1) {   // 한 글자씩, 끝이면 -1
        System.out.println((char) value);
    }
} catch (FileNotFoundException e) {
    e.printStackTrace();
} catch (IOException e) {
    e.printStackTrace();
}
```

---

## 2. FileWriter — 문자 단위로 쓰기

```java
try (FileWriter fw = new FileWriter("chap14-Io/src/com/ohgiraffers/section02/testWriter.txt")) {
    fw.write("안녕하세요\n");                       // 문자열 바로 쓰기 (getBytes 불필요)
    fw.write(new char[]{'a', 'p', 'p', 'l', 'e'}); // char 배열
} catch (IOException e) {
    e.printStackTrace();
}
```

> FileWriter의 write()도 오버로딩: String, char[], int(문자 하나)
> 이어쓰기: `new FileWriter(path, true)`

### 주의: 기본 문자셋

FileReader / FileWriter는 **실행 환경의 기본 문자셋**을 사용
→ 컴퓨터마다 기본 문자셋이 다르면 한글이 깨질 수 있음

## 3. 형변환 보조스트림 — 문자셋 직접 지정

바이트 스트림을 문자 스트림으로 **연결(변환)**해주는 어댑터.
혼자 사용 불가, 반드시 바이트 스트림을 감싸서 사용.

### InputStreamReader (바이트 → 문자, 읽기)

```java
try (Reader reader = new InputStreamReader(
        new FileInputStream("chap14-Io/src/com/ohgiraffers/section02/testReader.txt"),
        StandardCharsets.UTF_8)) {      // 바이트를 해석할 문자 규칙

    int value;
    while ((value = reader.read()) != -1) {
        System.out.println((char) value);
    }
} catch (IOException e) {
    e.printStackTrace();
}
```

### OutputStreamWriter (문자 → 바이트, 쓰기)

```java
try (Writer writer = new OutputStreamWriter(
        new FileOutputStream("chap14-Io/src/com/ohgiraffers/section02/test.txt"),  // 실제 바이트 통로
        StandardCharsets.UTF_8)) {                                                // 변환 규칙
    writer.write("안녕하세요");
} catch (IOException e) {
    e.printStackTrace();
}
```

> `Writer writer = new OutputStreamWriter(...)` → 업캐스팅 (부모 Writer 타입으로 참조)
> 비유: 돼지코 어댑터. 문자(충전기)를 바이트 스트림(외국 콘센트)에 꽂을 수 있게 변환

---

## 4. 스트림 4종 정리

| | 읽기 | 쓰기 |
|---|---|---|
| **바이트** | FileInputStream | FileOutputStream |
| **문자** | FileReader | FileWriter |
| **바이트↔문자 변환** | InputStreamReader | OutputStreamWriter |

---

## 전체 흐름 정리

    FileReader / FileWriter
    └─ 문자 단위, 한글 OK
    └─ Writer는 문자열 바로 write 가능
    └─ 기본 문자셋 사용 → 환경 따라 깨질 수 있음

    InputStreamReader / OutputStreamWriter
    └─ 바이트 스트림을 감싸서 문자로 변환
    └─ StandardCharsets.UTF_8 처럼 문자셋 직접 지정
    └─ 혼자 못 씀 (안에 바이트 스트림 필요)

    자주 헷갈리는 것
    └─ ~Stream = 바이트, ~Reader/~Writer = 문자
    └─ 텍스트 파일은 문자 스트림, 그 외 파일은 바이트 스트림
    └─ 어디서 실행해도 안전하게 하려면 UTF-8 직접 지정
