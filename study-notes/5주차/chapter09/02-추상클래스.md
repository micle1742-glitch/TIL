# 02-추상클래스

---

## 1. 추상 클래스란?

직접 객체를 생성할 수 없으며, 자식 클래스의 공통 기능을 정의하는 부모 클래스.
공통 속성과 기능을 물려주는 **미완성 부모 클래스**.

```java
public abstract class Player { }  // abstract 키워드로 선언

// new Player(); // 에러 — 직접 객체 생성 불가
Player p = new Warrior(); // 참조변수 타입으로는 사용 가능 (다형성)
```

---

## 2. 추상 메소드

몸체가 없는 메소드. 자식 클래스에서 반드시 오버라이딩해야 함.

```java
public abstract class Player {
    public abstract void attack(); // 몸체 없음, 자식이 반드시 구현

    public void defend() {         // 일반 메소드 — 그대로 물려줌
        System.out.println("공격을 방어합니다.");
    }
}
```

> 추상 클래스는 일반 메소드 + 추상 메소드 둘 다 가질 수 있음
> 추상 메소드가 하나라도 있으면 반드시 abstract class로 선언해야 함

---

## 3. 자식 클래스에서 구현

추상 메소드는 자식에서 반드시 @Override 구현.

```java
public class Warrior extends Player {
    @Override
    public void attack() {
        System.out.println("전사가 검으로 베기 공격을 합니다.");
    }
    // defend()는 오버라이딩 안 해도 됨 — 부모 것 그대로 사용
}
```

---

## 4. 다형성 적용

```java
Player[] players = new Player[2];
players[0] = new Warrior(); // 업캐스팅
players[1] = new Wizard();

for (Player player : players) {
    player.attack(); // 각 객체에 맞는 attack() 실행
    player.defend(); // 부모 공통 메소드 실행
}
```

---

## 전체 흐름 정리

    Player (추상 클래스)
    └─ abstract attack() → 자식이 반드시 구현
    └─ defend() → 공통 기능, 그대로 물려줌

    Warrior / Wizard extends Player
    └─ attack() 반드시 오버라이딩
    └─ defend()는 오버라이딩 안 해도 됨

    자주 헷갈리는 것
    └─ 추상 클래스는 new로 직접 생성 불가
    └─ 참조변수 타입으로는 사용 가능 (다형성)
    └─ 추상 메소드 = 몸체 없음, 자식이 반드시 구현
    └─ 일반 메소드는 그대로 물려줌 (오버라이딩 선택)
