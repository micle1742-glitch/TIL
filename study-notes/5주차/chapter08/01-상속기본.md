# chap08 — section01: 상속 (extend)

---

## 1. 상속이란?

공통 상태와 기능을 부모 클래스에 정의하고,
자식 클래스가 그것을 이어받아 사용하거나 자신의 목적에 맞게 확장하는 방법.

- 중복 코드를 줄이고 공통 기능은 부모에 한 번만 작성
- 자식은 다른 부분만 추가하거나 변경
- Java는 단일 상속만 지원 (부모 1개)

---

## 2. 기본 문법

```java
public class FireCar extends Car { }
```

---

## 3. 접근제한자

| 접근제한자  | 같은 클래스 | 같은 패키지 | 자식 클래스 | 외부 |
|-----------|-----------|-----------|-----------|------|
| public    | ✅ | ✅ | ✅ | ✅ |
| protected | ✅ | ✅ | ✅ | ❌ |
| (default) | ✅ | ✅ | ❌ | ❌ |
| private   | ✅ | ❌ | ❌ | ❌ |

> `private`은 자식도 접근 불가
> `protected`는 다른 패키지여도 자식이면 접근 가능
> 왜 다 public으로 안 쓰냐? → 외부에서 마음대로 값 변경하는 걸 막기 위해

---

## 4. protected 실사용 예시

```java
// Car.java
private boolean runningStatus;  // 외부·자식 직접 접근 불가

protected boolean isRunning() { // 자식은 이걸 통해 접근
    return runningStatus;
}
```

```java
// FireCar.java
@Override
public void soundHorn() {
    if (isRunning()) { ... }  // protected라 자식에서 호출 가능
}
```

---

## 5. 오버라이딩 (Overriding)

부모에게 물려받은 메소드를 자식의 목적에 맞게 같은 형태로 다시 작성하는 것.

```java
// FireCar.java
@Override
public void soundHorn() {
    if (isRunning()) {
        System.out.println("빠아아아아아아아앙");
    } else {
        System.out.println("소방차가 갑니다 비키세요~~!!!");
    }
}
```

> 부모 클래스 자체는 안 바뀜. Car 객체로 호출하면 원본, FireCar 객체로 호출하면 재정의된 버전 실행

---

## 6. super() — 부모 생성자 호출

자식 생성자에서 부모 생성자를 명시적으로 호출.

```java
// FireCar.java
public FireCar() {
    super(); // 부모(Car) 기본 생성자 호출
    System.out.println("FireCar 기본 생성자 호출...");
}
```

> 생략하면 Java가 자동으로 super() 삽입 (부모에 기본 생성자 있을 때만)
> 부모에 매개변수 있는 생성자만 있으면 반드시 직접 super(...) 써야 함

---

## 7. super.메소드() — 부모 메소드 호출

오버라이딩하면서 부모 것도 같이 실행하고 싶을 때.

```java
// RacingCar.java
@Override
public void run() {
    super.run();  // 부모 run() 먼저 실행 → "자동차가 달립니다."
    System.out.println("매우 빠르게 달립니다.");
}
```

---

## 8. 자식 클래스에서 기능 추가

오버라이딩 외에 자식만의 새 메소드 추가 가능.

```java
// FireCar.java
public void sprayWater() {
    System.out.println("불난 곳을 발견 했습니다 물을 뿌립니다!!");
}
```

> 부모 타입(Car)으로는 이 메소드 호출 불가. FireCar 타입으로 선언해야 함

---

## 9. 오버로딩 vs 오버라이딩

| 구분    | 오버로딩              | 오버라이딩               |
|--------|----------------------|-------------------------|
| 위치   | 같은 클래스 안        | 상속 관계 (부모 → 자식)  |
| 내용   | 이름 같고 매개변수 다름 | 부모 메소드를 자식이 재정의 |
| 키워드 | 없음                 | @Override               |

---

## 전체 흐름 정리

    Car (부모)
    └─ run(), stop(), soundHorn(), isRunning()
    └─ private runningStatus → 직접 접근 불가
    └─ protected isRunning() → 자식만 접근 가능

    FireCar extends Car (자식1)
    └─ super() → 부모 생성자 호출
    └─ soundHorn() 오버라이딩 → 소방차 버전으로 교체
    └─ sprayWater() 추가 → FireCar만의 기능

    RacingCar extends Car (자식2)
    └─ run() 오버라이딩
    └─ super.run() → 부모 것 먼저 실행 후 추가 출력

    Application
    └─ 실행 진입점, 객체 생성 및 메소드 호출만 담당
    └─ Car / FireCar / RacingCar 각각 객체 만들어서 비교

    자주 헷갈리는 것
    └─ super() : 부모 생성자 호출 (초기화 목적)
    └─ super.메소드() : 오버라이딩 안에서 부모 버전 실행
    └─ 부모 필드 그냥 쓰는 건 super 없어도 됨 (물려받은 거니까)
    └─ private은 자식도 못 씀 → getter/setter 또는 protected 메소드 이용
