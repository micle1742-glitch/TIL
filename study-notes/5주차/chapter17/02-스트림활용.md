# 02-스트림활용

---

## 1. 예제 데이터 (DTO 리스트)

```java
List<OnlineCourse> courses = Arrays.asList(
        new OnlineCourse("java의 정석", "Programming", 120, false),
        new OnlineCourse("Spring 완전 정복", "Programming", 300, false),
        new OnlineCourse("JPA 끝장내기", "Programming", 240, true),
        new OnlineCourse("포토샵 마스터", "Design", 90, true),
        new OnlineCourse("일러스트레이터 시작하기", "Design", 150, false),
        new OnlineCourse("SQL 첫걸음", "Database", 80, true),
        new OnlineCourse("데이터베이스 모델링", "Database", 150, false)
);
```

> OnlineCourse = 필드(title, category, duration, isFree) + 생성자 + getter/setter + toString
> boolean 필드의 getter는 `isFree()` 형태

---

## 2. 조건 검색 (filter + map)

Programming 강의 중 200분을 초과하는 강의 제목

```java
courses.stream()
        .filter(c -> "Programming".equals(c.getCategory()))
        .filter(c -> c.getDuration() > 200)
        .map(OnlineCourse::getTitle)       // 객체 → 제목(String)으로 변환
        .forEach(System.out::println);
// Spring 완전 정복, JPA 끝장내기
```

> `"Programming".equals(...)` : 확실한 문자열을 앞에 두면 null이어도 NPE 안 남
> 오타("Programing")가 있으면 에러 없이 **결과 0개** → 찾기 힘든 버그

---

## 3. 첫 번째 요소 찾기 (findFirst + Optional)

```java
Optional<OnlineCourse> firstRecommendedCourse = courses.stream()
        .filter(c -> "Programming".equals(c.getCategory()))
        .filter(c -> c.getDuration() > 200)
        .findFirst();

firstRecommendedCourse.ifPresent(c -> System.out.println("추천 강의 : " + c.getTitle()));
```

> Optional = 값이 있을 수도, 없을 수도 있는 상자 (null 대신 사용)
> `ifPresent` : 값이 있으면 실행

---

## 4. 정렬 (sorted)

무료 강의를 수강 시간순으로

```java
courses.stream()
        .filter(OnlineCourse::isFree)
        .sorted((c1, c2) -> Integer.compare(c1.getDuration(), c2.getDuration()))
        // .sorted(Comparator.comparingInt(OnlineCourse::getDuration))  // 같은 뜻, 더 짧게
        .forEach(System.out::println);
// SQL 첫걸음(80) → 포토샵 마스터(90) → JPA 끝장내기(240)
```

> sorted 안은 Comparator → `Integer.compare` 사용 (빼기 방식 X)

---

## 5. 중복 제거 (distinct)

```java
courses.stream()
        .map(OnlineCourse::getCategory)
        .distinct()
        .forEach(System.out::println);
// Programming, Design, Database
```

---

## 6. 합계·평균 (mapToInt)

```java
int totalDurationOfFree = courses.stream()
        .filter(OnlineCourse::isFree)
        .mapToInt(OnlineCourse::getDuration)   // 숫자 전용 스트림(IntStream)으로 변환
        .sum();
System.out.println("무료 강의 총 시간 : " + totalDurationOfFree);   // 410
```

| 메소드 | 기능 |
|---|---|
| `count()` | 남아 있는 요소 개수 |
| `sum()` | 합계 (mapToInt 후) |
| `average()` | 평균 (OptionalDouble 반환) |

---

## 7. 그룹핑 (groupingBy)

카테고리별로 강의 묶기

```java
Map<String, List<OnlineCourse>> courseByCategory = courses.stream()
        .collect(Collectors.groupingBy(OnlineCourse::getCategory));

courseByCategory.forEach((category, courseList) -> {
    System.out.println("[" + category + "]");
    courseList.forEach(c -> System.out.println("- " + c.getTitle()));
});
```

> 결과 타입: `Map<key 타입, List<요소 타입>>`
> HashMap이라 카테고리 출력 순서는 섞일 수 있음
> 람다 매개변수 타입은 전부 적거나 전부 생략 (섞으면 에러)

---

## 전체 흐름 정리

    조건 검색   filter (+ map으로 필요한 값만)
    하나 찾기   findFirst → Optional → ifPresent
    정렬       sorted(Integer.compare / Comparator.comparingInt)
    중복 제거   map → distinct
    집계       mapToInt → sum / average, count
    그룹핑     collect(Collectors.groupingBy(기준))

    자주 헷갈리는 것
    └─ 문자열 비교는 "확실한값".equals(변수)
    └─ 오타는 에러 없이 결과만 비게 만듦
    └─ groupingBy 결과는 Map → forEach((key, value) -> ...)로 출력
