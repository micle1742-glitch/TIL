# 01-스트림기본

---

## 1. Stream API란?

컬렉션에 들어 있는 여러 데이터를 조건에 따라 **거르고, 바꾸고, 모으는** 작업을 읽기 좋게 만들어주는 도구.

> 입출력 스트림(FileInputStream 등)과는 이름만 같고 다른 것
> 비유: List(상자) → stream()으로 컨베이어 벨트에 올림 → 가공 → 결과 받기

---

## 2. 스트림 3단계

| 단계 | 하는 일 | 예시 |
|---|---|---|
| 생성 | 컬렉션을 스트림으로 | `list.stream()` |
| 중간 연산 | 거르기·바꾸기·정렬 (여러 개 연결 가능) | `filter`, `map`, `sorted`, `distinct` |
| 최종 연산 | 결과 만들기 (**딱 한 번**) | `forEach`, `collect`, `count`, `anyMatch`, `allMatch` |

> 중간 연산만 있으면 아무것도 실행 안 됨 (게으른 실행, lazy)
> 세미콜론은 **맨 마지막에 한 번만** (중간에 붙이면 체인이 끊김)

## 3. for/if vs Stream

이름이 세 글자인 사람만 골라 대괄호를 붙여 출력

```java
List<String> names = Arrays.asList("홍길동", "유관순", "이순신", "신사임당", "장보고", "강감찬", "이성계");

// for/if 사용
for (String name : names) {
    if (name.length() == 3) {
        String decoratedName = "[" + name + "]";
        System.out.println(decoratedName);
    }
}

// Stream 사용
names.stream()
        .filter(name -> name.length() == 3)   // 조건에 맞는 것만 통과
        .map(name -> "[" + name + "]")        // 하나씩 변환
        .forEach(System.out::println);        // 하나씩 출력
```

| 메소드 | 받는 람다 타입 | 역할 |
|---|---|---|
| `filter` | Predicate | 값 → true/false, true만 통과 |
| `map` | Function | 값 → 다른 값으로 변환 |
| `forEach` | Consumer | 값 → 처리 (반환 없음) |

## 4. 정렬하고 리스트로 모으기

```java
List<String> leeFamily = names.stream()
        .filter(name -> name.startsWith("이"))      // "이"로 시작
        .sorted(Comparator.reverseOrder())          // 내림차순 정렬
        .collect(Collectors.toList());              // List로 모으기

System.out.println("이씨 가문 사람들 : " + leeFamily);   // [이성계, 이순신]
System.out.println("원본 이름 목록 : " + names);         // 원본은 그대로
```

> 스트림은 **원본을 바꾸지 않음** → 결과는 새로 만들어짐

## 5. 최종 연산

```java
// count() : 조건에 맞는 요소 개수 (long 반환)
long leeCount = names.stream()
        .filter(name -> name.startsWith("이"))
        .count();                                   // 2

// anyMatch() : 하나라도 조건을 만족하면 true
boolean hasJang = names.stream()
        .anyMatch(name -> name.equals("장보고"));   // true

// allMatch() : 모든 요소가 조건을 만족하면 true
boolean isAllThreeLetters = names.stream()
        .allMatch(name -> name.length() == 3);      // false (신사임당)
```

---

## 6. 스트림은 1회용

```java
Stream<String> stream = names.stream();
System.out.println("첫 번째 최종 연산 결과 " + stream.count());   // OK
stream.forEach(System.out::println);
// 💥 IllegalStateException: stream has already been operated upon or closed
```

> 최종 연산이 한 번 실행되면 스트림은 소비(닫힘)됨
> 다시 쓰려면 `names.stream()`으로 **새로 생성**

---

## 전체 흐름 정리

    Stream
    └─ 생성(stream) → 중간 연산(filter, map, sorted) → 최종 연산(forEach, collect, count)
    └─ 원본 변경 X, 최종 연산 없으면 실행 X, 1회용

    자주 헷갈리는 것
    └─ String vs Stream 철자 주의
    └─ 중간에 ; 붙이면 체인 끊김
    └─ 스트림 .map()(변환) ≠ 컬렉션 Map(key-value)
    └─ JS map은 바로 배열 반환, Java는 최종 연산 필요
