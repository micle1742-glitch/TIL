## 1. 메소드 기본

### 핵심 개념
- **메소드**: 특정 작업을 수행하기 위한 명령문의 묶음
- 왜 쓰나? → 같은 코드를 반복해서 쓰지 않고, 기능 단위로 나눠서 읽기 쉽고 고치기 쉽게 만들려고
- non-static 메소드는 **객체를 먼저 만들고** `객체.메소드()`로 호출

### 호출 문법

    Application1 app1 = new Application1(); // 객체 생성
    app1.methodA();                          // 메소드 호출

### 호출 흐름 (스택처럼 쌓였다가 거꾸로 끝남)

    main → methodA → methodB → methodC
    출력 순서:
    main 호출됨
    methodA() 호출함
    methodB() 호출함
    methodC() 호출함
    methodC() 종료됨
    methodB() 종료됨
    methodA() 종료됨
    main 종료됨

- 메소드를 호출하면 그 메소드가 **끝날 때까지** 호출한 쪽은 기다림
- 끝나면 **호출했던 위치로 돌아와서** 다음 줄 실행
- 같은 클래스 안의 non-static 메소드끼리는 `methodB();`처럼 객체 없이 바로 호출 가능 (이미 객체 안에서 실행 중이라서)

### 헷갈리는 부분
- 먼저 호출된 메소드가 **가장 나중에** 종료됨 (먼저 들어간 게 나중에 나옴 = 스택)

## 2. 전달인자 / 매개변수 / 반환값

### 용어 구분 (암기)
| 용어 | 위치 | 예시 |
|---|---|---|
| 전달인자(argument) | 호출할 때 넘기는 값 | `app2.printAge(5)`의 `5` |
| 매개변수(parameter) | 메소드 선언부에서 받는 변수 | `printAge(int age)`의 `age` |
| 반환값(return value) | 메소드가 끝나면서 돌려주는 값 | `return "hello";` |

### 매개변수 여러 개

    public void printUserInfo(String name, int age, char gender) { ... }

    app2.printUserInfo("판다", 3, '남');

- **타입, 개수, 순서**를 정확히 맞춰야 함
- `printUserInfo(3, "판다", '남')` → 순서 틀려서 컴파일 에러

### 반환 타입

    // void: 반환값 없음, return 생략 가능
    public void printAge(int age) {
        System.out.println("나이: " + age);
    }

    // String: 반드시 String 값을 return
    public String createString(String name, int age) {
        String profile = name + "님의 나이는 " + age + "세";
        return profile;
    }

    String message2 = app2.createString("코알라", 2); // 반환값을 변수에 저장

### 왜 반환값을 쓰나?
- `println`으로 바로 출력하면 그 결과를 **다른 곳에서 다시 쓸 수 없음**
- `return`으로 돌려주면 변수에 저장하거나, 다른 메소드의 인자로 바로 넘길 수 있음
  - 예: `System.out.println(sumTwoNumbers(10, 20));`

### 헷갈리는 부분
- 반환 타입이 `void`가 아니면 **return 없으면 컴파일 에러**
- `return`을 만나면 메소드는 **그 자리에서 즉시 종료**
- 반환값을 안 받아도 에러는 아님 (`Math.abs(-7);`처럼 그냥 버려짐 → 의미 없는 코드)

## 3. static 메소드 vs non-static 메소드

### 핵심 개념
- **static 메소드**: 객체가 아니라 **클래스에 속함** → 객체 생성 없이 `클래스명.메소드명()`
- **non-static 메소드**: 객체에 속함 → `new`로 객체 만든 뒤 `객체.메소드명()`

### 예시 (Calculator)

    public class Calculator {
        public int minNumberOf(int first, int second) {          // non-static
            return (first < second) ? first : second;
        }
        public static int maxNumberOf(int first, int second) {   // static
            return (first > second) ? first : second;
        }
    }

    Calculator calc = new Calculator();
    int min = calc.minNumberOf(100, 50);          // non-static → 객체로 호출
    int max = Calculator.maxNumberOf(100, 50);    // static → 클래스명으로 호출

### 호출 방법 정리 (암기)
| 상황 | 호출 방법 |
|---|---|
| non-static | `객체.메소드()` (new 필수) |
| static, 다른 클래스 | `클래스명.메소드()` (클래스명 필수) |
| static, 같은 클래스 | `메소드()` (클래스명 생략 가능) |

### 헷갈리는 부분
- `calc.maxNumberOf(3, 1)`처럼 static 메소드를 객체로 호출해도 **동작은 함** → 하지만 **권장 X**
  - 이유: 객체랑 상관없는 메소드인데 객체 메소드처럼 보여서 읽는 사람이 헷갈림
- `main`이 static이라서 main 안에서 같은 클래스의 **non-static 메소드는 바로 못 부름** → 그래서 Application1에서 `new Application1()` 한 것
- 언제 static? → 객체 상태(필드)를 안 쓰고 입력값만으로 결과가 나오는 기능 (예: 두 수 중 큰 값, Math 메소드들)

## 4. package와 import

### 핵심 개념
- **package**: 클래스를 묶는 폴더 같은 것. 클래스의 진짜 이름은 `패키지명.클래스명` (풀네임)
- 다른 패키지의 클래스를 쓸 땐 풀네임을 써야 함 → 매번 쓰기 귀찮으니까 **import**

### import 없이 (풀네임)

    com.ohgiraffers.section01.method.Calculator calc =
        new com.ohgiraffers.section01.method.Calculator();

### import 사용

    import com.ohgiraffers.section01.method.Calculator;

    Calculator calc = new Calculator();
    int max = Calculator.maxNumberOf(30, 20);

### static import (static 메소드에서 클래스명까지 생략)

    import static com.ohgiraffers.section01.method.Calculator.maxNumberOf;

    int max3 = maxNumberOf(30, 20);

### 헷갈리는 부분
- `import`는 **클래스**를 가져옴, `import static`은 **static 멤버(메소드/상수)**를 가져옴
- import 위치: `package` 선언 **아래**, `class` 선언 **위**
- `java.lang` 패키지(String, Math, System, Integer 등)는 **import 안 해도 자동**으로 쓸 수 있음
- static import는 편하지만 남발하면 이 메소드가 어느 클래스 건지 헷갈림 → 선택적으로

## 5. API - Math, Random

### API란?
- 자바가 자주 쓰는 기능을 클래스·메소드로 **미리 만들어서 제공**하는 것 + 그걸 쓰는 규칙
- 직접 구현하지 않고 가져다 쓰면 됨 (예: 최대값, 난수)

### java.lang.Math (전부 static → 객체 생성 X)

    Math.abs(-7);        // 절대값 7
    Math.max(10, 20);    // 20
    Math.min(10, 20);    // 10
    Math.random();       // 0.0 이상 1.0 미만 실수

### Math.random()으로 범위 난수 (공식 암기)

    (int) (Math.random() * 개수) + 최소값

    // 10 ~ 15 → 개수 6개(10,11,12,13,14,15), 최소값 10
    int random = (int) (Math.random() * 6) + 10;

- 개수 = 최대값 - 최소값 + 1

### java.util.Random (객체 생성 O, import 필요)

    import java.util.Random;

    Random rd = new Random();
    int n = rd.nextInt(10);        // 0 ~ 9
    int m = rd.nextInt(6) + 10;    // 10 ~ 15

### 비교
| | Math.random() | Random.nextInt() |
|---|---|---|
| 패키지 | java.lang (import X) | java.util (import O) |
| 호출 | static → `Math.random()` | 객체 생성 후 `rd.nextInt()` |
| 반환 | double (0.0 ~ 1.0 미만) | int (0 ~ bound-1) |
| 정수 만들기 | 곱하고 (int) 형변환 필요 | 바로 정수 |

### 헷갈리는 부분
- `(int) Math.random() * 6` → **항상 0** (먼저 형변환돼서 0 × 6). 괄호 꼭 `(int) (Math.random() * 6)`
- `nextInt(10)`은 10 **포함 X** → 0~9

## 6. Scanner (키보드 입력)

### 기본 구조

    import java.util.Scanner;

    Scanner sc = new Scanner(System.in);  // System.in = 키보드 입력
    // ... 입력 받기
    sc.close();                           // 다 쓰면 자원 정리

### 주요 메소드 (암기)
| 메소드 | 읽는 범위 | 반환 |
|---|---|---|
| `nextLine()` | 엔터 전까지 **한 줄 전체** (공백 포함) | String |
| `next()` | 공백/엔터 전까지 **한 단어** | String |
| `nextInt()` | 공백/엔터 전까지 정수 | int |
| `nextDouble()` | 공백/엔터 전까지 실수 | double |

### 문자(char) 입력 받기
- Scanner엔 `nextChar()`가 **없음**
- 문자열로 받고 `charAt(인덱스)`로 꺼냄

    char ch = sc.nextLine().charAt(0);  // 첫 글자

### 문자열 → 정수 변환

    String ageInput = sc.nextLine();
    int age = Integer.parseInt(ageInput);

### 가장 많이 헷갈리는 부분: 버퍼에 남은 엔터

    int age = sc.nextInt();   // "20" 입력 후 엔터 → 20만 가져가고 엔터(\n)는 남음
    sc.nextLine();            // 남은 엔터 비우기 (이거 없으면 아래 nextLine이 빈 문자열 받음)
    String name = sc.nextLine();

- `nextInt()`, `next()`, `nextDouble()` 뒤에 `nextLine()`을 쓰면 **남아있던 엔터를 바로 읽고 끝나버림**
- 해결법 2가지
  1. 중간에 `sc.nextLine();` 한 번 넣어서 비우기
  2. 처음부터 전부 `nextLine()`으로 받고 `Integer.parseInt()`로 변환
- `next()`도 비슷함: "안녕 하세요" 입력하면 `next()`는 "안녕"만 가져가고 " 하세요"가 남음 → 다음 `nextInt()`가 "하세요"를 읽으려다 **InputMismatchException**

## 직접 해보기
1. `int sum(int a, int b)`를 non-static으로 만들고 main에서 호출해서 결과 출력하기
2. 같은 걸 static으로 바꾸고, 다른 클래스에서 `클래스명.sum()`으로 호출하기
3. 다른 패키지에서 import / static import로 각각 호출해보기
4. 1~45 난수를 Math.random()과 Random 두 방식으로 만들기
5. Scanner로 나이(nextInt) 받고 → 이름(nextLine) 받기. `sc.nextLine()` 빼고 실행해서 무슨 일 생기는지 확인

## 셀프 체크 (OX)
- static 메소드는 객체를 만들어야만 호출할 수 있다 → X
- 반환 타입이 int인 메소드에 return이 없으면 컴파일 에러다 → O
- Math 클래스는 import 해야 쓸 수 있다 → X (java.lang)
- `new Random().nextInt(5)`의 결과 범위는 0~5다 → X (0~4)
- `nextInt()` 다음에 바로 `nextLine()`을 쓰면 빈 문자열이 들어올 수 있다 → O

## 전체 흐름 정리
기능을 **메소드**로 나눠 만들고, 값을 **매개변수로 받고 return으로 돌려준다.**
메소드는 객체에 속하면 `new` 후 `객체.메소드()`, 클래스에 속하면(**static**) `클래스명.메소드()`로 부른다.
다른 패키지의 클래스는 **import**로 가져오고, 자바가 미리 만들어 둔 클래스들(**API**: Math, Random, Scanner)도 같은 규칙으로 쓴다.
Math는 static이라 바로, Random/Scanner는 객체를 만들어서 쓴다.
마지막으로 Scanner로 사용자 입력을 받아 프로그램에 값을 넣는데, **엔터 버퍼 문제**만 조심하면 된다.
