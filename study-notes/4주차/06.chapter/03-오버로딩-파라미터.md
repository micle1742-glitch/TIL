# 03-오버로딩-파라미터

---

## section05-1. 오버로딩 (Overloading)

### 1. 오버로딩이란?

이름은 같지만 매개변수(시그니처)가 다른 메소드를 여러 개 정의하는 것.
Java가 인자를 보고 알맞은 메소드를 자동으로 찾아줌.

```java
calc.add(20, 30);       // int 2개 → add(int, int) 호출
calc.add(20.5, 30.5);   // double 2개 → add(double, double) 호출
calc.add(40, 50, 60);   // int 3개 → add(int, int, int) 호출
```

### 2. 메소드 시그니처

메소드를 식별하는 고유한 바코드 = **메소드 이름 + 매개변수 타입·개수·순서**

```java
public void test() {}
public void test(String str) {}    // 개수 다름 → 성립
public void test(int num) {}       // 타입 다름 → 성립
public void test(int num, String str) {}   // 순서 다름 → 성립
public void test(String str, int num) {}   // 순서 다름 → 성립
```

### 3. 오버로딩 불성립 경우

```java
// 반환 타입만 다른 경우 → 불성립
public int test() { return 0; }
// public void test() {} 와 구분 불가

// 접근제한자만 다른 경우 → 불성립
// 매개변수 이름만 다른 경우 → 불성립
public void test(int num2) {} // test(int num)과 같음
```

## section05-2. 파라미터 전달 방식

### 1. 기본 자료형 — 값 복사 (pass by value)

```java
int num = 20;
mp.primitiveType(num); // 값 20을 복사해서 전달
// 메소드 안에서 num = 99로 바꿔도 원본에 영향 없음
System.out.println(num); // 여전히 20
```

### 2. 참조 자료형 — 참조값 복사 (pass by reference)

```java
int[] iarr = {1, 2, 3, 4, 5};
ArrayParameter(iarr);          // 배열의 참조값(주소)을 복사해서 전달
// 메소드 안에서 arr[0] = 99로 바꾸면 원본도 변경됨
System.out.println(Arrays.toString(iarr)); // [99, 2, 3, 4, 5]
```

> 기본 자료형: 값 자체를 복사 → 원본 불변
> 배열·객체: 주소를 복사 → 원본도 변경됨

### 3. 가변인자 (varargs)

전달 인자의 개수가 유동적일 때 사용. JS의 `...rest`와 같은 역할.

```java
public void orderPizza(String customerName, String... toppings) {
    System.out.println(Arrays.toString(toppings));
}

orderPizza("판다", "치즈", "페퍼로니");     // toppings = ["치즈", "페퍼로니"]
orderPizza("코알라");                       // toppings = []
```

> `...`으로 선언, 메소드 내부에서 배열로 취급
> 가변인자는 매개변수 목록의 마지막에 위치해야 함

## 전체 흐름 정리

    오버로딩
    └─ 같은 이름, 다른 매개변수(타입·개수·순서)
    └─ 반환 타입·접근제한자·매개변수 이름만 다르면 불성립
    └─ Java가 인자 보고 알맞은 메소드 자동 선택

    파라미터 전달
    └─ 기본 자료형: 값 복사 → 메소드 안에서 바꿔도 원본 불변
    └─ 배열·객체: 참조값(주소) 복사 → 원본도 변경됨
    └─ 가변인자(...): 개수 유동적, 내부에서 배열로 처리

    자주 헷갈리는 것
    └─ 오버로딩 vs 오버라이딩: 같은 클래스 안 vs 상속 관계
    └─ 배열은 참조 자료형이라 메소드에 넘기면 원본 바뀜
    └─ 가변인자는 항상 마지막 매개변수로
