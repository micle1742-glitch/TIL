# 문제

**1.** [단답] 출력 결과는?

```java
Car[] carArray = new Car[3];
System.out.println(carArray[0]);
```

**2.** [개념] 자식 생성자에서 부모 생성자를 호출해 부모 필드를 초기화할 때 쓰는 것은?

**3.** [개념] 오버라이딩한 메소드 안에서 부모 버전의 메소드를 실행할 때 쓰는 것은?

**4.** [개념] 부모에게 물려받은 메소드를 이름·매개변수는 그대로 두고 자식의 목적에 맞게 다시 작성하는 것은?

**5.** [개념] 자식 객체를 부모 타입 변수에 저장하는 것으로 자동으로 형변환되는 것은?

**6.** [개념] 자식 고유 메소드를 쓰기 위해 부모 타입을 자식 타입으로 명시적으로 형변환하는 것은?

**7.** [개념] 컴파일 때는 부모 메소드로 보이지만 실행 시 실제 객체의 오버라이딩된 메소드가 호출되는 것은?

**8.** [개념] 다운캐스팅하기 전에 실제 객체의 타입을 확인하는 연산자는?

**9.** [개념] 직접 객체를 생성할 수 없고, 몸체 없는 추상 메소드를 가질 수 있는 미완성 부모 클래스는?

**10.** [단답] 인스턴스 필드(공통 상태)를 가질 수 있는 것은 추상 클래스와 인터페이스 중 어느 쪽인가?

**11.** [개념] 문자열을 반복해서 연결할 때 새 객체를 계속 만드는 String과 달리 내부 버퍼에 추가하는 가변 클래스는?

**12.** [단답] 출력 결과는?

```java
String input = null;
System.out.println("java".equals(input));
```

**13.** [단답] `Integer.parseInt("abc")`를 실행하면 발생하는 예외는?

**14.** [개념] `<T extends Rabbit>`처럼 Rabbit과 그 자식 타입만 허용하도록 제네릭의 타입을 제한하는 문법은?

**15.** [단답] ArrayList와 LinkedList 중 중간 추가·삭제에 유리한 것은?

**16.** [개념] 클래스 안에 `compareTo()`를 구현해 기본 정렬 기준을 정하는 인터페이스는?

**17.** [개념] 정렬할 클래스 밖에 별도 클래스로 구현해 추가적인 정렬 기준을 정하는 인터페이스는?

**18.** [단답] 출력 결과는?

```java
Deque<Integer> stack = new ArrayDeque<>();
stack.push(1);
stack.push(2);
System.out.println(stack.pop());
```

**19.** [단답] 출력 결과는?

```java
Queue<String> queue = new ArrayDeque<>();
System.out.println(queue.poll());
```

**20.** [개념] 중복을 허용하지 않으면서 입력한 순서를 기억하는 Set은?

**21.** [개념] 중복을 허용하지 않으면서 저장할 때마다 자동으로 오름차순 정렬하는 Set은?

**22.** [단답] 출력 결과는?

```java
Map<String, String> map = new HashMap<>();
map.put("two", "jdbc");
map.put("two", "html");
System.out.println(map.get("two"));
```

**23.** [개념] 예외를 지금 직접 발생시키는 키워드는?

**24.** [개념] 메소드 선언부에 붙여 예외가 나갈 수 있다고 선언하고 처리를 호출한 쪽에 넘기는 키워드는?

**25.** [개념] 텍스트 파일을 문자 단위로 읽어 한글도 깨지지 않게 읽는 기본 스트림은?

**26.** [단답] `BufferedReader.readLine()`은 더 읽을 줄이 없으면 무엇을 반환하는가?

**27.** [개념] try 괄호 안에서 스트림을 만들면 블록이 끝날 때 자동으로 close()가 호출되는 문법은?

**28.** [개념] key=value 설정 값을 파일로 저장(store)하고 읽어오는(load) 클래스는?

**29.** [개념] 정해진 값들만 가질 수 있는 전용 타입을 만드는 문법은?

**30.** [개념] 추상 메소드가 딱 1개인 인터페이스로 람다가 담기는 타입이 되는 것은?

**31.** [개념] 입력을 받아 처리만 하고 반환값이 없는(accept) 함수형 인터페이스는?

**32.** [개념] 입력 없이 값만 제공하는(get) 함수형 인터페이스는?

**33.** [개념] 입력을 받아 true/false를 반환하는(test) 검사용 함수형 인터페이스는?

**34.** [개념] 입력을 받아 다른 타입으로 변환해 반환하는(apply) 함수형 인터페이스는?

**35.** [단답] 결과는?

```java

Calculator c = (a, b) -> a - b;
System.out.println(c.operate(10, 19));
```

**36.** [단답] `Integer::parseInt`를 매개변수 이름 `value`를 쓴 람다로 풀어 쓰면?

**38.** [개념] `findFirst()`처럼 값이 있을 수도 없을 수도 있는 결과를 null 대신 담는 상자는?

**39.** [개념] 스트림 요소를 카테고리 같은 기준으로 묶어 `Map<기준, List<요소>>`로 만드는 Collectors 메소드는?

# 정답

| 번호 | 정답 | 해설 |
|---|---|---|
| 1 | null | new Car[3]은 칸만 만들고 각 칸은 객체를 넣기 전까지 null이다. |
| 2 | super() | 생성자의 첫 줄에 위치하며, 부모 필드가 private이어도 초기화할 수 있다. |
| 3 | super.메소드() | super()는 생성자에서 부모 초기화, super.메소드()는 부모 메소드 재사용이다. |
| 4 | 오버라이딩 | 매개변수가 다르면 오버라이딩이 아니라 오버로딩이다. |
| 5 | 업캐스팅 | 업캐스팅 후에는 부모에 정의된 메소드만 접근할 수 있다. |
| 6 | 다운캐스팅 | `((Rabbit)a1).jump()`처럼 쓰며 잘못하면 ClassCastException이 발생한다. |
| 7 | 동적 바인딩 | `Animal a1 = new Rabbit(); a1.cry();`는 Rabbit의 cry()가 실행된다. |
| 8 | instanceof | 확인 후 다운캐스팅해야 ClassCastException을 피할 수 있다. |
| 9 | 추상 클래스(abstract class) | 자식이 추상 메소드를 반드시 오버라이딩해야 하며 일반 메소드도 가질 수 있다. |
| 10 | 추상 클래스 | 인터페이스는 인스턴스 필드를 가질 수 없고 상수만 가능하다. |
| 11 | StringBuilder | String은 불변이라 연결할 때마다 새 객체가 생겨 느리다. |
| 12 | false | 리터럴을 앞에 두고 equals를 호출하면 null이어도 NullPointerException이 나지 않는다. |
| 13 | NumberFormatException | 숫자로 바꿀 수 없는 문자열을 파싱하면 NumberFormatException이 발생한다. |
| 14 | 타입 제한(extends) | Rabbit 계열이 아닌 타입은 컴파일 에러로 차단된다. |
| 15 | LinkedList | 연결만 바꾸면 되지만, ArrayList는 뒤 요소를 밀어야 한다. |
| 16 | Comparable | 클래스 밖에 `compare(o1, o2)`로 다른 기준을 정하는 것은 Comparator이다. |
| 17 | Comparator | `compare(o1, o2)`를 구현하며 `list.sort(new 기준())`으로 사용한다. |
| 18 | 2 | Stack은 후입선출(LIFO)이라 나중에 넣은 값이 먼저 나온다. |
| 19 | null | 빈 Queue에 poll()하면 에러가 아니라 null을 반환한다. |
| 20 | LinkedHashSet | HashSet은 순서 보장이 없고, TreeSet은 자동 정렬이다. |
| 21 | TreeSet | 객체를 담으려면 Comparable 구현 또는 Comparator 전달이 필요하다. |
| 22 | html | key는 중복될 수 없어서 같은 key로 put하면 값을 덮어쓴다. |
| 23 | throw | throw가 실행되면 그 아래 코드는 실행되지 않는다. |
| 24 | throws | throw는 발생시키는 행동, throws는 던질 수 있다는 선언이다. |
| 25 | FileReader | FileInputStream은 1바이트씩 읽어서 한글이 깨질 수 있다. |
| 26 | null | read()의 끝 신호는 -1이고 readLine()의 끝 신호는 null이다. |
| 27 | try-with-resources | finally와 null 체크, close 예외 처리가 필요 없어진다. |
| 28 | Properties | key와 value는 모두 String이며 DB 접속 정보 등을 코드 밖으로 분리할 때 쓴다. |
| 29 | enum(열거형) | int 상수와 달리 타입 안전성이 있고 출력하면 이름이 나온다. |
| 30 | 함수형 인터페이스 | `@FunctionalInterface`로 추상 메소드가 1개인지 검사할 수 있다. |
| 31 | Consumer | 출력만 하는 용도이며 `accept(t)`를 쓴다. |
| 32 | Supplier | 자판기처럼 기본값을 제공할 때 쓴다. |
| 33 | Predicate | 스트림 filter가 받는 람다 타입이기도 하다. |
| 34 | Function | 입력과 출력 타입이 같으면 UnaryOperator이다. |
| 35 | -9 | 람다가 10 - 19를 계산한다. |
| 36 | value -> Integer.parseInt(value) | 받은 값을 그대로 static 메소드에 넘기기만 할 때 `::`로 줄인다. |
| 37 | 지연 실행(lazy) | 최종 연산이 호출될 때 비로소 실행된다. |
| 38 | Optional | `ifPresent`로 값이 있을 때만 실행한다. |
| 39 | groupingBy | `collect(Collectors.groupingBy(기준))` 형태로 쓴다. |
