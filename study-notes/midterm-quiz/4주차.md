# 문제

**1.** [단답] 출력 결과는?

```java
System.out.println('a' + 'b');
```

**2.** [단답] 출력 결과는?

```java
System.out.println(9 + 9 + "9");
```

**3.** [단답] 출력 결과는? (byte 범위: -128 ~ 127)

```java
byte num = 127;
num++;
System.out.println(num);
```

**4.** [단답] int끼리 곱하면 int 범위에서 먼저 넘친다. 정확한 값을 구하도록 빈칸을 채우시오.

```java
int a = 1000000, b = 70000;
long result = (______) a * b;
```

**5.** [단답] 출력 결과는?

```java
float f = 4.7f;
System.out.println((long) f);
```

**6.** [단답] result의 값은?

```java
int firstNum = 10;
int result = ++firstNum * 3;
```

**7.** [단답] 마지막 비교 결과는?

```java
String a = "java";
String c = new String("java");
System.out.println(a == c);
```

**8.** [단답] 출력되는 num의 값은?

```java
int num = 10;
boolean r = false && ++num > 0;
System.out.println(num);
```

**9.** [개념] 메소드를 호출할 때 넘기는 실제 값은?

**10.** [개념] 메소드 선언부에서 값을 받기 위해 선언한 변수는?

**11.** [개념] 객체를 만들지 않고 `클래스명.메소드()`로 호출하는 메소드는?

**12.** [단답] 10~15 사이 난수를 만드는 코드의 빈칸은?

```java
int r = (int) (Math.random() * ______) + 10;
```

**13.** [개념] `nextInt()` 뒤에 `nextLine()`을 쓰면 빈 문자열이 읽히는 이유는 버퍼에 무엇이 남아 있기 때문인가?

**14.** [단답] 마지막 줄에서 발생하는 예외는?

```java
int[] arr = new int[3];
arr[3] = 1;
```

**15.** [개념] `int[] b = a;`처럼 배열 변수를 대입해 주소(참조값)만 복사하는 복사 방식은?

**16.** [단답] 새 배열을 만들어 복사하는 깊은 복사 메소드의 빈칸은?

```java
int[] copy = Arrays.______(origin, origin.length);
```

**17.** [단답] 반복 후 arr[0]의 값은?

```java
int[] arr = {1, 2, 3};
for (int value : arr) {
    value += 10;
}
```

**18.** [단답] 두 값을 교환하도록 빈칸을 채우시오.

```java
int temp = a;
a = b;
b = ______;
```

**19.** [개념] 바로 옆 칸끼리 비교해 큰 값을 뒤로 밀어 보내는 정렬은?

**20.** [개념] 남은 값 중 가장 작은 값의 위치(minIndex)를 찾아 앞자리와 회차당 한 번 교환하는 정렬은?

**21.** [개념] 중첩 반복문의 바깥 반복문까지 한 번에 탈출할 때 `break 이름;`으로 쓰는, 반복문 앞에 붙이는 이름은?

**22.** [개념] 향상된 switch(`case ->`)의 중괄호 블록에서 결과값을 돌려줄 때 쓰는 키워드는?

**23.** [개념] 기존 switch에서 break를 빼먹으면 맞는 case부터 아래 case들이 연달아 실행되는 현상은?

**24.** [개념] 반복 횟수를 모르지만 본문을 최소 한 번은 실행해야 할 때 쓰는 반복문은?

**25.** [개념] 객체가 가질 데이터(필드)와 기능(메소드)을 정의한 설계도는?

**26.** [개념] 필드를 private으로 감추고 getter/setter 메소드를 통해서만 접근하게 하는 방식은?

**27.** [개념] 접근 범위가 '같은 패키지 + 상속받은 자식 클래스'까지로 제한되는 접근제한자는?

**28.** [단답] `private boolean isActivated;`의 getter 메소드 이름은?

**29.** [개념] CarRacer가 Car 객체를 필드로 가지고 있는 것처럼 한 클래스가 다른 클래스를 소유하는 관계는?

**30.** [개념] 로직 없이 여러 데이터를 하나로 묶어 전달하는 객체는?

**31.** [단답] `public User(String id) { }`만 작성한 클래스에서 `new User()`를 호출하면?

**32.** [개념] 같은 클래스의 다른 생성자를 호출하며 반드시 생성자 첫 줄에 쓰는 것은?

**33.** [단답] `public int test()`와 `public void test()`를 한 클래스에 함께 선언하면 오버로딩이 성립하는가?

**34.** [단답] 출력 결과는?

```java
static void change(int n) { n = 99; }
// main
int num = 20;
change(num);
System.out.println(num);
```

**35.** [개념] `String... toppings`처럼 전달인자 개수가 유동적일 때 쓰는 매개변수는?

**36.** [개념] 모든 객체가 하나를 공유하고 클래스명으로 접근하는 클래스 변수를 만드는 키워드는?

**37.** [단답] `final String ssn;` 같은 final 인스턴스 필드는 어디에서 초기화해야 하는가?

**38.** [개념] 클래스의 인스턴스가 딱 하나만 생성되도록 보장하는 디자인 패턴은?

**39.** [개념] 싱글톤에서 getInstance()가 처음 호출될 때 인스턴스를 생성하는 방식은?

# 정답

| 번호 | 정답 | 해설 |
|---|---|---|
| 1 | 195 | 문자끼리는 유니코드 숫자(97 + 98)로 계산되어 "ab"가 아니다. |
| 2 | 189 | 왼쪽부터 9+9=18을 먼저 계산한 뒤 문자열 "9"와 이어 붙인다. |
| 3 | -128 | 범위를 넘으면 반대쪽 끝으로 넘어가는 오버플로우가 일어난다. |
| 4 | long | 계산 전에 하나를 long으로 바꿔야 계산 전체가 long으로 처리된다. |
| 5 | 4 | 실수를 정수로 강제 형변환하면 소수점이 버려진다. |
| 6 | 33 | 전위 증가는 먼저 1 증가(11)한 뒤 사용하므로 11 * 3이다. |
| 7 | false | new로 만들면 새 객체라 ==는 주소가 달라 false이다(내용 비교는 equals). |
| 8 | 10 | &&는 앞이 false면 뒤를 실행하지 않는다(단락 평가). |
| 9 | 전달인자(argument) | `printAge(5)`의 5가 전달인자이다. |
| 10 | 매개변수(parameter) | `printAge(int age)`의 age가 매개변수이다. |
| 11 | static 메소드 | static 메소드는 객체가 아니라 클래스에 속한다. |
| 12 | 6 | 개수 = 최대값 - 최소값 + 1 = 15 - 10 + 1 = 6이다. |
| 13 | 엔터(줄바꿈 \n) | nextInt는 숫자만 가져가고 엔터는 남겨서 nextLine이 그것을 바로 읽는다. |
| 14 | ArrayIndexOutOfBoundsException | 길이 3인 배열의 마지막 인덱스는 2이다. |
| 15 | 얕은 복사 | 배열은 하나이고 변수만 둘이라 b를 바꾸면 a도 바뀐다. |
| 16 | copyOf | Arrays.copyOf는 새 배열을 반환하고 길이를 조절할 수 있다. |
| 17 | 1 (바뀌지 않음) | 향상된 for의 value는 복사본이라 원본 배열이 바뀌지 않는다. |
| 18 | temp | 원래 a 값을 temp에 보관해야 b에 넣을 수 있다. |
| 19 | 버블 정렬 | 한 회차마다 가장 큰 값이 맨 뒤로 확정된다. |
| 20 | 선택 정렬 | 버블 정렬은 조건이 맞을 때마다 여러 번 교환한다. |
| 21 | 라벨 | `outer:`를 반복문 앞에 쓰고 `break outer;`로 탈출한다. |
| 22 | yield | return은 메소드 전체를 끝내지만 yield는 switch의 결과값만 정한다. |
| 23 | fall-through | break를 만날 때까지 아래 case가 모두 실행된다. |
| 24 | do-while | 본문을 먼저 실행하고 나중에 조건을 검사한다. |
| 25 | 클래스 | 클래스 자체는 객체가 아니며 new로 객체를 만든다. |
| 26 | 캡슐화 | setter에서 검증해 잘못된 값(음수 나이 등)을 막을 수 있다. |
| 27 | protected | public은 모든 패키지, default는 같은 패키지만, private은 해당 클래스 내부만 접근된다. |
| 28 | isActivated() | boolean 필드의 getter는 get 대신 is로 시작한다. |
| 29 | has-a 관계 | 상속(is-a)과 달리 소유 관계이다. |
| 30 | DTO | Data Transfer Object는 데이터 저장·전달만 담당한다. |
| 31 | 컴파일 에러 | 매개변수 있는 생성자가 하나라도 있으면 기본 생성자가 자동 추가되지 않는다. |
| 32 | this() | super()는 부모 생성자를 호출한다. |
| 33 | 성립하지 않는다 | 반환 타입만 다르면 시그니처(이름 + 매개변수)가 같아 구분할 수 없다. |
| 34 | 20 | 기본 자료형은 값이 복사되어 전달되므로 원본이 바뀌지 않는다. |
| 35 | 가변인자 | 메소드 내부에서 배열로 취급하며 매개변수 목록의 마지막에 둔다. |
| 36 | static | 인스턴스 변수는 객체마다 따로 존재한다. |
| 37 | 생성자 | 객체 생성 시 한 번만 결정되고 이후에는 바꿀 수 없다. |
| 38 | 싱글톤 | 생성자를 private으로 막고 static getInstance()로만 접근한다. |
| 39 | 늦은 초기화(Lazy) | 처음엔 null이고 최초 호출 시에만 생성해 메모리를 절약한다. |
