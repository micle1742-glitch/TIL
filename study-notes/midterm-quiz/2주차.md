# 문제

**1.** [개념] 대입한 문자열을 일반 텍스트로 처리하는 요소 프로퍼티는?

**2.** [개념] 대입한 문자열을 HTML로 해석해서 요소 내부를 바꾸는 프로퍼티는?

**3.** [단답] `createElement`로 만든 `$li`를 `$list`의 마지막 자식으로 추가하는 메서드는?

```js
$list.______($li);
```

**4.** [단답] 이미 DOM에 있는 노드를 다른 부모에 appendChild하면 복사될까, 이동될까?

**5.** [단답] HTML이 `<input value="홍길동">`이고 사용자가 `김철수`를 입력했다. `$input.value`의 결과는?

**6.** [단답] 위와 같은 상황에서 `$input.getAttribute('value')`의 결과는?

**7.** [단답] `<div class="box active">`에 `$box.className = 'circle'`을 실행한 뒤 class 값은?

**8.** [단답] 버튼을 클릭했을 때 출력되는 값은?

```js
$btn.onclick = function() { console.log('A'); };
$btn.onclick = function() { console.log('B'); };
```

**9.** [개념] 같은 이벤트에 여러 함수를 등록할 수 있는 이벤트 등록 메서드는?

**10.** [개념] 이벤트 객체에서 실제로 이벤트가 발생한 요소를 가리키는 프로퍼티는?

**11.** [개념] 이벤트 객체에서 이벤트 리스너를 등록한 요소를 가리키는 프로퍼티는?

**12.** [개념] 자식에서 발생한 이벤트가 부모 방향으로 올라가며 전달되는 현상은?

**13.** [개념] 부모 요소에 이벤트를 등록해 자식 요소에서 발생한 이벤트를 처리하는 방법은?

**14.** [개념] 현재 요소에서 가장 가까운 조건의 조상 요소를 찾는 메서드는?

**15.** [개념] 폼 제출이나 링크 이동 같은 브라우저의 기본 동작을 막는 메서드는?

**16.** [개념] 이벤트가 부모 요소로 전파되는 것을 막는 메서드는?

**17.** [개념] 키보드 이벤트에서 키의 물리적인 위치(예: 'KeyA')를 알려주는 프로퍼티는?

**18.** [개념] 일정 시간이 지난 후 콜백 함수를 딱 한 번 실행하는 함수는?

**19.** [개념] 일정 시간마다 콜백 함수를 계속 반복 실행하는 함수는?

**20.** [단답] 출력 순서는?

```js
console.log('1');
setTimeout(() => console.log('2'), 0);
console.log('3');
```

**21.** [개념] Call Stack이 비어 있는지 확인하고 Task Queue의 콜백을 Call Stack으로 옮기는 것은?

**22.** [개념] React에서 화면을 구성하는 하나의 독립적인 UI 단위는?

**23.** [개념] JavaScript 안에서 HTML과 비슷한 문법으로 UI를 작성하게 해주는 문법은?

**24.** [개념] React가 관리할 HTML 영역(`#root`)을 지정하는 함수는?

**25.** [개념] 부모 컴포넌트가 자식 컴포넌트에게 전달하는 데이터를 부르는 말은?

**26.** [개념] 컴포넌트가 내부에서 관리하는 데이터로, 변경되면 화면이 다시 렌더링되는 것은?

**27.** [개념] State가 변경되었을 때 컴포넌트 함수가 다시 실행되어 화면이 업데이트되는 과정은?

**28.** [단답] `onClick={handleEnter()}`는 함수가 언제 실행되는가?

**29.** [개념] input의 `value`를 State와 연결하고 `onChange`로 State를 바꾸는 방식은?

**30.** [단답] onChange에서 현재 입력값을 가져오는 코드의 빈칸은?

```js
onChange={e => setUsername(e.target.______)}
```

**31.** [단답] 결과 객체는?

```js
const form = { username: '영동', email: 'a@a.com' };
const next = { ...form, email: 'b@b.com' };
```

**32.** [개념] `setForm({ ...form, [name]: value })`에서 `[name]: value`처럼 변수 값을 속성 이름으로 쓰는 문법은?

**33.** [단답] 결과는?

```js
console.log([1, 2, 3].filter(x => x !== 2));
```

**34.** [개념] `todos.map(todo => <li ____={todo.id}>...</li>)`처럼 React가 리스트의 각 항목을 구분하도록 지정하는 속성 이름은?

**35.** [개념] 렌더링 이후에 실행할 부수효과(타이머, API 요청 등)를 작성하는 Hook은?

**36.** [단답] 이 Effect는 언제 실행되는가?

```js
useEffect(() => { console.log('실행'); }, []);
```

**37.** [단답] 이 Effect는 언제 실행되는가?

```js
useEffect(() => { console.log('실행'); }, [count]);
```

**38.** [개념] useEffect에서 `return () => {}`로 반환하며 Unmount 등에서 이전 작업을 정리하는 함수는?

**39.** [개념] `{showTimer && <Timer />}`처럼 값에 따라 컴포넌트를 보이거나 숨기는 방식은?

# 정답

| 번호 | 정답 | 해설 |
|---|---|---|
| 1 | textContent | HTML 태그도 문자 그대로 표시된다. |
| 2 | innerHTML | `<p>`처럼 태그가 실제 요소로 만들어진다. |
| 3 | appendChild | appendChild는 노드를 부모의 마지막 자식으로 추가한다. |
| 4 | 이동 | 복사되지 않고 위치가 옮겨진다. |
| 5 | '김철수' | .value는 현재 입력값을 반환한다. |
| 6 | '홍길동' | getAttribute는 HTML에 작성된 초기값을 반환한다. |
| 7 | circle | className은 class 전체를 교체한다. |
| 8 | B | onclick은 함수 하나만 저장하므로 나중 함수가 덮어쓴다. |
| 9 | addEventListener | onclick은 함수 1개만 저장된다. |
| 10 | e.target | 자식을 클릭하면 자식 요소가 target이 될 수 있다. |
| 11 | e.currentTarget | target과 다를 수 있다. |
| 12 | 이벤트 버블링 | 이벤트는 기본적으로 버블링된다. |
| 13 | 이벤트 위임 | 버블링을 이용해 자식마다 이벤트를 등록하지 않아도 된다. |
| 14 | closest() | 못 찾으면 null을 반환한다. |
| 15 | preventDefault() | stopPropagation은 전파를 막는다. |
| 16 | stopPropagation() | 버블링을 차단한다. |
| 17 | e.code | 실제 입력된 키('a', 'A')는 e.key이다. |
| 18 | setTimeout | 반복 실행은 setInterval이다. |
| 19 | setInterval | 멈추려면 clearInterval을 쓴다. |
| 20 | 1, 3, 2 | setTimeout 콜백은 Task Queue에서 대기하다 Call Stack이 비면 실행된다. |
| 21 | 이벤트 루프(Event Loop) | 그래서 비동기 콜백은 나중에 실행된다. |
| 22 | 컴포넌트 | 컴포넌트를 나누면 재사용과 관리가 쉽다. |
| 23 | JSX | `{}` 안에서 JavaScript 표현식을 쓸 수 있다. |
| 24 | ReactDOM.createRoot() | 그 영역에 표시하는 것은 render()이다. |
| 25 | Props | 자식은 읽기만 하고 직접 변경하지 않는다. |
| 26 | State | State는 내가 관리하는 값, Props는 외부에서 전달받는 값이다. |
| 27 | 리렌더링(Rerender) | 변경된 State로 JSX가 다시 계산된다. |
| 28 | 렌더링할 때 바로 | 클릭 시 실행하려면 `onClick={handleEnter}`처럼 함수 자체를 전달한다. |
| 29 | Controlled Input | State가 Input의 값을 관리한다. |
| 30 | value | e.target은 input 요소, e.target.value는 현재 입력값이다. |
| 31 | { username: '영동', email: 'b@b.com' } | ...form은 기존 값을 복사하고 email만 덮어쓴다. |
| 32 | 계산된 속성명 | name이 'email'이면 `email: value`가 된다. |
| 33 | [1, 3] | 삭제할 항목을 제외한 새 배열을 만드는 방식이다. |
| 34 | key | 보통 객체의 고유한 id를 쓰며 화면에는 표시되지 않는다. |
| 35 | useEffect | 화면을 그리는 코드가 아니라 화면이 그려진 뒤 실행할 작업이다. |
| 36 | 처음 화면에 나타날 때 한 번 | 빈 의존성 배열은 의존하는 값이 없어 Mount 때만 실행된다. |
| 37 | 처음 실행 + count가 변경될 때 | 의존성 배열의 값이 바뀔 때 다시 실행된다. |
| 38 | Cleanup 함수 | 타이머 등을 정리할 때 사용한다. |
| 39 | 조건부 렌더링 | showTimer가 true일 때만 Timer가 표시된다. |
