# 1주차 중간평가 대비 문제

범위: CSS(최소), 변수·스코프, 타입·변환, 연산자, 조건·반복, 객체·prototype, 함수·콜백, 배열·문자열, 화살표 함수, 클래스, Spread/Rest

- 유형: [개념] 설명을 보고 개념 이름 맞추기 / [단답] 짧은 코드 결과 쓰기·빈칸 채우기

# 문제

**1.** [개념] 요소의 내용과 테두리 사이의 안쪽 여백을 만드는 CSS 속성은?

**2.** [개념] width/height 안에 padding과 border까지 포함해서 크기를 계산하게 하는 box-sizing 값은?

**3.** [개념] 재할당이 불가능하고 선언과 동시에 초기화해야 하는 변수 선언 키워드는?

**4.** [개념] 블록 `{}`이 아니라 함수 단위로 스코프가 정해지는 변수 선언 키워드는?

**5.** [개념] `{}` 블록 안에서 let/const로 선언한 변수를 블록 밖에서 쓸 수 없게 하는 스코프 규칙은?

**6.** [단답] 출력 결과는?

```js
function test() {
    console.log(status);
    var status = '완료';
}
test();
```

**7.** [단답] 결과는?

```js
console.log('5' + 1);
```

**8.** [개념] 조건문에서 false로 평가되는 값(false, 0, '', null, undefined, NaN)을 통틀어 부르는 말은?

**9.** [개념] 논리 연산에서 결과가 이미 결정되면 나머지 값을 확인하지 않는 동작은?

**10.** [단답] 결과는?

```js
console.log(0 || 10);
```

**11.** [단답] 결과는?

```js
console.log(0 ?? 10);
```

**12.** [개념] `user.address?.city`처럼, 왼쪽이 null/undefined이면 에러 없이 undefined를 반환하는 연산자는?

**13.** [개념] `조건 ? 참일 때 값 : 거짓일 때 값` 형태의 간단한 조건 연산자는?

**14.** [개념] 반복문에서 현재 반복만 건너뛰고 다음 반복을 계속 진행하게 하는 키워드는?

**15.** [단답] 출력되는 값은?

```js
for (let i = 1; i <= 5; i++) {
    if (i === 3) break;
    console.log(i);
}
```

**16.** [개념] 조건과 관계없이 코드를 최소 한 번은 실행한 뒤 조건을 확인하는 반복문은?

**17.** [개념] 객체의 프로퍼티 키를 하나씩 가져오는 반복문은?

**18.** [개념] 생성자 함수 안에서 새로 만들어지는 객체를 가리키는 키워드는?

**19.** [개념] 생성자 함수를 호출해 새로운 객체를 만들 때 앞에 붙이는 키워드는?

**20.** [개념] 객체에 없는 속성이나 메서드를 연결된 부모 쪽에서 찾아보는 구조는?

**21.** [개념] 함수가 호출된 위치가 아니라 정의된 위치를 기준으로 변수를 찾는 규칙은?

**22.** [개념] 다른 함수에 전달되어 필요한 시점에 실행되는 함수는?

**23.** [개념] 함수를 매개변수로 받거나 함수를 반환하는 함수는?

**24.** [단답] 결과는?

```js
console.log([1, 2, 3].map(x => x * 2));
```

**25.** [단답] 출력 결과는?

```js
const r = [1, 2, 3].forEach(x => x * 2);
console.log(r);
```

**26.** [단답] 결과는?

```js
console.log([5, 10, 15].filter(x => x > 7));
```

**27.** [개념] 조건에 맞는 첫 번째 요소 하나만 반환하는 배열 메서드는?

**28.** [개념] 배열의 요소 중 하나라도 조건에 맞으면 true를 반환하는 메서드는?

**29.** [개념] 배열의 모든 요소가 조건에 맞아야 true를 반환하는 메서드는?

**30.** [단답] 내림차순 정렬이 되도록 빈칸을 채우시오.

```js
[30, 10, 20].sort((a, b) => ______);
```

**31.** [단답] 결과는?

```js
console.log([10, 20, 30, 40, 50].slice(1, 4));
```

**32.** [단답] 결과는?

```js
console.log([10, 20, 30].reduce((sum, cur) => sum + cur, 0));
```

**33.** [개념] `.filter().sort().map()`처럼 메서드를 이어서 쓰는 방식은?

**34.** [단답] 출력 결과는?

```js
const f = x => { x * 2 };
console.log(f(3));
```

**35.** [개념] 화살표 함수에서 객체를 바로 반환할 때 `{ }` 바깥을 감싸는 기호는?

**36.** [개념] 객체를 만들기 위한 설계도 역할을 하며 `constructor`와 메서드를 가지는 문법은?

**37.** [단답] 빈칸에 들어갈 키워드는?

```js
class Person {
    ______(name) { this.name = name; }
}
```

**38.** [개념] `...`로 배열 등을 하나씩 펼쳐 주는 문법은?

**39.** [개념] 함수 매개변수에서 `...args`로 전달된 여러 값을 하나의 배열로 모으는 문법은?

**40.** [단답] 결과는?

```js
console.log([...[1, 2], ...[3, 4]]);
```

# 정답

| 번호 | 정답 | 해설 |
|---|---|---|
| 1 | padding | padding은 안쪽 여백, margin은 바깥 여백이다. |
| 2 | border-box | border-box는 padding과 border를 width/height에 포함해 계산한다. |
| 3 | const | const는 값을 다시 할당할 수 없다. |
| 4 | var | var는 블록을 벗어나도 쓸 수 있고 함수 밖으로만 못 나간다. |
| 5 | 블록 스코프 | let/const는 `{}` 기준으로 사용 범위가 정해진다. |
| 6 | undefined | var는 선언이 끌어올려져(호이스팅) 선언 전에 써도 undefined이다. |
| 7 | '51' | + 연산자에 문자열이 포함되면 문자열 연결로 동작해 숫자 1이 문자열로 변환된다. |
| 8 | Falsy | 그 외 대부분의 값은 Truthy이다. |
| 9 | 단축 평가 | &&, \|\|는 상황에 따라 실제 값을 반환한다. |
| 10 | 10 | \|\|는 왼쪽이 falsy(0)이면 오른쪽 값을 쓴다. |
| 11 | 0 | ??는 null/undefined일 때만 오른쪽을 쓰므로 0이 그대로 나온다. |
| 12 | 옵셔널 체이닝(?.) | 값이 있으면 속성에 접근하고 없으면 undefined로 끝난다. |
| 13 | 삼항 연산자 | 조건에 따라 두 값 중 하나를 선택한다. |
| 14 | continue | break는 반복문 전체를 종료한다. |
| 15 | 1, 2 | i가 3일 때 break로 반복문이 종료된다. |
| 16 | do...while | while은 조건을 먼저 확인한다. |
| 17 | for...in | `객체[key]`로 값에 접근할 수 있다. |
| 18 | this | `this.이름 = 이름`은 새 객체에 속성을 만든다. |
| 19 | new | `new 학생('영동', 30)`처럼 객체를 생성한다. |
| 20 | 프로토타입(prototype) | prototype에 둔 메서드는 여러 객체가 공유한다. |
| 21 | 렉시컬 스코프 | 함수는 자신이 선언된 위치의 바깥 스코프에서 변수를 찾는다. |
| 22 | 콜백 함수 | `manager(sayHello, 3)`에서 sayHello가 콜백이다. |
| 23 | 고차 함수 | 고차 함수에 전달되는 함수가 콜백 함수이다. |
| 24 | [2, 4, 6] | map은 각 요소를 가공해 새 배열을 반환한다. |
| 25 | undefined | forEach의 반환값은 항상 undefined이다. |
| 26 | [10, 15] | filter는 조건이 true인 요소만 새 배열로 반환한다. |
| 27 | find | 못 찾으면 undefined를 반환한다. |
| 28 | some | 모든 요소가 맞아야 true인 것은 every이다. |
| 29 | every | 하나라도 맞으면 true인 것은 some이다. |
| 30 | b - a | 오름차순은 a - b, 내림차순은 b - a이다. |
| 31 | [20, 30, 40] | 인덱스는 0부터 시작하고, slice의 끝 번호(4)는 포함하지 않는다. |
| 32 | 60 | 0부터 시작해 10, 30, 60으로 누적된다. |
| 33 | 메서드 체이닝 | 앞 메서드가 반환한 값을 뒤 메서드가 사용할 수 있어야 한다. |
| 34 | undefined | 중괄호를 쓰면 return을 직접 써야 한다. |
| 35 | 소괄호 ( ) | 중괄호가 함수 코드 블록으로 해석되는 것을 막는다. |
| 36 | 클래스(class) | 생성자 함수와 비슷한 역할이며 `new`로 객체를 만든다. |
| 37 | constructor | constructor는 `new`로 객체를 만들 때 실행되는 초기화 메서드이다. |
| 38 | Spread | Rest는 반대로 여러 값을 배열로 모은다. |
| 39 | Rest | Spread는 펼치기, Rest는 모으기이다. |
| 40 | [1, 2, 3, 4] | 두 배열을 펼쳐서 새 배열로 합친다. |
