# 문제

**8.** [개념] 조건문에서 false로 취급되는 값(0, '', null, undefined, NaN 등)을 부르는 말은?

# 정답

| 번호 | 정답 | 해설 |
|---|---|---|
| 3 | const | const는 값을 다시 할당할 수 없다. |
| 4 | var | var는 블록을 벗어나도 쓸 수 있고 함수 밖으로만 못 나간다. |
| 5 | 블록 스코프 | let/const는 `{}` 기준으로 사용 범위가 정해진다. |
| 6 | undefined | var는 선언이 끌어올려져(호이스팅) 선언 전에 써도 undefined이다. |
| 7 | '51' | + 연산자에 문자열이 포함되면 문자열 연결로 동작해 숫자 1이 문자열로 변환된다. |
| 8 | Falsy | 그 외 대부분의 값은 Truthy이다. |
| 9 | 단축 평가 | &&, \|\|는 상황에 따라 실제 값을 반환한다. |
| 10 | 10 | \|\|는 왼쪽이 falsy(0)이면 오른쪽 값을 쓴다. |
| 11 | 0 | ??는 null/undefined일 때만 오른쪽을 쓰므로 0이 그대로 나온다. |
| 12 | 옵셔널 체이닝(?.) | 왼쪽이 null/undefined면 에러 없이 undefined를 반환한다. |
| 13 | 삼항 연산자 | 조건에 따라 두 값 중 하나를 선택한다. |
| 14 | continue | break는 반복문 전체를 종료한다. |
| 15 | 1, 2 | i가 3일 때 break로 반복문이 종료된다. |
| 16 | ③ do...while | while은 조건을 먼저 확인한다. |
| 17 | for...in | `객체[key]`로 값에 접근할 수 있다. |
| 18 | this | `this.이름 = 이름`은 새 객체에 속성을 만든다. |
| 19 | new | `new 학생('영동', 30)`처럼 객체를 생성한다. |
| 20 | 프로토타입(prototype) | prototype에 둔 메서드는 여러 객체가 공유한다. |
| 21 | 렉시컬 스코프 | 함수는 자신이 선언된 위치의 바깥 스코프에서 변수를 찾는다. |
| 22 | 콜백 함수 | `manager(sayHello, 3)`에서 sayHello가 콜백이다. |
| 23 | 고차 함수 | 고차 함수에 전달되는 함수가 콜백 함수이다. |
| 24 | [2, 4, 6] | map은 각 요소를 가공해 새 배열을 반환한다. |
| 25 | undefined | forEach의 반환값은 항상 undefined이다. |
| 26 | [10, 15] | filter는 조건이 true인 요소만 새 배열로 반환한다. |
| 27 | ① find | 못 찾으면 undefined를 반환한다. |
| 28 | some | 모든 요소가 맞아야 true인 것은 every이다. |
| 29 | every | 하나라도 맞으면 true인 것은 some이다. |
| 30 | b - a | 오름차순은 a - b, 내림차순은 b - a이다. |
| 31 | [20, 30, 40] | 인덱스는 0부터 시작하고, slice의 끝 번호(4)는 포함하지 않는다. |
| 32 | 60 | 0부터 시작해 10, 30, 60으로 누적된다. |
| 33 | 메서드 체이닝 | 앞 메서드가 반환한 값을 뒤 메서드가 사용할 수 있어야 한다. |
| 34 | undefined | 중괄호를 쓰면 return을 직접 써야 한다. |
| 35 | 소괄호 ( ) | 중괄호가 함수 코드 블록으로 해석되는 것을 막는다. |
| 36 | 클래스(class) | 생성자 함수와 비슷한 역할이며 `new`로 객체를 만든다. |
| 37 | constructor | constructor는 `new`로 객체를 만들 때 실행되는 초기화 메서드이다. |
| 38 | Spread | Rest는 반대로 여러 값을 배열로 모은다. |
| 39 | Rest | Spread는 펼치기, Rest는 모으기이다. |
| 40 | [1, 2, 3, 4] | 두 배열을 펼쳐서 새 배열로 합친다. |
