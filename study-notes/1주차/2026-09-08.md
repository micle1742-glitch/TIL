**## 오늘 배운 내용**

**### 1. 함수(Function)**

함수는 특정 작업을 하나의 코드 묶음으로 만들어 필요할 때 실행할 수 있는 기능이다.

같은 작업을 여러 번 작성하지 않고 함수로 만들어 재사용할 수 있다.

**#### 함수 선언**

함수는 `function` 키워드를 사용하여 선언할 수 있다.

```javascript
function hello() {
    console.log('안녕하세요');
}
```

함수를 실행하려면 함수 이름 뒤에 `()`를 사용한다.

```javascript
hello();
```

---

**### 2. 매개변수(Parameter)와 인수(Argument)**

함수는 외부에서 값을 전달받아 사용할 수 있다.

**#### 매개변수**

함수를 선언할 때 값을 전달받기 위해 사용하는 변수를 매개변수라고 한다.

```javascript
function hello(name) {
    console.log(name);
}
```

여기서 `name`은 매개변수이다.

**#### 인수**

함수를 호출할 때 전달하는 실제 값을 인수라고 한다.

```javascript
hello('홍길동');
```

여기서 `'홍길동'`은 인수이다.

---

**### 3. return**

`return`은 함수의 실행 결과를 함수 밖으로 반환할 때 사용한다.

```javascript
function multiply(a, b) {
    return a * b;
}

console.log(multiply(2, 3));
```

`return`을 만나면 값을 반환하고 함수의 실행이 종료된다.

반환된 값은 변수에 저장하거나 다른 계산에 사용할 수 있다.

---

**### 4. 함수 호이스팅(Hoisting)**

함수 선언문은 함수를 선언하기 전에 호출할 수 있다.

```javascript
console.log(hello('홍길동'));

function hello(name) {
    return `${name} 안녕?`;
}
```

이를 함수 호이스팅이라고 한다.

---

**### 5. 함수 표현식**

함수도 하나의 값처럼 변수에 저장할 수 있다.

```javascript
const sayHello = function() {
    console.log('안녕하세요');
};
```

변수에 저장된 함수는 함수 이름처럼 호출할 수 있다.

```javascript
sayHello();
```

함수의 자료형은 `function`이다.

```javascript
console.log(typeof sayHello);
```

---

**### 함수 선언문과 함수 표현식**

**함수 선언문**

```javascript
function hello() {
    console.log('안녕하세요');
}
```

\- `function`을 사용하여 함수를 선언

\- 선언하기 전에 호출 가능

**함수 표현식**

```javascript
const hello = function() {
    console.log('안녕하세요');
};
```

\- 함수를 변수에 저장

\- 함수도 하나의 값처럼 사용할 수 있음

---

**### 6. 함수도 값이다**

JavaScript에서 함수는 하나의 값처럼 사용할 수 있다.

따라서 함수는:

\- 변수에 저장 가능

\- 다른 함수에 전달 가능

\- 함수의 반환값으로 사용할 수 있음

**#### 함수 이름과 함수 호출의 차이**

```javascript
sayHello
```

\- 함수 자체를 의미

\- 다른 함수에 전달할 때 사용 가능

```javascript
sayHello()
```

\- 함수를 즉시 실행

---

**### 7. 콜백 함수(Callback Function)**

콜백 함수는 다른 함수에 전달하여 필요한 시점에 실행하는 함수이다.

```javascript
function manager(task, count) {

    for (let i = 0; i < count; i++) {
        task();
    }
}
```

함수를 호출할 때 다른 함수를 전달할 수 있다.

```javascript
manager(sayHello, 3);
```

여기서:

\- `manager` : 다른 함수를 전달받는 함수

\- `sayHello` : 전달되는 콜백 함수

\- `3` : 반복 횟수

`task()`를 실행하면 전달받은 함수가 실행된다.

---

**### 콜백 함수의 특징**

콜백 함수를 전달할 때는 `()`를 사용하지 않는다.

```javascript
manager(sayHello, 3);
```

`sayHello`는 함수 자체를 전달한다.

반면:

```javascript
sayHello();
```

는 함수를 즉시 실행한다.

---

**### 8. 고차 함수(Higher-order Function)**

고차 함수는 함수를 매개변수로 받거나 함수를 반환하는 함수이다.

```javascript
function calculator(callback, a, b) {

    const result = callback(a, b);

    return result;
}
```

계산 방식은 외부에서 전달받은 함수가 결정할 수 있다.

```javascript
function add(a, b) {
    return a + b;
}

function multiply(a, b) {
    return a * b;
}
```

같은 고차 함수에 다른 함수를 전달하여 사용할 수 있다.

```javascript
calculator(add, 9, 8);

calculator(multiply, 9, 8);
```

---

**### 고차 함수와 콜백 함수**

\- 고차 함수 : 함수를 매개변수로 받거나 반환하는 함수

\- 콜백 함수 : 고차 함수에 전달되는 함수

예시:

```javascript
calculator(add, 9, 8);
```

\- `calculator` : 고차 함수

\- `add` : 콜백 함수

---

**### 9. 함수 반환**

함수는 값을 반환할 수도 있고 다른 함수를 반환할 수도 있다.

```javascript
function manager() {

    return function() {
        console.log('모든 업무가 완료되었습니다');
    };
}
```

반환된 함수는 변수에 저장하여 실행할 수 있다.

```javascript
const report = manager();

report();
```

---

**### 10. 스코프(Scope)**

스코프는 변수에 접근하거나 사용할 수 있는 범위를 의미한다.

변수는 선언된 위치에 따라 사용할 수 있는 범위가 달라진다.

---

**### 블록 스코프(Block Scope)**

`{}` 블록 안에서 `let` 또는 `const`로 선언한 변수는 블록 밖에서 사용할 수 없다.

```javascript
const outerValue = '바깥쪽 값';

if (true) {

    const blockValue = '블록 안의 값';

    console.log(blockValue);

    console.log(outerValue);
}

console.log(blockValue);
```

`blockValue`는 블록 내부에서만 사용할 수 있다.

반면 바깥쪽에서 선언한 `outerValue`는 블록 안에서도 사용할 수 있다.

---

**### 스코프의 특징**

\- 안쪽에서는 바깥쪽 변수를 사용할 수 있음

\- 바깥쪽에서는 안쪽 변수를 사용할 수 없음

\- 변수의 선언 위치에 따라 사용할 수 있는 범위가 결정됨

---

**### 11. 렉시컬 스코프(Lexical Scope)**

JavaScript의 함수는 호출된 위치가 아니라 함수가 정의된 위치를 기준으로 변수를 찾는다.

```javascript
const label = '바깥';

function printLabel() {
    console.log(label);
}

function run() {

    const label = 'run 안쪽';

    printLabel();
}

run();
```

출력 결과:

```text
바깥
```

`printLabel()`은 `run()` 안에서 호출되었지만 `printLabel`이 정의된 위치의 바깥쪽 변수인 `'바깥'`을 찾는다.

---

**### 렉시컬 스코프 특징**

\- 함수는 자신이 선언된 위치를 기준으로 변수를 찾음

\- 함수가 어디에서 호출되었는지는 변수 탐색에 영향을 주지 않음

\- 현재 함수 내부에 변수가 없으면 바깥쪽 스코프에서 변수를 찾음

---

# JavaScript 나만의 정리

## 1. 함수 Function

```javascript
function add(a, b) {
    return a + b;
}

console.log(add(3, 5));
```

- `function` → 함수 만들기
- `a`, `b` → 파라미터(매개변수)
- `3`, `5` → 인자(Argument)
- `return` → 결과를 밖으로 반환

### 파라미터

```javascript
function add(a, b) {
    return a + b;
}
```

`a`, `b` = 값을 받는 자리

호출할 때:

```javascript
add(3, 5);
```

실제로:

```text
a = 3
b = 5
```

---

## 2. return

```javascript
function add(a, b) {
    return a + b;
}
```

`return`은 결과를 함수 밖으로 돌려준다.

```javascript
const result = add(3, 5);

console.log(result);
```

결과:

```text
8
```

### return을 만나면 함수는 끝난다

```javascript
function test() {
    return 10;

    console.log('실행 안 됨');
}
```

---

## 3. 함수 표현식

```javascript
const add = function(a, b) {
    return a + b;
};
```

함수를 변수에 저장할 수 있다.

### 함수 이름 생략 가능

```javascript
const add = function(a, b) {
    return a + b;
};
```

`function` 뒤에 이름이 없는 것을 **익명 함수**라고 한다.

```text
함수 선언문 → 함수 이름 필요

함수 표현식 → 함수 이름 생략 가능
```

---

## 4. 함수도 return 가능

```javascript
function first() {
    return function() {
        console.log('안녕');
    };
}
```

함수는 숫자나 문자열뿐만 아니라 **함수도 반환할 수 있다.**

```javascript
const result = first();

result();
```

흐름:

```text
first()
↓
함수 반환
↓
result에 함수 저장
↓
result() 실행
```

---

## 5. 콜백 함수

함수를 다른 함수의 파라미터로 전달하는 것.

```javascript
function first(callback) {
    callback();
}

function second() {
    console.log('안녕');
}

first(second);
```

```text
second 함수를
↓
first에 전달
↓
callback()으로 실행
```

# 6. 스코프 Scope

```text
스코프 = 변수를 사용할 수 있는 범위
```

### 안에서는 밖을 볼 수 있음

```javascript
const outside = '밖';

function test() {
    console.log(outside);
}
```

⭕ 가능

### 밖에서는 안을 볼 수 없음

```javascript
function test() {
    const inside = '안';
}

console.log(inside);
```

❌ 불가능

### 쉽게 기억

```text
안 → 밖을 볼 수 있음 ⭕
밖 → 안을 볼 수 없음 ❌
```

# 7. const / let / var

## const

```javascript
const name = '영동';
```

- 재할당 ❌
- 블록 스코프 `{}`

## let

```javascript
let count = 0;

count = 1;
```

- 재할당 ⭕
- 블록 스코프 `{}`

## var

```javascript
if (true) {
    var name = '영동';
}

console.log(name);
```

⭕ 가능

`var`는 `{}` 블록을 벗어나도 사용할 수 있다.

하지만 함수 밖으로는 못 나간다.

```javascript
function test() {
    var name = '영동';
}

console.log(name); // ❌
```

### 쉽게 기억

```text
let / const → {} 기준

var → 함수 기준
```

# 8. 호이스팅 Hoisting

```javascript
function test() {
    console.log(status);

    var status = '완료';
}
```

결과:

```text
undefined
```

자바스크립트가 대충 이렇게 처리하는 것처럼 생각하면 된다.

```javascript
function test() {
    var status;

    console.log(status);

    status = '완료';
}
```

### const / let이라면

```javascript
console.log(status);

const status = '완료';
```

❌ 에러 발생

```text
var → 선언 전에 사용하면 undefined

let / const → 선언 전에 사용하면 에러
```

# 10. 템플릿 리터럴 ${}

문자열 안에 변수나 계산 결과를 넣을 때 사용한다.

```javascript
const 이름 = '영동';

console.log(`안녕하세요 ${이름}님`);
```

결과:

```text
안녕하세요 영동님
```

⚠️ **백틱(`)을 사용해야 한다.**

```javascript
`안녕하세요 ${이름}님`
```

# 11. document

```javascript
document.getElementById('open');
```

JavaScript가 **HTML 요소를 찾고 조작하기 위해 사용한다.**

HTML:

```html
<button id="open">열기</button>
```

JavaScript:

```javascript
document.getElementById('open');
```

뜻:

```text
HTML 전체(document)
↓
id가 open인 요소 찾기
↓
JavaScript로 조작
```

예시:

```javascript
document.getElementById('alert').style.display = 'block';
```

```text
alert라는 HTML 요소를 찾아서
↓
화면에 보여주기
```
