# 1. HTML(HyperText Markup Language)이란?

## 1-1. 개요

- HTML은 웹 페이지를 작성하는 표준 마크업 언어
- 웹 페이지의 **구조와 콘텐츠**를 정의
- 태그(Tag)를 사용하여 텍스트, 이미지, 링크 등을 구성

## 1-2. HTML 구성요소

- **태그(Tag)** : HTML 명령을 나타내는 표시
- **요소(Element)** : 시작 태그와 종료 태그를 포함한 전체 구성
- **속성(Attribute)** : 태그에 추가 정보를 제공
- **값(Value)** : 속성에 설정하는 값

# 2. HTML
## 01. HTML 기본 구조와 글자·목록

### HTML 글자 태그

- `<h1> ~ <h6>` : 제목 태그 (h1이 가장 큼)
- `<p>` : 문단
- `<br>` : 줄바꿈
- `<hr>` : 가로줄
- `<pre>` : 작성한 형태 그대로 표시

### 글자 강조 태그

- `<b>` : 굵은 글씨
- `<strong>` : 중요한 내용 강조
- `<i>` : 기울임 글씨
- `<em>` : 강조하고 싶은 내용
- `<mark>` : 형광펜 효과
- `<del>` : 삭제된 내용 표시

## 02. HTML 표와 미디어

### 목록 태그

- `<ul>` : 순서 없는 목록
- `<ol>` : 순서 있는 목록
- `<li>` : 목록 항목

### Emmet

- `ol>li*4` : ol 안에 li 태그 4개 생성

## 03. HTML 링크와 폼

### 하이퍼링크

- `<a>` : 다른 페이지나 웹사이트로 이동하는 링크
- `href` : 이동할 주소 또는 파일 경로
- `target="_blank"` : 새 탭에서 열기
- `href="#id"` : 같은 페이지 내부의 특정 위치로 이동

### 폼(Form)

- `<form>` : 사용자 입력 데이터를 서버로 전달
- `action` : 데이터를 보낼 위치
- `method` : 데이터 전송 방식

## 04. HTML 레이아웃과 시맨틱 태그

### 입력 태그

- `<input type="text">` : 텍스트 입력
- `password` : 비밀번호 입력
- `number` : 숫자 입력
- `radio` : 하나만 선택
- `checkbox` : 여러 개 선택 가능
- `placeholder` : 입력 안내 문구
- `required` : 필수 입력

### 기타 폼 태그

- `<label>` : 입력 항목 설명
- `<select>` : 드롭다운 목록
- `<option>` : 선택 항목
- `<textarea>` : 여러 줄 입력
- `<button type="submit">` : 제출
- `<button type="reset">` : 입력 내용 초기화
- `<fieldset>` : 폼 항목 묶기
- `<legend>` : 폼 그룹 제목


### div와 span

- `<div>` : 블록 레벨 요소, 한 줄 전체를 차지하며 영역을 나눔
- `<span>` : 인라인 요소, 콘텐츠 크기만큼 공간을 차지

### 시맨틱 태그

- 의미를 담아 웹 페이지의 영역을 나누는 태그

- `<header>` : 페이지의 머리말 (로고, 제목, 메뉴)
- `<nav>` : 페이지 이동 메뉴
- `<main>` : 문서의 핵심 내용
- `<section>` : 관련된 내용을 하나의 영역으로 구분
- `<footer>` : 페이지의 하단 영역

# 3. CSS 선택자

## CSS 기본 문법

선택자 {
    속성: 값;
}

## 선택자 종류

- **태그 선택자** : HTML 태그 이름을 그대로 사용
- **클래스 선택자** : `.클래스이름`으로 선택
- **아이디 선택자** : `#아이디이름`으로 선택
- **후손 선택자** : `부모 자식` → 특정 요소 안의 모든 후손 선택
- **자식 선택자** : `부모 > 자식` → 바로 아래 자식만 선택
- **속성 선택자** : `[속성]` 또는 `[속성="값"]`을 가진 요소 선택
- **인접 형제 선택자** : `요소 + 요소` → 바로 뒤에 이어지는 형제 요소 선택
