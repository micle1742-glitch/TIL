---

## Git 핵심 요약

## 1. 기본 커밋 & 조회
- `git status` : 현재 작업 상태 확인
- `git add <file|.>` : Staging Area에 파일 추가
- `git commit -m "메시지"` : 커밋 생성
- `git log --oneline` : 커밋 내역 한 줄로 조회
- `git revert <커밋해시>` : 이전 커밋을 취소하는 새 커밋 생성

## 2. 원격 저장소 (GitHub)
- `git remote add origin <URL>` : 원격 저장소 연결
- `git remote -v` : 연결된 원격 저장소 확인
- `git push -u origin main` : 원격 저장소에 업로드
- `git pull origin main` : 원격 저장소 내용 내려받기

## 3. 브랜치 (Branch)
- `git branch` : 브랜치 목록 확인
- `git switch <브랜치명>` : 지정 브랜치로 이동
- `git switch -c <브랜치명>` : 브랜치 생성과 동시에 이동
- `git merge <브랜치명>` : 현재 브랜치로 대상 브랜치 병합

## 4. 충돌(Conflict) 해결
1. `git merge <브랜치명>` 실행 시 충돌 발생
2. 충돌 파일 열어 직접 코드 수정 및 저장
3. `git add .` 실행
4. `git commit -m "충돌해결"` 로 마무리

## 5. Git 기능 브랜치 작업 & 원격 푸시 요약

1. **새 브랜치 생성 및 이동**
   - `git switch -c feature/my-name`

2. **작업 내용 저장 (Staging & Commit)**
   - `git add .`
   - `git commit -m "조영동"`

3. **원격 저장소(GitHub)에 브랜치 푸시**
   - `git push origin feature/my-name
   - *푸시 완료 후 출력되는 GitHub URL을 통해 Pull Request(PR)를 생성할 수 있습니다.*
