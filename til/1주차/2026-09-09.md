# JavaScript 오늘 공부 정리

## 1. 옵셔널 체이닝 연산자 `?.`

```js
객체?.속성
```

- 왼쪽 값이 `null` 또는 `undefined`이면 에러를 내지 않고 `undefined`를 반환함.
- 값이 있으면 오른쪽 속성으로 접근함.

예:

```js
user2.address?.city
```

`user2.address`가 `undefined`라면

```text
undefined
```

가 나옴.

### 기억하기

`?.` = **앞에 값이 없으면 undefined로 끝내고, 있으면 속성에 접근**


---

## 2. null 병합 연산자 `??`

```js
왼쪽값 ?? 오른쪽값
```

- 왼쪽 값이 `null` 또는 `undefined`일 때만 오른쪽 값을 사용함.
- `null`, `undefined`가 아니면 왼쪽 값을 그대로 사용함.

```js
null ?? 10        // 10
undefined ?? 10   // 10
0 ?? 10           // 0
'' ?? 10          // ''
false ?? 10       // false
```

### 기억하기

`??` = **진짜 값이 없을 때(null / undefined)만 대신 넣기**


---

## 3. `||` 연산자

`||`는 `??`보다 범위가 넓음.

왼쪽이 **falsy 값**이면 오른쪽 값을 사용함.

```js
'' || '기본값'       // '기본값'
0 || 10             // 10
false || true       // true
null || '기본값'    // '기본값'
undefined || 10     // 10
```

### `??`와 차이

```js
'' ?? '기본값'   // ''
'' || '기본값'   // '기본값'

0 ?? 10         // 0
0 || 10         // 10
```

### 기억하기

```text
?? → null / undefined만 없다고 판단
|| → '', 0, false 등 falsy도 없다고 판단
```

# 4. 객체(Object)

객체는 여러 정보를 `키 : 값` 형태로 저장함.

```js
const 학생 = {
    이름: '영동',
    나이: 30
};
```

여기서

```text
이름 → 키(key)
'영동' → 값(value)

나이 → 키(key)
30 → 값(value)
```

### 왜 앞에 키, 뒤에 값?

`키 : 값` 형태로 정해져 있기 때문.

쉽게 생각하면:

```text
이름이라는 이름표 → 영동이라는 내용
나이라는 이름표 → 30이라는 내용
```


---

# 5. 객체의 값 가져오기

## 방법 1. 점 표기법

```js
학생.이름
```

결과:

```text
영동
```

## 방법 2. 대괄호 표기법

```js
학생['이름']
```

결과:

```text
영동
```

### 기억하기

```js
학생.이름
학생['이름']
```

두 가지 방법이 있음.

# 6. 메서드(Method)

**객체 안에 들어있는 함수 = 메서드**

예:

```js
const 학생 = {
    이름: '영동',

    인사하기: function() {
        console.log('안녕하세요');
    }
};
```

여기서

```text
인사하기 → 메서드
function() → 함수
```

사용:

```js
학생.인사하기();
```

메서드에서도 매개변수와 `return`을 사용할 수 있음.

```js
const 계산기 = {
    더하기: function(숫자1, 숫자2) {
        return 숫자1 + 숫자2;
    }
};

console.log(계산기.더하기(10, 20));
```

결과:

```text
30
```

# 7. 생성자 함수

생성자 함수는 **객체를 여러 개 만들 때 사용하는 함수**.

객체를 하나하나 직접 만들면 귀찮기 때문에 틀을 만들어 놓고 `new`로 여러 객체를 만들 수 있음.

```js
function 학생(이름, 나이) {
    this.이름 = 이름;
    this.나이 = 나이;
}
```

여기서

```text
학생 → 생성자 함수
이름, 나이 → 매개변수
this.이름, this.나이 → 만들어지는 객체의 속성
```

객체 만들기:

```js
const 학생1 = new 학생('영동', 30);
const 학생2 = new 학생('철수', 20);
```

이렇게 하면 학생 객체를 여러 개 만들 수 있음.

### `new`의 느낌

```js
new 학생('영동', 30)
```

→ 학생이라는 생성자 함수를 이용해서 **새로운 객체를 만들어줌**.


---

# 8. `this`

생성자 함수에서 `this`는 **새로 만들어지는 객체**를 가리킴.

```js
function 학생(이름, 나이) {
    this.이름 = 이름;
    this.나이 = 나이;
}
```

```js
const 학생1 = new 학생('영동', 30);
```

그러면 대략 이런 느낌:

```text
학생1
 ├─ 이름: 영동
 └─ 나이: 30
```

즉,

```js
this.이름 = 이름;
```

은

> 새로 만들어진 객체에 `이름`이라는 속성을 만들고 매개변수로 받은 이름을 넣는다.

라는 뜻.


---

# 9. Prototype(프로토타입)

프로토타입은 **객체에 없는 속성이나 메서드를 찾을 때 연결된 곳에서 찾아보는 구조**.

쉽게 기억:

> 프로토타입 = **없는 값을 부모 쪽에서 찾아보는 연결**

생성자 함수에서 사용:

```js
function 학생(이름, 나이) {
    this.이름 = 이름;
    this.나이 = 나이;
}

학생.prototype.getInfo = function() {
    return `${this.이름}는 ${this.나이}세입니다.`;
};
```

객체 생성:

```js
const 학생1 = new 학생('영동', 30);
const 학생2 = new 학생('철수', 20);
```

사용:

```js
console.log(학생1.getInfo());
console.log(학생2.getInfo());
```

`학생1` 자체에 `getInfo`가 없어도

```text
학생1
 ↓
학생.prototype
 ↓
getInfo 찾음
```

이런 식으로 찾아감.


---

# 10. Prototype을 사용하는 이유

메서드를 객체마다 새로 만들지 않고 **공유해서 사용할 수 있음**.

```js
학생.prototype.getInfo = function() {
    return `${this.이름}는 ${this.나이}세입니다.`;
};
```

학생1과 학생2가 같은 프로토타입의 `getInfo`를 사용할 수 있음.


---

# 11. `Object.hasOwn()`

```js
Object.hasOwn(객체, '속성명')
```

**그 객체가 해당 속성을 직접 가지고 있는지 확인**함.

예:

```js
Object.hasOwn(학생1, '이름')
```

→ `true`

하지만 `getInfo`가 prototype에 있다면:

```js
Object.hasOwn(학생1, 'getInfo')
```

→ `false`

왜냐하면 `학생1`이 직접 가지고 있는 게 아니라

```text
학생1
 ↓
학생.prototype
 ↓
getInfo
```

여기에 있기 때문.


---

# 12. `학생`과 `학생.prototype`은 다름

```js
function 학생() {}
```

여기서

```text
학생 → 생성자 함수
학생.prototype → 생성된 객체들이 사용할 프로토타입 객체
```

둘은 서로 다른 것임.

```js
학생.prototype.getInfo = function() {
    ...
};
```


---

# 13. `Object.getPrototypeOf()`

객체의 프로토타입을 확인할 수 있음.

```js
Object.getPrototypeOf(학생1)
```

그리고 비교:

```js
Object.getPrototypeOf(학생1) === 학생.prototype
```

결과:

```text
true
```

즉,

> 학생1의 프로토타입이 학생.prototype과 같은가?

를 확인하는 것.
