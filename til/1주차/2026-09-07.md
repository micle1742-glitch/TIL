## 오늘 배운 내용

### 1. 연산자

JavaScript에서 값을 계산하거나 비교할 때 사용하는 기능이다.

#### 산술 연산자

- `+` : 더하기
- `-` : 빼기
- `*` : 곱하기
- `/` : 나누기
- `%` : 나머지
- `**` : 거듭제곱

#### 할당 연산자

변수에 값을 저장하거나 계산한 값을 다시 저장할 때 사용한다.

- `=` : 값 할당
- `+=` : 기존 값에 더한 후 저장
- `-=` : 기존 값에서 뺀 후 저장

#### 증감 연산자

값을 1씩 증가하거나 감소시킬 때 사용한다.

- `++` : 1 증가
- `--` : 1 감소
- 전위 증감 : 값을 먼저 변경한 후 사용
- 후위 증감 : 현재 값을 먼저 사용한 후 변경

---

### 2. 비교 연산자

두 값을 비교하고 `true` 또는 `false`를 반환한다.

- `==` : 값 비교
- `!=` : 값이 다른지 비교
- `===` : 값과 타입까지 비교
- `!==` : 값 또는 타입이 다른지 비교
- `>` : 큼
- `<` : 작음
- `>=` : 크거나 같음
- `<=` : 작거나 같음

---

### 3. 논리 연산자

여러 조건을 함께 판단할 때 사용한다.

- `&&` : AND
- `||` : OR
- `!` : NOT

#### 단축 평가

논리 연산자를 확인하는 과정에서 결과가 이미 결정되면 나머지 값을 확인하지 않는 것을 단축 평가라고 한다.

논리 연산자는 항상 `true`, `false`만 반환하는 것이 아니라 상황에 따라 실제 값을 반환할 수도 있다.

---

### 4. 삼항 연산자

조건에 따라 두 값 중 하나를 선택하는 간단한 조건문이다.

- 조건이 참이면 첫 번째 값 선택
- 조건이 거짓이면 두 번째 값 선택

형식:

`조건 ? 참일 때 값 : 거짓일 때 값`

---

### 5. 조건문

조건에 따라 다른 코드를 실행할 때 사용한다.

#### if

조건이 참일 경우 코드를 실행한다.

#### else if

여러 조건을 추가로 확인할 때 사용한다.

#### else

앞의 모든 조건이 거짓일 경우 실행한다.

---

### 6. switch문

하나의 값을 여러 경우와 비교하여 다른 코드를 실행할 때 사용한다.

- `case` : 각각의 조건
- `break` : 실행 후 `switch`문 종료
- `default` : 해당하는 조건이 없을 때 실행

---

### 7. for문

정해진 조건 동안 코드를 반복 실행할 때 사용한다.

구성:

- 초기화 : 반복 변수의 시작값 설정
- 조건식 : 반복을 계속할지 결정
- 증감식 : 반복 변수의 값을 증가하거나 감소

실행 순서:

초기화 → 조건 확인 → 코드 실행 → 증감 → 다시 조건 확인

---

### 8. while문

조건이 참인 동안 계속 반복하는 반복문이다.

`for`문과 달리 반복 횟수가 정해져 있지 않을 때 사용할 수 있다.

조건이 계속 참이면 무한 반복이 될 수 있으므로 조건 변경이 중요하다.

---

### 9. 배열과 반복문

배열에 여러 개의 데이터를 저장할 수 있다.

- `length` : 배열에 들어있는 요소의 개수
- `배열[i]` : 배열의 특정 위치에 있는 요소

`for`문을 사용하면 배열의 요소를 처음부터 끝까지 하나씩 확인할 수 있다.

---

### 10. for문과 if문

`for`문과 `if`문을 함께 사용할 수 있다.

- `for`문 : 반복
- `if`문 : 조건 판단

반복하면서 특정 조건에 해당하는 값만 찾거나 출력할 수 있다.

---

## ⭐ 오늘 핵심 정리

- 산술 연산자 : 계산
- 할당 연산자 : 값 저장 및 변경

- 비교 연산자 : 두 값을 비교
- 논리 연산자 : 여러 조건 판단

## 오후 배운 내용

### 11. do...while문

`do...while`문은 코드를 먼저 실행한 후 조건을 확인하는 반복문이다.

#### 특징

- 조건과 관계없이 최소 한 번은 실행된다.
- 실행 후 조건을 확인한다.

#### while문과 차이

- `while`문 : 조건을 먼저 확인한 후 실행
- `do...while`문 : 코드를 먼저 실행한 후 조건 확인

---

### 12. break

`break`는 반복문을 즉시 종료할 때 사용한다.

- 특정 조건이 만족되면 반복문 전체를 종료한다.
- `break` 이후의 반복은 실행되지 않는다.

---

### 13. continue

`continue`는 현재 반복을 건너뛰고 다음 반복으로 넘어갈 때 사용한다.

- 반복문 자체는 종료되지 않는다.
- 현재 반복의 남은 코드를 건너뛴다.
- 다음 반복을 계속 실행한다.

#### break와 continue 차이

- `break` : 반복문 전체 종료
- `continue` : 현재 반복만 건너뛰고 다음 반복 진행

---

### 14. 중첩 반복문

반복문 안에 또 다른 반복문을 사용하는 것을 중첩 반복문이라고 한다.

#### 실행 방식

바깥쪽 반복문이 한 번 실행될 때 안쪽 반복문은 조건이 끝날 때까지 반복된다.

일반적으로:

- 바깥쪽 반복 변수 : `i`
- 안쪽 반복 변수 : `j`

를 사용한다.

#### 활용

- 구구단
- 표 형태의 데이터 출력
- 행과 열을 반복 처리할 때 사용

---

## 15. 객체(Object)

객체는 여러 개의 데이터를 하나로 묶어서 관리할 수 있는 데이터 구조이다.

객체는 여러 개의 프로퍼티(Property)로 구성된다.

---

### 프로퍼티(Property)

프로퍼티는 객체 안에 저장된 정보이다.

프로퍼티는 다음과 같이 구성된다.

- 키(Key) : 프로퍼티의 이름
- 값(Value) : 프로퍼티에 저장되는 값

객체 안에서 여러 프로퍼티는 `,`로 구분한다.

---

### 메서드(Method)

객체 내부에 있는 함수를 메서드라고 한다.

메서드는 객체의 데이터를 사용하거나 특정 동작을 수행할 수 있다.

객체 내부에서 자신의 프로퍼티에 접근할 때 `this`를 사용할 수 있다.

- `this` : 현재 객체 자신을 의미

---

### 프로퍼티 접근 방법

객체의 프로퍼티에 접근하는 방법은 두 가지가 있다.

#### 마침표 표기법

`객체.프로퍼티`

일반적인 프로퍼티 이름에 접근할 때 사용한다.

#### 대괄호 표기법

`객체['프로퍼티']`

- 프로퍼티 이름을 문자열로 작성한다.
- 특수문자가 포함된 프로퍼티에 접근할 수 있다.
- 숫자로 된 키에 접근할 수 있다.
- 변수에 저장된 값을 프로퍼티 이름으로 사용할 수 있다.

---

### 프로퍼티 생성(추가)

객체에 없는 프로퍼티에 값을 할당하면 새로운 프로퍼티가 생성된다.

- 마침표 표기법으로 추가 가능
- 대괄호 표기법으로 추가 가능

예시:

`dog.age = 3`

→ 객체에 `age` 프로퍼티가 새로 생성된다.

---

### 프로퍼티 변경

이미 존재하는 프로퍼티에 새로운 값을 할당하면 값이 변경된다.

예시:   

`dog.name = '초코'`

→ 기존 `name` 프로퍼티의 값이 `'초코'`로 변경된다.

---

### 프로퍼티 추가와 변경의 차이

- 존재하지 않는 프로퍼티에 값을 할당 → 프로퍼티 생성
- 이미 존재하는 프로퍼티에 값을 할당 → 프로퍼티 값 변경.

---

### 프로퍼티 삭제

`delete`를 사용하여 객체의 프로퍼티를 삭제할 수 있다.

---

### const 객체의 특징

`const`로 객체를 선언하면 객체 자체를 새로운 객체로 변경할 수 없다.

하지만 객체 내부의 프로퍼티는 변경할 수 있다.

- 객체 자체 재할당 ❌
- 프로퍼티 값 변경 ⭕
- 프로퍼티 추가 ⭕
- 프로퍼티 삭제 ⭕

---

### 프로퍼티 존재 확인

`in` 연산자를 사용하면 객체에 특정 프로퍼티가 존재하는지 확인할 수 있다.

결과는 `true` 또는 `false`로 반환된다.

---

### 객체순회 (for...in)

객체순회 `for...in`문은 객체의 프로퍼티를 하나씩 확인할 때 사용한다.


- 객체의 프로퍼티 키를 하나씩 가져온다.
- 가져온 키를 이용하여 객체의 값에 접근할 수 있다.
- 객체의 값을 가져올 때 `객체[key]` 형태를 사용할 수 있다.

---
