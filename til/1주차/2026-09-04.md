# 오늘 배운 CSS 정리

## 1. 글꼴과 글자 스타일

- `font-family` : 글꼴 변경
- `font-size` : 글자 크기 설정
- `font-weight` : 글자 굵기 설정
- `color` : 글자 색상 변경
- `line-height` : 글자 사이의 줄 간격 설정
- `text-align` : 글자 정렬 설정

### text-align

- `left` : 왼쪽 정렬
- `center` : 가운데 정렬
- `right` : 오른쪽 정렬

---

# 2. 박스 모델

HTML 요소는 기본적으로 박스 형태로 구성된다.

- `content` : 실제 내용
- `padding` : 내용과 테두리 사이의 안쪽 여백
- `border` : 요소의 테두리
- `margin` : 요소 바깥쪽 여백

### 핵심

- `margin` = 바깥 여백
- `padding` = 안쪽 여백
- `border` = 테두리

---

## 3. 박스 크기

- `width` : 박스의 가로 크기
- `height` : 박스의 세로 크기
- `max-width` : 박스가 가질 수 있는 최대 가로 크기

### box-sizing

`box-sizing: border-box`를 사용하면 `width`와 `height` 안에 `padding`과 `border`까지 포함해서 크기를 계산한다.

박스가 부모 영역 밖으로 튀어나가는 문제를 줄일 수 있다.

---

## 4. 배경색과 테두리

- `background-color` : 요소의 배경색 변경
- `border` : 테두리 설정
- `border-radius` : 박스의 모서리를 둥글게 만듦

`border`를 이용하여 테두리의 두께, 스타일, 색상을 변경할 수 있다.

---

## 5. 그림자 효과

- `box-shadow` : 요소에 그림자 효과를 적용

박스나 버튼을 입체적으로 보이게 만들 수 있다.

---

# 6. Flexbox

Flexbox는 요소를 **한 방향으로 배치할 때 사용하는 방법**이다.

예를 들어:

- 메뉴를 가로로 나열할 때
- 버튼들을 한 줄로 정렬할 때
- 요소들을 가운데 정렬할 때

사용한다.

### 주요 속성

- `display: flex` : Flexbox 사용
- `flex-direction` : 요소가 배치되는 방향 설정
- `justify-content` : 주축 방향 정렬
- `align-items` : 교차축 방향 정렬
- `flex-wrap` : 공간이 부족하면 다음 줄로 이동

### flex-direction

- `row` : 가로 방향 배치
- `column` : 세로 방향 배치

### justify-content

주축 방향의 요소 위치를 조절한다.

- `flex-start` : 시작 위치 정렬
- `center` : 가운데 정렬
- `flex-end` : 끝 위치 정렬
- `space-between` : 요소 사이에 동일한 간격 배치

### align-items

교차축 방향의 요소 위치를 조절한다.

- `flex-start` : 시작 위치
- `center` : 가운데 정렬
- `flex-end` : 끝 위치

---

# 7. Grid

Grid는 요소를 **행과 열 형태로 배치할 때 사용하는 방법**이다.

여러 개의 요소를 표처럼 정렬하거나 카드 형태의 화면을 만들 때 사용한다.

### 주요 속성

- `display: grid` : Grid 사용
- `grid-template-columns` : 열의 개수와 크기 설정
- `gap` : 요소 사이의 간격 설정

### fr 단위

`fr`은 Grid에서 공간의 비율을 나타낸다.

예를 들어:

`1fr 1fr 1fr`

은 화면을 동일한 크기의 3개의 열로 나눈다.

### grid-column

특정 요소가 여러 열을 차지하도록 설정할 수 있다.

---

# 8. Position

Position은 요소의 위치를 직접 조절할 때 사용한다.

### position: relative

현재 요소를 위치의 기준점으로 만든다.

주로 부모 요소에 사용한다.

### position: absolute

요소를 일반적인 문서 흐름에서 벗어나 원하는 위치에 배치한다.

주로 부모 요소에 `relative`를 주고 자식 요소에 `absolute`를 사용한다.

### 위치 설정

- `top` : 위쪽 위치
- `left` : 왼쪽 위치
- `right` : 오른쪽 위치
- `bottom` : 아래쪽 위치

### 주의점

`position: absolute`가 적용된 요소는 원래 위치의 공간을 다른 요소들이 비워두지 않는다.

따라서 요소들을 겹쳐서 배치할 수 있지만 너무 많이 사용하면 화면 구조가 흐트러질 수 있다.

---

# 9. 버튼 스타일

링크나 요소를 버튼처럼 만들 수 있다.

### 주요 속성

- `display: inline-block` : 요소를 버튼처럼 배치 가능
- `padding` : 버튼 안쪽 여백
- `margin` : 버튼 바깥쪽 여백
- `background-color` : 버튼 배경색
- `color` : 글자 색상
- `text-decoration` : 글자 밑줄 제거
- `border-radius` : 버튼 모서리를 둥글게 만듦

---

# 10. transition

`transition`은 CSS 속성이 변경될 때 부드럽게 변화하도록 만드는 기능이다.

예를 들어 마우스를 버튼 위에 올렸을 때 색상이 자연스럽게 변경된다.

- `all` : 모든 속성에 적용
- 시간 : 변화하는 속도 설정
- `ease` : 자연스럽게 시작하고 끝나는 효과

---

# 11. :hover

`:hover`는 마우스 커서를 요소 위에 올렸을 때 적용되는 가상 클래스이다.

주로 버튼에 마우스를 올렸을 때 사용한다.

변경할 수 있는 효과:

- 배경색 변경
- 글자 색상 변경
- 위치 이동
- 그림자 추가
- 투명도 변경

---

# 12. transform

`transform`은 요소의 위치나 크기 등을 변경할 수 있다.

### translateY()

세로 방향으로 요소를 이동한다.

- 음수 값 → 위로 이동
- 양수 값 → 아래로 이동

버튼에 마우스를 올렸을 때 위로 움직이는 효과를 만들 수 있다.

---

# 13. opacity

`opacity`는 요소의 투명도를 설정한다.

- `1` : 완전히 보임
- `0` : 완전히 투명
- `0.5` : 반투명

소수점은 `0,9`가 아니라 `0.9`처럼 점(`.`)을 사용한다.

---

# 14. :active

`:active`는 마우스로 요소를 클릭하고 있는 순간 적용되는 가상 클래스이다.

버튼을 클릭했을 때 위치를 이동시키거나 크기를 변경하는 효과를 만들 수 있다.

---

# ⭐ 오늘 핵심 정리

## 박스 모델

- `margin` → 바깥쪽 여백
- `padding` → 안쪽 여백
- `border` → 테두리
- `box-sizing` → 박스 크기 계산 방식

## 박스 디자인

- `width` / `height` → 박스 크기
- `max-width` → 최대 가로 크기
- `background-color` → 배경색
- `color` → 글자색
- `border-radius` → 둥근 모서리
- `box-shadow` → 그림자 효과

## Flexbox

- 한 방향으로 요소 배치
- `flex-direction` → 배치 방향
- `justify-content` → 주축 방향 정렬
- `align-items` → 교차축 방향 정렬
- `flex-wrap` → 공간 부족 시 다음 줄 이동

## Grid

- 행과 열 형태로 요소 배치
- `grid-template-columns` → 열 설정
- `gap` → 요소 간격
- `fr` → 공간 비율

## Position

- `relative` → 위치 기준점 생성
- `absolute` → 원하는 위치에 배치
- `top`, `left`, `right`, `bottom` → 위치 설정

## 버튼 효과

- `:hover` → 마우스를 올렸을 때
- `:active` → 클릭하고 있는 동안
- `transition` → 변화 효과를 부드럽게 만듦
- `transform` → 요소 이동 및 변형
- `translateY()` → 위아래 방향 이동
- `opacity` → 투명도 설정

# 오늘 배운 JavaScript 정리

## 1. 변수(Variable)

변수는 데이터를 저장할 때 사용하는 **이름이 붙은 저장소**이다.

변수를 생성하는 것을 **변수 선언**이라고 한다.

### 변수 선언 방법

`키워드 변수명;`

- 키워드 : 변수를 어떤 규칙으로 만들지 정함
- 변수명 : 저장된 값을 다시 사용할 때 부르는 이름

---

## 2. 변수 선언 키워드

### var

ES5까지 사용했던 변수 선언 키워드이다.

ES6에서 단점을 보완하기 위해 `let`과 `const`가 추가되었다.

---

### let

값을 변경할 수 있는 변수를 선언할 때 사용한다.

즉, 값을 다시 할당할 수 있다.

---

### const

값을 다시 할당할 수 없는 변수를 선언할 때 사용한다.

- 재할당 금지
- 반드시 선언과 동시에 초기화해야 함

---

## 3. 변수 선언과 할당

### 변수 선언

변수를 만드는 것을 의미한다.

### 값 할당

변수에 값을 저장하는 것을 의미한다.

### 초기화

변수를 선언하면서 동시에 처음 값을 할당하는 것을 의미한다.

---

## 4. 변수명 규칙

변수 이름에는 다음 문자를 사용할 수 있다.

- 문자
- 숫자
- `_`
- `$`

### 주의사항

- 변수 이름은 숫자로 시작할 수 없다.
- 예약어는 변수 이름으로 사용할 수 없다.
- 변수 이름은 의미 있게 작성하는 것이 좋다.

### camelCase

두 번째 단어부터 첫 글자를 대문자로 작성하는 방식이다.

JavaScript에서는 일반적으로 `camelCase`를 많이 사용한다.

예시:

- `userName`
- `userAge`
- `firstName`

---

# 5. 동적 타입 언어

JavaScript는 **동적 타입 언어**이다.

변수에 현재 들어 있는 값에 따라 타입이 결정된다.

JavaScript와 Python 등이 동적 타입 언어에 해당한다.

---

# 6. JavaScript의 데이터 타입

## 1) 숫자(Number)

JavaScript는 하나의 숫자 타입만 존재한다.

모든 수를 Number 타입으로 처리한다.

`typeof`를 사용하면 변수의 데이터 타입을 확인할 수 있다.

---

## 2) 문자열(String)

문자열은 텍스트 데이터를 의미한다.

문자열은 다음과 같이 표현할 수 있다.

- 작은따옴표 `' '`
- 큰따옴표 `" "`
- 백틱 `` ` ` ``

---

## 3) 불린(Boolean)

논리적인 참과 거짓을 나타내는 데이터 타입이다.

값은 두 가지뿐이다.

- `true` : 참
- `false` : 거짓

---

## 4) null

명시적으로 값이 없음을 나타낼 때 사용한다.

의도적으로 값이 없다는 것을 표현한다.

`typeof null`의 결과는 `object`가 나오는데, 이는 JavaScript의 오래된 버그이다.

---

## 5) undefined

변수에 값이 할당되지 않았을 때 자동으로 할당되는 값이다.

---

# 7. typeof

`typeof`는 변수나 값의 데이터 타입을 확인할 때 사용한다.

확인할 수 있는 대표적인 타입:

- `number`
- `string`
- `boolean`
- `undefined`
- `object`

---

# 8. 템플릿 리터럴(Template Literal)

ES6부터 도입된 문자열 표기법이다.

작은따옴표나 큰따옴표 대신 **백틱(`)**을 사용한다.

### 특징

문자열 안에 변수를 쉽게 사용할 수 있다.

`${변수명}` 형태로 변수 값을 문자열 안에 넣을 수 있다.

### 줄바꿈

백틱을 사용하면 문자열 안에서 줄바꿈을 사용할 수 있다.

---

# 9. eval()

`eval()`은 문자열 형태의 코드를 실제 JavaScript 코드처럼 실행한다.

문자열 안에 있는 계산식이나 코드를 실행할 수 있다.

---

# 10. 암묵적 타입 변환

개발자가 직접 타입 변환을 명령하지 않아도 JavaScript 엔진이 문맥에 맞게 타입을 자동으로 변환하는 것을 의미한다.

---

## 문자열 타입으로 암묵적 변환

`+` 연산자에서 문자열이 포함되어 있으면 문자열 연결 연산자로 동작할 수 있다.

숫자가 문자열과 함께 사용되면 문자열로 변환될 수 있다.

---

## 숫자 타입으로 암묵적 변환

산술 연산자의 피연산자는 숫자로 계산되어야 한다.

따라서 숫자가 아닌 값이 숫자로 변환될 수 있다.

대표적인 산술 연산자:

- `-`
- `*`
- `/`
- `%`

---

## 비교 연산자

비교 연산을 할 때도 값의 타입이 변환될 수 있다.

대표적인 비교 연산자:

- `<`
- `>`

---

## 단항 + 연산자

단항 `+` 연산자는 피연산자가 숫자가 아닐 경우 숫자 타입으로 변환할 수 있다.

예시:

- `+true`
- `+false`
- `+''`

---

# 11. Truthy와 Falsy

JavaScript에서는 Boolean 타입이 아닌 값도 조건문에서 참 또는 거짓으로 평가된다.

이를 다음과 같이 구분한다.

- Truthy : 참으로 평가되는 값
- Falsy : 거짓으로 평가되는 값

---

## Falsy 값 6가지

다음 값들은 `false`로 평가된다.

- `false`
- `0`
- `''` (빈 문자열)
- `null`
- `undefined`
- `NaN`

이 외의 대부분의 값은 `true`로 평가된다.

---

# 12. 명시적 타입 변환

개발자의 의도에 따라 직접 값의 타입을 변환하는 것을 의미한다.

---

## 문자열(String) 타입으로 변환

### String()

`String()` 생성자 함수를 사용하여 값을 문자열로 변환할 수 있다.

숫자, Boolean, null 등을 문자열로 변환할 수 있다.

---

### toString()

`toString()` 메서드를 사용하여 값을 문자열로 변환할 수 있다.

단, `null`이나 `undefined`에는 사용할 수 없다.

---

# 13. 숫자(Number) 타입으로 변환

## Number()

`Number()`를 사용하여 값을 숫자 타입으로 변환한다.

숫자로 변환할 수 없는 문자열은 `NaN`이 될 수 있다.

---

## parseInt()

문자열을 정수로 변환한다.

소수점이 있는 경우 정수 부분만 변환한다.

---

## parseFloat()

문자열을 실수로 변환한다.

소수점까지 포함하여 숫자로 변환한다.

---

# 14. Boolean 타입으로 변환

## Boolean()

`Boolean()`을 사용하여 값을 Boolean 타입으로 변환할 수 있다.

### Falsy 값

다음 6개의 값은 `false`가 된다.

- `false`
- `undefined`
- `null`
- `0`
- `''`
- `NaN`

나머지 값은 대부분 `true`로 변환된다.

---

## !! 연산자 사용

`!` 부정 논리 연산자를 두 번 사용하면 값을 Boolean 타입으로 변환할 수 있다.

### 첫 번째 `!`

값을 반대로 바꾼다.

### 두 번째 `!`

다시 반대로 바꾸면서 원래 값의 Truthy 또는 Falsy 결과를 Boolean 값으로 확인할 수 있다.

---

# ⭐ 오늘 핵심 정리

## 변수

- 변수 = 데이터를 저장하는 이름이 붙은 저장소
- `var` = ES5까지 사용하던 변수 선언 방식
- `let` = 재할당 가능
- `const` = 재할당 불가능
- `const` = 선언과 동시에 초기화 필요

## 변수명

- 숫자로 시작할 수 없음
- 예약어 사용 금지
- 문자, 숫자, `_`, `$` 사용 가능
- JavaScript에서는 `camelCase`를 많이 사용

## 데이터 타입

- `number` → 숫자
- `string` → 문자열
- `boolean` → 참과 거짓
- `null` → 의도적으로 값이 없음
- `undefined` → 값이 할당되지 않음

## 템플릿 리터럴

- 백틱 `` ` `` 사용
- `${}`를 이용하여 문자열 안에 변수 사용 가능
- 줄바꿈 가능

## 타입 변환

### 암묵적 타입 변환

JavaScript 엔진이 자동으로 타입을 변환한다.

### 명시적 타입 변환

개발자가 직접 타입을 변환한다.

- `String()` → 문자열 변환
- `toString()` → 문자열 변환
- `Number()` → 숫자 변환
- `parseInt()` → 정수 변환
- `parseFloat()` → 실수 변환
- `Boolean()` → Boolean 변환

## Truthy / Falsy

### Falsy 6총사

- `false`
- `0`
- `''`
- `null`
- `undefined`
- `NaN`

그 외의 대부분의 값은 Truthy로 평가된다.

## typeof

- 변수나 값의 데이터 타입을 확인할 때 사용한다.
