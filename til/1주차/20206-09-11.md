# 오늘 배운 거 나만의 정리

## 1. Date

### new Date()

new Date()는
"생성한 당시의 날짜와 시간"을 가져오는 것.

const now = new Date();

→ 현재 날짜와 시간을 가진 Date 객체가 만들어짐.


### toLocaleString()

toLocaleString()
→ 날짜와 시간을 "지역에 맞는 형식"으로 표시해줌.

console.log(now.toLocaleString());


### 날짜 가져오기

getFullYear()
→ 연도

getMonth()
→ 월
→ 0부터 시작하기 때문에 +1 해야 실제 월이 됨

getDate()
→ 일


예시

const now = new Date();

const year = now.getFullYear();
const month = now.getMonth() + 1;
const date = now.getDate();

console.log(`${year}${month}${date}`);


정리

getFullYear()
→ 년

getMonth() + 1
→ 월

getDate()
→ 일


# 2. Class (클래스)

클래스는
생성자 함수 같은 역할을 하는 것 같음.

객체를 만들기 위한 설계도 같은 느낌.


### 기본 형식

class Person {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }

    sayHello() {
        console.log(`안녕하세요 ${this.name}입니다.`);
    }
}


const person1 = new Person('영동', 29);
const person2 = new Person('철수', 30);


### new

class는 정의만 해놓는다고
객체가 자동으로 만들어지는 것은 아님.

new를 사용해서 객체를 만들어야 함.

const person = new Person('영동', 29);


즉

class
→ 객체를 만들기 위한 설계도

new
→ 실제 객체 생성


### 생성자 함수와 비슷한 점

예전에는 생성자 함수를 이용해서
객체를 만드는 방식이 있었음.

function Person(name) {
    this.name = name;
}

const person = new Person('영동');


class는 이것을 좀 더 보기 편하게 작성하는 방식이라고 이해하면 됨.


# 3. 클래스의 메서드와 prototype

클래스 안에서 만든 메서드는
객체마다 함수를 새로 만드는 방식이 아니라
prototype을 통해 공유하는 방식으로 동작함.

예를 들어

class Person {
    constructor(name) {
        this.name = name;
    }

    sayHello() {
        console.log(this.name);
    }
}


const person1 = new Person('영동');
const person2 = new Person('철수');


person1과 person2가
각각 sayHello 함수를 하나씩 따로 만드는 것이 아니라

Person.prototype.sayHello

를 통해 같은 메서드를 공유하는 구조.


생성자 함수로 직접 작성하면

function Person(name) {
    this.name = name;
}

Person.prototype.sayHello = function() {
    console.log(this.name);
};


이런 식으로 prototype에 한 번 만들어서
여러 객체가 공유할 수 있음.


### 핵심

객체마다 함수를 따로 만들면
메모리를 더 사용할 수 있음.

prototype에 함수를 만들어 공유하면
여러 객체가 같은 함수를 사용할 수 있음.


# 4. 화살표 함수 심화

화살표 함수에서 중요한 것

→ 화살표 함수는 자신만의 this를 가지고 있지 않음.


일반 함수

function() {
    console.log(this);
}


→ 자신만의 this가 있음.


화살표 함수

() => {
    console.log(this);
}


→ 자신만의 this가 없음.

자신이 만들어진 곳의
상위 스코프의 this를 사용함.


### 그래서 예전에 쓰던 방식

const that = this;

이런 식으로
현재 this를 다른 변수에 저장해서
안쪽 함수에서 사용하기도 했음.

예시

function Person() {

    const that = this;

    this.name = '영동';

    setTimeout(function() {
        console.log(that.name);
    }, 1000);
}


여기서

const that = this;

→ 현재 this를 that이라는 변수에 저장


그 다음 일반 함수 안에서

that.name

으로 사용.


### 화살표 함수를 사용하면

function Person() {

    this.name = '영동';

    setTimeout(() => {
        console.log(this.name);
    }, 1000);
}


화살표 함수는
자신만의 this가 없기 때문에
바깥의 this를 그대로 사용함.

그래서

const that = this;

처럼 따로 저장하지 않아도 됨.


### 핵심

일반 함수
→ 자신만의 this가 있음

화살표 함수
→ 자신만의 this가 없음
→ 바깥쪽 this를 사용


# 5. for...of

배열 같은 반복 가능한 값을
하나씩 꺼내는 반복문.

기존 for문으로 하면

const arr = ['사과', '바나나', '포도'];

for (let i = 0; i < arr.length; i++) {
    console.log(arr[i]);
}


for...of를 사용하면

for (const fruit of arr) {
    console.log(fruit);
}


훨씬 간단하게
배열의 값을 하나씩 꺼낼 수 있음.


### 기본 형식

for (const 변수명 of 반복할배열) {
    // 실행할 코드
}


예시

const fruits = ['사과', '바나나', '포도'];

for (const fruit of fruits) {
    console.log(fruit);
}


결과

사과
바나나
포도


### 내가 배운 범위에서

for...of는
배열이나 문자열처럼
반복할 수 있는 값에 사용할 수 있음.

배열

const arr = [1, 2, 3];

for (const value of arr) {
    console.log(value);
}


문자열

const text = 'ABC';

for (const value of text) {
    console.log(value);
}


→ A
→ B
→ C


즉

for...of
→ 값을 하나씩 꺼내는 반복문


# 6. Spread 문법

Spread
→ "펼쳐준다"라고 이해하면 됨.

... 을 사용함.


### 배열 펼치기

const arr1 = [1, 2, 3];

const arr2 = [...arr1];


arr1의 값들을
하나씩 펼쳐서
arr2에 넣는 느낌.


결과

arr2
→ [1, 2, 3]


### 배열 합치기

const arr1 = [1, 2];
const arr2 = [3, 4];

const result = [...arr1, ...arr2];


결과

[1, 2, 3, 4]


### 배열 복사

const arr1 = [1, 2, 3];

const arr2 = [...arr1];


→ arr1의 요소들을 펼쳐서
새로운 배열을 만드는 것.


하지만 중요한 점

→ 얕은 복사(Shallow Copy)


1차원 배열의 단순한 값들은
새로운 배열에 복사되지만

객체나 배열이 내부에 들어있는 경우에는
참조가 공유될 수 있음.


# 7. Rest 문법

Rest는 Spread와 똑같이
...을 사용하지만 역할이 반대라고 생각하면 쉬움.


Spread
→ 펼침

Rest
→ 모음


특히 함수의 매개변수에서

...변수명

을 사용하면
전달된 여러 값을 하나의 배열로 모아줌.


### 기본 형태

function test(...args) {

    console.log(args);

}


test(10, 20, 30);


결과

[10, 20, 30]


즉

...args
→ 전달받은 나머지 값들을
하나의 배열로 모음


# 8. Rest를 사용한 합계

예를 들어

function sum(...numbers) {

    let total = 0;

    for (const number of numbers) {
        total += number;
    }

    return total;
}


sum(10, 20, 30);


과정

numbers
→ [10, 20, 30]

total
→ 0

첫 번째 반복
→ total = 10

두 번째 반복
→ total = 30

세 번째 반복
→ total = 60


결과

60


즉

function sum(...numbers)

→ 함수에 몇 개의 숫자가 들어올지 몰라도
전부 numbers 배열로 모음.


그리고

let total = 0;

→ 합계를 저장할 변수


for (const number of numbers)

→ numbers 배열에서 값을 하나씩 꺼냄


total += number;

→ 꺼낸 값을 total에 계속 더함


return total;

→ 최종 합계를 반환


# 9. Spread와 Rest 차이

둘 다 ...

하지만 역할이 반대.


Spread

const arr = [1, 2, 3];

const newArr = [...arr];


→ 배열을 펼침


Rest

function test(...args) {

}


test(1, 2, 3);


→ 여러 값을 배열로 모음


쉽게 외우기

Spread
→ 펼치기

Rest
→ 모으기
