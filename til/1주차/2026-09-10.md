# JavaScript 오늘 배운 내용 정리

## 1. Array(배열)

### 배열 선언

배열 = 여러 개의 값을 하나로 묶어서 저장

const fruits = ['사과', '바나나', '포도'];

[]를 사용함.


### index(인덱스)

배열의 위치 번호
index는 0부터 시작

const fruits = ['사과', '바나나', '포도'];

fruits[0]; // 사과
fruits[1]; // 바나나
fruits[2]; // 포도


### 요소 변경

fruits[1] = '딸기';

console.log(fruits);
// ['사과', '딸기', '포도']


### 배열 요소 한 번에 뽑기

for문을 이용해서 배열의 모든 요소를 하나씩 뽑을 수 있음.

for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}


## 2. 배열 추가 / 삭제

push()
→ 배열 뒤에 추가

fruits.push('포도');


pop()
→ 배열 뒤에서 삭제

fruits.pop();


unshift()
→ 배열 앞에 추가

fruits.unshift('딸기');


shift()
→ 배열 앞에서 삭제

fruits.shift();


암기:

push    → 뒤에 추가
pop     → 뒤에 삭제
unshift → 앞에 추가
shift   → 앞에 삭제


## 3. forEach()

배열의 요소를 하나씩 실행함.

const numbers = [1, 2, 3];

numbers.forEach(x => {
    console.log(x);
});

결과:

1
2
3


### forEach의 반환값

forEach() 자체의 반환값은 항상 undefined

const result = numbers.forEach(x => {
    console.log(x);
});

console.log(result);
// undefined


### console.log와 return은 다름

console.log()
→ 화면에 출력

return
→ 값을 함수 밖으로 반환


forEach 안에서 console.log()를 하면 당연히 출력됨.

numbers.forEach(x => {
    console.log(x * 2);
});

결과:

2
4
6

하지만 forEach() 자체의 반환값은 undefined.


### forEach에서 return을 사용해도?

numbers.forEach(x => {
    return x * 2;
});

return은 각 콜백 함수에서 실행되는 것이고,
forEach가 그 값을 모아서 반환해주지는 않음.

const result = numbers.forEach(x => {
    return x * 2;
});

console.log(result);
// undefined


## 4. map()

배열의 각 요소를 가공해서 새로운 배열을 만듦.

const numbers = [1, 2, 3];

const result = numbers.map(x => {
    return x * 2;
});

console.log(result);
// [2, 4, 6]


### map의 특징

map()
→ 각 요소를 가공
→ return한 값을 모음
→ 새로운 배열을 반환

원본 배열에는 영향을 주지 않음.

const numbers = [1, 2, 3];

const result = numbers.map(x => x * 2);

console.log(numbers);
// [1, 2, 3]

console.log(result);
// [2, 4, 6]


### forEach와 map 비교

forEach
→ 하나씩 실행
→ 반환값은 undefined

map
→ 하나씩 가공
→ 결과를 모아서 새로운 배열로 반환


## 5. filter()

filter = 걸러내다

조건이 true인 요소만 골라서 새로운 배열로 반환함.

const numbers = [1, 2, 3, 4, 5];

const result = numbers.filter(x => x >= 3);

console.log(result);
// [3, 4, 5]


쉽게:

1 → false → 버림
2 → false → 버림
3 → true  → 가져옴
4 → true  → 가져옴
5 → true  → 가져옴


## 6. find()

조건에 맞는 첫 번째 요소 하나를 찾아줌.

const students = [
    { 이름: '철수', 점수: 70 },
    { 이름: '영희', 점수: 90 },
    { 이름: '민수', 점수: 80 }
];

const result = students.find(student => student.점수 >= 80);

console.log(result);
// { 이름: '영희', 점수: 90 }


find()
→ 딱 하나 찾음
→ 조건에 맞는 첫 번째 요소만 반환

못 찾으면:

undefined


## 7. some()

하나라도 조건에 맞는지 확인함.

결과는 true / false

const numbers = [1, 2, 3, 4];

const result = numbers.some(x => x > 3);

console.log(result);
// true


some()
→ "하나라도 맞아?"


## 8. every()

모든 요소가 조건에 맞는지 확인함.

결과는 true / false

const numbers = [2, 4, 6];

const result = numbers.every(x => x > 0);

console.log(result);
// true


some()
→ 하나라도 맞는지

every()
→ 전부 맞는지


## 9. sort()

배열을 정렬함.

const numbers = [30, 10, 20];

numbers.sort((a, b) => a - b);

console.log(numbers);
// [10, 20, 30]


### 오름차순

(a, b) => a - b

낮은 값 → 높은 값


### 내림차순

(a, b) => b - a

높은 값 → 낮은 값


### 숫자 sort 주의

sort()를 그냥 사용하면 숫자를 사람이 생각하는 숫자 크기대로 정렬하지 않을 수 있음.

[10, 2, 30].sort();

숫자는 보통:

numbers.sort((a, b) => a - b);


### sort의 특징

sort()는 원본 배열 자체를 변경함.


## 10. reduce()

배열의 값을 하나로 누적해서 최종 결과를 만드는 것.

총합을 구할 때 많이 사용함.

const numbers = [10, 20, 30];

const total = numbers.reduce((sum, current) => {
    return sum + current;
}, 0);

console.log(total);
// 60


### reduce 형식

sum
→ 지금까지 누적된 값

current
→ 현재 배열 요소

0
→ 시작값


흐름:

0 + 10 = 10
10 + 20 = 30
30 + 30 = 60


### 상품 총액

const 총액 = 정렬상품.reduce((sum, product) => {
    return sum + product.price;
}, 0);


reduce는 형식이 어려워서 기본 형태를 익혀두는 게 중요함.

## 14. slice()

문자열이나 배열의 일부를 잘라서 가져옴.

const numbers = [10, 20, 30, 40, 50];

const result = numbers.slice(1, 4);

console.log(result);
// [20, 30, 40]


끝 번호는 포함하지 않음.

slice(1, 4)

1 → 포함
2 → 포함
3 → 포함
4 → 제외


원본 배열은 변경하지 않음.


## 15. lastIndexOf()

찾지 못하면 -1


## 16. split()

문자열을 배열로 나눔.

const text = '사과,바나나,포도';

const result = text.split(',');

console.log(result);
// ['사과', '바나나', '포도']


### # 기준으로 나누기

const tags = '#자바#개발자#프론트엔드';

const result = tags.split('#');

console.log(result);
// ['', '자바', '개발자', '프론트엔드']


처음에 #이 있기 때문에 첫 번째 값이 빈 문자열 ''이 됨.

result.shift();

console.log(result);
// ['자바', '개발자', '프론트엔드']


즉 split()이 빈 값을 자동으로 제거하는 것은 아님.


## 17. 메서드 체이닝(Chaining)

메서드를 여러 개 이어서 사용하는 방식.

const 상품이름 = products
    .filter(product => product.stock > 0)
    .sort((a, b) => a.price - b.price)
    .map(product => product.name);

console.log(상품이름);


처리 순서:

products
↓
filter
→ 재고 있는 상품만 선택
↓
sort
→ 가격순 정렬
↓
map
→ 이름만 추출


### 체이닝의 핵심

앞의 메서드가 반환한 값을
뒤의 메서드가 사용할 수 있어야 함.

filter()
→ 새 배열 반환
→ .map() 가능

map()
→ 새 배열 반환
→ .filter() 가능

sort()
→ 배열 반환
→ .map() 가능

forEach()
→ undefined 반환
→ .map() 불가능


## 18. 배열 메서드 반환값과 체이닝

| 메서드 | 반환값 | 뒤에 체이닝 |
|---|---|---|
| filter() | 새 배열 | ✅ |
| map() | 새 배열 | ✅ |
| sort() | 배열 | ✅ |
| find() | 객체/값 또는 undefined | ⚠️ |
| some() | true / false | ❌ 배열 메서드 연결 X |
| reduce() | 최종 값 | ⚠️ |
| forEach() | undefined | ❌ |

## 20. 화살표 함수(Arrow Function)

오늘 가장 헷갈렸던 부분.

x => x * 2

쉽게 해석하면:

"x를 받아서 → x × 2 해라"


일반 함수:

function(x) {
    return x * 2;
}


화살표 함수:

x => x * 2


둘은 같은 기능.


## 21. 화살표 함수의 소괄호()

매개변수가 1개면 소괄호 생략 가능.

x => x * 2


매개변수가 여러 개면:

(a, b) => a + b


매개변수가 없으면:

() => '안녕'


## 22. 화살표 함수의 중괄호{}

### 중괄호가 없으면 자동 return

x => x * 2


이것과 비슷함:

x => {
    return x * 2;
}


### 중괄호가 있으면 값을 반환할 때 return 직접 작성

x => {
    return x * 2;
}


다음은 return이 없기 때문에 undefined:

x => {
    x * 2;
}


중요:

{}를 쓰는 것 자체가 return을 위한 것은 아님.
여러 줄의 코드를 작성하기 위해 {}를 사용할 수도 있음.

다만 {}를 사용하고 값을 반환하려면 return을 직접 작성해야 함.


## 23. 객체 반환하기

화살표 함수에서 객체를 바로 반환할 때:

const 객체유저 = (id, name) => ({
    아이디: id,
    이름: name
});

console.log(객체유저(1, '판다'));


({})의 의미:

()
→ 객체를 감싸줌

{}
→ 객체


중괄호를 함수의 코드 블록으로 착각하지 않게
소괄호로 객체를 감싸서 바로 반환하는 방식.


return을 직접 쓰면 소괄호가 필요 없음.

const 객체유저 = (id, name) => {
    return {
        아이디: id,
        이름: name
    };
};


즉:

() => ({ 객체 })

=

() => {
    return { 객체 };
}


## 24. 콜백 함수

콜백 함수 = 함수를 다른 함수에 전달하는 것.

function calculate(value, option) {
    return option(value);
}


여기서 option은 함수가 들어오는 자리.


### 먼저 함수 만들기

const 제곱 = function(x) {
    return x * x;
};


화살표 함수로 쓰면:

const 제곱 = x => x * x;


### 다른 함수에 전달

console.log(calculate(3, 제곱));


흐름:

calculate(3, 제곱)
↓
value = 3
option = 제곱 함수
↓
option(value)
↓
제곱(3)
↓
3 × 3
↓
9


calculate가 직접 제곱하는 것이 아님.

calculate는
"나한테 함수를 하나 줬으니까 그 함수를 실행할게."
라고 하는 것.


### 함수를 바로 전달할 수도 있음

console.log(
    calculate(3, Number => Number * Number)
);


여기서는 제곱이라는 함수를 미리 만들지 않고
화살표 함수를 바로 전달한 것.


## 25. products와 product 구분

이 부분이 매우 중요함.

const products = [
    { name: '노트', price: 3000, stock: 5 },
    { name: '펜', price: 1000, stock: 0 },
    { name: '파일', price: 2000, stock: 3 }
];


products
→ 전체 상품 배열

product
→ 배열에서 하나씩 꺼낸 상품


예:

products.filter(product => product.stock > 0)


뜻:

products 배열에서
↓
상품 하나를 product라는 이름으로 받아서
↓
그 product의 stock을 검사


그래서 보통 이렇게 통일해서 사용:

products.map(product => ...)
products.filter(product => ...)
products.find(product => ...)
products.some(product => ...)
products.every(product => ...)


기억:

products = 여러 개 / 전체 배열
product = 하나의 상품


## 26. 오늘 실습한 Product 코드

const products = [
    { name: '노트', price: 3000, stock: 5 },
    { name: '펜', price: 1000, stock: 0 },
    { name: '파일', price: 2000, stock: 3 }
];


### 재고 있는 상품 + 가격순 정렬

const 정렬상품 =
    products
        .filter(product => product.stock > 0)
        .sort((a, b) => a.price - b.price);


결과:

[
    { name: '파일', price: 2000, stock: 3 },
    { name: '노트', price: 3000, stock: 5 }
]


### 상품 이름만 뽑기

const 이름 = 정렬상품.map(product => product.name);

console.log(이름);

// ['파일', '노트']


### 총액

const 총액 = 정렬상품.reduce((sum, product) => {
    return sum + product.price;
}, 0);

console.log(총액);

// 5000


### 상품 찾기

const 상품찾기 = products.find(product => product.name === '펜');

console.log(상품찾기);

// { name: '펜', price: 1000, stock: 0 }


### 품절 상품이 하나라도 있는지

const 품절상품있음 = products.some(product => product.stock === 0);

console.log(품절상품있음);

// true


### 모든 가격이 양수인지

const 가격양수 = products.every(product => product.price > 0);

console.log(가격양수);

// true


### 판매 가능한 상품의 이름과 가격

const 판매가능상품 = products.filter(product => product.stock > 0);

const 가격이름 = 판매가능상품.map(product => {
    return {
        가격: product.price,
        이름: product.name
    };
});

console.log(가격이름);

// [
//     { 가격: 3000, 이름: '노트' },
//     { 가격: 2000, 이름: '파일' }
// ]


### 정렬상품을 이용해서 줄일 수도 있음

이미 정렬상품에는 재고 있는 상품만 들어 있으므로
다시 filter할 필요 없이 바로 map 가능.

const 가격이름 = 정렬상품.map(product => {
    return {
        가격: product.price,
        이름: product.name
    };
});

console.log(가격이름);

함수를 다른 함수에 전달할 수 있음.
↓
그게 콜백 함수
↓
map / filter / sort 등의 함수에 계속 사용
↓
화살표 함수로 콜백을 짧게 작성할 수 있음.


그리고 배열 메서드는
"무엇을 반환하는지"가 중요함.

filter → 배열
map → 배열
sort → 배열
find → 하나의 값
some → true / false
every → true / false
reduce → 최종 값
forEach → undefined

앞의 결과를 뒤에서 사용할 수 있으면
메서드 체이닝이 가능함.
