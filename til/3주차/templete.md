오늘 배운 내용을 복습용 Markdown으로 정리해줘.
- 내가 제공한 코드와 오늘 배운 내용을 기준으로 작성해줘.
- 순서는 내가 지정한 학습 순서를 그대로 따라줘.
- 전체 내용을 하나의 Markdown 코드블록 안에 넣어줘.
- 코드블록은 시작 ``` 1번, 끝 ``` 1번만 사용하고 중간에는 절대 사용하지 마.
- 제목, 설명, 목록, 코드 예시는 전부 하나의 코드블록 안에서 Markdown 형식으로 작성해줘.
- 기본 코드를 통째로 길게 넣지 말고, 복습에 필요한 핵심 코드만 짧게 보여줘.
- 긴 코드는 핵심 구조나 문법만 남겨서 내가 직접 다시 작성해볼 수 있게 해줘.
- 단순히 코드를 복사하는 정리가 아니라 무엇을 왜 사용하는지 이해할 수 있게 설명해줘.
- 핵심 개념, 문법, 자주 헷갈리는 부분, 암기할 내용을 포함해줘.
- 마지막에는 오늘 배운 내용을 전체 흐름으로 연결해서 짧게 정리해줘.
- 너무 길어지면 파일형식으로만들어서 보내줘도 괜찮아
- 내가 바로 복사해서 .md 파일에 붙여넣을 수 있는 형태로 만들어줘.
