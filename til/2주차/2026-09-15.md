# 📚 오늘 배운 JavaScript 이벤트 정리

## ⭐ ① 한 줄 암기 버전

1. `onclick` → 이벤트 함수 1개 저장
2. `addEventListener` → 이벤트 여러 개 등록
3. `removeEventListener` → 등록한 이벤트 함수 제거
4. 이벤트 객체 `e` → 이벤트 정보를 담은 객체
5. `e.target` → 실제 이벤트가 발생한 요소
6. `e.currentTarget` → 이벤트를 등록한 요소
7. `this` → 이벤트가 등록된 요소 (일반 함수 기준)
8. 이벤트 버블링 → 자식에서 부모 방향으로 이벤트 전달
9. 이벤트 위임 → 부모에서 자식 이벤트를 처리
10. `closest()` → 가장 가까운 조상 요소 찾기
11. `dataset` → HTML의 `data-*` 속성 값 가져오기
12. `preventDefault()` → 브라우저의 기본 동작 막기
13. `stopPropagation()` → 이벤트 전파 막기
14. `click / mousedown` → 클릭 / 마우스 버튼 누르기
15. `keydown / keyup / input` → 키 누름 / 키 뗌 / 입력값 변경
16. `form / submit` → 폼 선택 / 폼 제출 이벤트
17. `focus / blur` → 포커스 들어옴 / 포커스 빠짐

# JavaScript 이벤트 복습

## 1. onclick

이벤트 핸들러를 직접 지정하는 방식

$btn.onclick = function() {
    console.log('첫 번째 임무 수행');
};

- 하나의 이벤트에 함수 하나만 저장 가능
- 새로운 함수를 지정하면 기존 함수가 덮어써짐


## 2. addEventListener

특정 이벤트를 기다렸다가 함수를 실행

$btn.addEventListener('click', function() {
    console.log('첫 번째 임무 수행');
});

$btn.addEventListener('click', function() {
    console.log('두 번째 임무 수행');
});

- 같은 이벤트에 여러 함수 등록 가능
- onclick보다 유연하게 사용 가능


## 3. removeEventListener

등록한 이벤트 함수를 제거

function mission() {
    console.log('임무 수행');
}

$btn.addEventListener('click', mission);

$btn.removeEventListener('click', mission);

- addEventListener로 등록한 함수를 제거
- 등록할 때 사용한 것과 같은 함수를 전달해야 함
- 익명 함수는 같은 함수를 다시 지정할 수 없어서 제거하기 어려움


## ⭐ 핵심 비교

onclick
→ 함수 하나만 저장

addEventListener
→ 여러 함수 등록 가능

removeEventListener
→ 등록한 이벤트 함수 제거


## 한 줄 암기

onclick             → 이벤트 함수 1개 저장
addEventListener    → 이벤트 여러 개 등록
removeEventListener → 등록한 이벤트 함수 제거

## 4. 이벤트 객체 e

이벤트가 발생하면 브라우저가 이벤트 정보를 담은 객체를 전달함

$btn.addEventListener('click', (e) => {
    console.log(e);
});

- e는 이벤트 정보를 담고 있음
- e라는 이름은 꼭 사용할 필요 없음
- event라고 작성해도 됨


## 5. e.target

실제로 이벤트가 발생한 요소

$btn.addEventListener('click', (e) => {
    console.log(e.target);
});

- 실제로 클릭한 요소
- 자식 요소를 클릭하면 자식 요소가 target이 될 수 있음


## 6. e.currentTarget

이벤트 리스너를 등록한 요소

$boardList.addEventListener('click', (e) => {
    console.log(e.currentTarget);
});

- 이벤트를 등록해놓은 요소
- 이벤트가 실제로 발생한 요소와 다를 수 있음


## ⭐ target vs currentTarget

e.target
→ 실제 이벤트가 발생한 요소

e.currentTarget
→ 이벤트를 등록한 요소


## 7. this

일반 함수에서 this는 이벤트가 등록된 요소를 가리킴

$btn.addEventListener('click', function(e) {
    console.log(this);
});

- 일반 함수에서 this는 이벤트가 등록된 요소
- 일반 함수에서는 this === e.currentTarget
- 화살표 함수에서는 this가 다르게 동작함


## 8. 이벤트 버블링

자식에서 발생한 이벤트가 부모 방향으로 올라가는 현상

자식
 ↑
부모
 ↑
조상
 ↑
window

- 이벤트는 기본적으로 버블링됨
- 자식에서 발생한 이벤트가 부모에게 전달될 수 있음


## 9. 이벤트 전파 3단계

① 캡처링
window → 부모 → 자식

② 타깃 단계
실제 이벤트 대상에 도착

③ 버블링
자식 → 부모 → window


## 10. 이벤트 위임

부모 요소에 이벤트를 등록하고
자식 요소에서 발생한 이벤트를 처리하는 방법

$list.addEventListener('click', (e) => {

    if (e.target.tagName !== 'LI') return;

    console.log('게시글 클릭');
});

- 부모 하나에 이벤트를 등록
- 자식마다 이벤트를 등록할 필요가 없음
- 이벤트 버블링을 이용함


## 11. closest()

현재 요소에서 가장 가까운 조건의 조상 요소를 찾음

const $li = e.target.closest('li');

- 가장 가까운 li를 찾음
- 찾으면 해당 요소를 반환
- 찾지 못하면 null 반환

if (!$li) return;

→ li를 찾지 못하면 종료


## 12. dataset

HTML의 data-* 속성 값을 가져오는 방법

HTML

<li data-board-id="13"
    data-category-name="맛집">
    맛집 추천
</li>

JavaScript

const boardId = $li.dataset.boardId;
const categoryName = $li.dataset.categoryName;

결과

boardId
→ "13"

categoryName
→ "맛집"


## ⭐ dataset 규칙

data-board-id
→ dataset.boardId

data-category-name
→ dataset.categoryName

HTML의 data-* 속성을
JavaScript에서는 dataset으로 가져옴

## 13. preventDefault()

브라우저의 기본 동작을 막음

$form.addEventListener('submit', (e) => {
    e.preventDefault();
});

- form 제출 시 기본 동작을 막을 수 있음
- a 태그의 링크 이동 등을 막을 수도 있음
- 유효성 검사에서 조건에 맞지 않을 때 제출을 막는 데 사용


## 14. stopPropagation()

이벤트가 부모 요소로 전파되는 것을 막음

$child.addEventListener('click', (e) => {
    e.stopPropagation();
});

- 이벤트 버블링을 막음
- 자식에서 발생한 이벤트가 부모로 전달되지 않게 함


## ⭐ preventDefault vs stopPropagation

preventDefault()
→ 브라우저의 기본 동작을 막음

stopPropagation()
→ 이벤트가 부모로 전파되는 것을 막음


## 15. 마우스 이벤트

click
→ 마우스 클릭

dblclick
→ 더블클릭

mousedown
→ 마우스 버튼을 누르는 순간

mouseup
→ 마우스 버튼을 떼는 순간

mousemove
→ 마우스를 움직일 때


## 16. 키보드 이벤트

keydown
→ 키를 누르는 순간

keyup
→ 키에서 손을 떼는 순간

input
→ 입력값이 변경될 때


## 17. event.key

실제로 입력된 키를 알려줌

e.key

예:
'a'
'A'
'Enter'


## 18. event.code

키보드의 물리적인 키 위치를 알려줌

e.code

예:
'KeyA'
'Enter'


## ⭐ key vs code

e.key
→ 실제 입력된 키

e.code
→ 물리적인 키의 위치


## 19. Form 선택

폼의 name 속성값으로 폼을 선택할 수 있음

HTML

<form name="joinForm">

JavaScript

const $form = document.forms.joinForm;


## 20. Form 내부 요소 선택

폼에 포함된 입력 요소는 name으로 가져올 수 있음

HTML

<input name="username">

JavaScript

const $username = $form.username;


## 21. submit 이벤트

폼이 제출될 때 발생

$form.addEventListener('submit', (e) => {
    console.log('submit 이벤트 발생');
});

유효성 검사 후 제출을 막을 때 사용할 수 있음

if ($username.value.trim().length < 2) {
    e.preventDefault();
    return;
}


## 22. focus

요소에 포커스가 들어올 때 발생

$input.addEventListener('focus', () => {
    console.log('포커스 들어옴');
});


## 23. blur

요소에서 포커스가 빠질 때 발생

$input.addEventListener('blur', () => {
    console.log('포커스 빠짐');
});


## ⭐ focus vs blur

focus
→ 포커스 들어옴

blur
→ 포커스 빠짐
