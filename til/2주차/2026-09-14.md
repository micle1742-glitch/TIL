# JavaScript DOM 복습 — PART 1
## DOM 기본 / 텍스트 조작 / 내부 내용 조작

---

# 1. 중요 키워드

- DOM : HTML 문서를 JavaScript가 객체 형태로 다룰 수 있게 만든 구조
- Element : HTML 요소 하나
- nodeType : 노드의 종류를 확인
- nodeName : 노드의 이름을 확인
- nodeValue : 텍스트 노드의 값
- textContent : 요소 내부의 전체 텍스트를 가져오거나 변경
- innerHTML : 요소 내부의 HTML 전체를 가져오거나 변경
- value : input 등의 현재 입력값
- createElement() : 새로운 HTML 요소 생성
- appendChild() : 새로운 자식 요소를 마지막에 추가

---

# 2. DOM이란?

DOM은 HTML 문서를 JavaScript에서 객체처럼 다룰 수 있도록 만든 구조이다.

HTML:

<div>
    <p>Hello</p>
</div>

JavaScript에서는 HTML의 각각의 요소를 객체처럼 선택하고 조작할 수 있다.

예:

const $p = document.querySelector('p');

$p.textContent = '안녕하세요';

즉,

HTML
↓
DOM 구조
↓
JavaScript로 선택 및 조작

이라는 흐름이다.

---

# 3. Element

Element는 쉽게 말해서 HTML 요소이다.

예:

<div>내용</div>
<p>내용</p>
<li>JavaScript</li>
<button>클릭</button>

이 각각의 HTML 요소를 DOM에서는 Element라고 한다.

따라서 다음과 같은 이름을 볼 수 있다.

parentElement
→ 부모 요소

firstElementChild
→ 첫 번째 자식 요소

lastElementChild
→ 마지막 자식 요소

nextElementSibling
→ 다음 형제 요소

Element = HTML 요소

# 14일차 공부 — DOM

## 1. 요소의 종류 확인하기

### nodeType

노드의 종류를 숫자로 확인할 수 있다.

- 1 : 요소 노드(Element Node)
- 3 : 텍스트 노드(Text Node)
- 9 : 문서 노드(Document Node)

예시

const $title = document.querySelector('h1');

console.log($title.nodeType);
// 1 → 요소 노드


## 2. nodeValue

노드가 가지고 있는 값을 확인하거나 변경한다.

### 요소 노드의 nodeValue

요소 노드 자체의 nodeValue는 null이다.

const $title = document.querySelector('h1');

console.log($title.nodeValue);
// null


### 텍스트 노드의 nodeValue

텍스트 노드를 직접 찾아가면 텍스트 값을 가져올 수 있다.

const $title = document.querySelector('h1');

console.log($title.firstChild.nodeValue);


### 텍스트 변경

$title.firstChild.nodeValue = '새로운 제목';


## 3. textContent

요소와 자손 노드의 전체 텍스트 내용을 가져오거나 변경한다.

const $title = document.querySelector('h1');

console.log($title.textContent);


### textContent로 텍스트 변경

$title.textContent = '새로운 제목';


### nodeValue와 textContent 차이

nodeValue
→ 텍스트 노드 자체의 값을 다룸

textContent
→ 요소 안의 전체 텍스트를 다룸

실무에서는 일반적으로 textContent를 더 편하게 사용한다.


# 4. innerHTML

선택한 요소 내부의 HTML을 가져오거나 변경한다.

const $area = document.querySelector('#area');

$area.innerHTML = '<p>안녕하세요</p>';


### textContent와 innerHTML 차이

textContent
→ 문자열을 일반 텍스트로 처리

innerHTML
→ 문자열을 HTML로 해석

예시

$area.textContent = '<p>안녕하세요</p>';

화면:
<p>안녕하세요</p>


$area.innerHTML = '<p>안녕하세요</p>';

화면:
안녕하세요


### 주의

사용자 입력값을 innerHTML에 그대로 넣으면
XSS 공격에 취약할 수 있다.

사용자 입력값을 단순히 출력할 때는
기본적으로 textContent를 우선 생각한다.


# 5. insertAdjacentHTML

기존 HTML을 유지하면서 특정 위치에 HTML을 추가한다.

element.insertAdjacentHTML(위치, HTML문자열);


위치

'beforebegin'
→ 요소 바로 앞

'afterbegin'
→ 요소 내부의 가장 앞

'beforeend'
→ 요소 내부의 가장 뒤

'afterend'
→ 요소 바로 뒤


예시

$area.insertAdjacentHTML(
    'beforeend',
    '<li>새로운 메뉴</li>'
);


# 6. createElement

새로운 HTML 요소를 만든다.

const $li = document.createElement('li');


하지만 createElement만 하면
실제 화면에는 아직 나타나지 않는다.

DOM에 추가해야 한다.


# 7. appendChild

노드를 부모 요소의 마지막 자식으로 추가한다.

const $li = document.createElement('li');

$li.textContent = '사과';

const $list = document.querySelector('ul');

$list.appendChild($li);


과정

1. createElement()
   → 요소 생성

2. textContent
   → 내용 입력

3. appendChild()
   → DOM에 추가


# 8. DocumentFragment

여러 요소를 효율적으로 추가할 때 사용하는
임시 DOM 공간이다.

const $fragment = document.createDocumentFragment();

const $li1 = document.createElement('li');
$li1.textContent = '사과';

const $li2 = document.createElement('li');
$li2.textContent = '바나나';

$fragment.appendChild($li1);
$fragment.appendChild($li2);

$list.appendChild($fragment);


과정

요소 생성
↓
Fragment에 모으기
↓
실제 DOM에 한 번에 추가


# 9. insertBefore

특정 노드를 기준으로 그 앞에 새로운 노드를 삽입한다.

부모요소.insertBefore(삽입할노드, 기준노드);


예시

$list.insertBefore($steak, $pizza);


의미

$list 안에서
$pizza 앞에
$steak를 삽입


# 10. appendChild를 이용한 노드 이동

이미 존재하는 노드를 appendChild하면
복사되는 것이 아니라 실제 위치가 이동한다.

$drinkList.appendChild($pizza);


즉,

기존 위치
↓
다른 부모의 마지막 위치

로 이동한다.


# 11. replaceChild

기존 노드를 새로운 노드로 교체한다.

부모요소.replaceChild(새로운노드, 기존노드);


예시

$list.replaceChild($newItem, $oldItem);


의미

$oldItem을 제거하고
$newItem으로 교체


# 12. removeChild

자식 노드를 삭제한다.

부모요소.removeChild(삭제할노드);


예시

$list.removeChild($item);


의미

$list에서
$item을 삭제


# 13. Attribute와 Property

## Attribute

HTML 태그에 작성되어 있는 속성이다.

예시

<input id="username" value="홍길동">


여기서

id="username"
value="홍길동"

이 Attribute이다.


## Property

JavaScript에서 DOM 객체가 가지고 있는 속성이다.

예시

$input.value

$input.id


# 14. Attribute 기본 조작

## getAttribute()

Attribute 값을 가져온다.

$input.getAttribute('value');


## setAttribute()

Attribute 값을 설정한다.

$input.setAttribute('value', '김철수');


## hasAttribute()

Attribute가 존재하는지 확인한다.

$input.hasAttribute('value');


결과

true
또는
false


## removeAttribute()

Attribute를 삭제한다.

$input.removeAttribute('value');


# 15. input의 value Attribute와 Property

HTML

<input id="username" value="홍길동">


초기 HTML에 작성된 value

$input.getAttribute('value');


→ '홍길동'


JavaScript Property

$input.value


→ 현재 input에 들어가 있는 값


중요한 차이

getAttribute('value')
→ HTML에 적혀 있는 초기값

.value
→ 사용자가 현재 입력한 값


예시

<input id="username" value="홍길동">


사용자가

김철수

라고 입력했다면

$input.getAttribute('value')
// '홍길동'

$input.value
// '김철수'


# 16. checkbox의 Attribute와 Property

checkbox는 Property가 boolean 값으로 동작한다.

$checkbox.checked


→ true 또는 false


반면 Attribute는 문자열 형태로 존재한다.

$checkbox.getAttribute('checked');


즉,

Property
→ 실제 현재 상태

Attribute
→ HTML에 작성된 속성


# 17. data-* Attribute

HTML에서 사용자 정의 데이터를 저장할 때 사용한다.

예시

<button
    data-id="101"
    data-name="키보드">
    상품
</button>


JavaScript

$button.getAttribute('data-id');


→ '101'


# 18. dataset

data-* Attribute를 JavaScript에서 편하게 다룰 수 있다.

HTML

<button
    data-id="101"
    data-name="키보드">
    상품
</button>


JavaScript

$button.dataset.id
// '101'

$button.dataset.name
// '키보드'


값 변경

$button.dataset.id = '202';


값 삭제

delete $button.dataset.id;


규칙

data-user-id

↓

dataset.userId


즉,

HTML
data-user-name

JavaScript
dataset.userName


# 19. CSS 조작 — style

element.style을 사용하면
인라인 CSS를 직접 변경할 수 있다.

const $box = document.querySelector('.box');

$box.style.color = 'red';

$box.style.backgroundColor = 'yellow';

$box.style.fontSize = '20px';


CSS

background-color

JavaScript

backgroundColor


# 20. className

className을 사용하면
요소의 class 전체를 문자열로 다룰 수 있다.

$box.className = 'circle';


주의

기존 class가 있었다면
전체가 새로운 문자열로 교체된다.

예를 들어

<div class="box active"></div>

$box.className = 'circle';


결과

<div class="circle"></div>


기존 class인
box
active

가 사라진다.


# 21. classList

class를 개별적으로 관리할 때 사용한다.


## add()

클래스 추가

$box.classList.add('active');


## remove()

클래스 제거

$box.classList.remove('active');


## toggle()

클래스가 있으면 제거하고
없으면 추가한다.

$box.classList.toggle('active');


## contains()

특정 클래스가 있는지 확인한다.

$box.classList.contains('active');


결과

true
또는
false
