# 오늘 배운 거 나만의 정리

## 1. 비동기 프로그래밍

### 동기 프로그래밍

동기 방식은 작업을 하나씩 순서대로 처리한다.

앞의 작업이 끝나야 다음 작업을 실행할 수 있다.

예를 들어 버튼을 눌렀을 때 시간이 오래 걸리는 작업이 실행되면 그 작업이 끝날 때까지 다음 작업을 진행하지 못한다.

### delay 함수

동기 방식으로 시간이 걸리는 작업을 연습하기 위해 `delay` 함수를 만들어 보았다.

    function delay() {
        // 시간이 오래 걸리는 작업
    }

동기 방식에서는 앞의 작업이 끝난 후 다음 작업이 실행된다.

실행 흐름:

`1번 작업 → delay() → 2번 작업 → 3번 작업`

---

## 2. 비동기 프로그래밍

비동기는 시간이 걸리는 작업을 기다리는 동안 다른 작업을 먼저 진행할 수 있는 방식이다.

대표적인 비동기 함수:

- `setTimeout()`
- `setInterval()`

### setTimeout()

`setTimeout`은 일정 시간이 지난 후 콜백 함수를 딱 한 번 실행한다.

쉽게 기억하기:

> `setTimeout` → "조금 이따가 딱 한 번 해줘"

예시:

    setTimeout(function() {
        console.log("3초 후 실행");
    }, 3000);

3초 후 한 번 실행된다.

### setInterval()

`setInterval`은 일정한 시간 간격마다 콜백 함수를 계속 반복해서 실행한다.

쉽게 기억하기:

> `setInterval` → "계속 반복해서 해줘"

예시:

    setInterval(function() {
        console.log("1초마다 실행");
    }, 1000);

1초마다 계속 실행된다.

### setTimeout과 setInterval 차이

| 함수 | 동작 |
|---|---|
| `setTimeout()` | 일정 시간이 지난 후 한 번 실행 |
| `setInterval()` | 일정 시간마다 계속 반복 실행 |

---

## 3. 이벤트 루프

비동기 함수가 실행될 때 자바스크립트는 이벤트 루프를 통해 비동기 작업을 처리한다.

중요한 개념:

- Call Stack
- Web API
- Callback
- Task Queue
- Event Loop

### 기본적인 동작 흐름

    JavaScript 코드
          ↓
    Call Stack
          ↓
    비동기 작업 발생
          ↓
    Web API
          ↓
    작업 완료
          ↓
    Callback
          ↓
    Task Queue
          ↓
    Event Loop
          ↓
    Call Stack이 비어 있는지 확인
          ↓
    Callback을 Call Stack으로 이동
          ↓
    실행

### 예시

    console.log("1");

    setTimeout(function() {
        console.log("2");
    }, 0);

    console.log("3");

결과:

    1
    3
    2

`setTimeout`의 시간이 0초라고 해도 콜백 함수가 바로 실행되는 것은 아니다.

비동기 작업으로 처리되고 콜백은 Task Queue에서 대기한다.

Event Loop가 Call Stack이 비어 있는 것을 확인하면 콜백을 Call Stack으로 보내 실행한다.

### 핵심

> 비동기 함수는 바로 실행되는 것이 아니라 적절한 시점에 실행될 수 있도록 대기한다.

# 4. 브라우저 제어

자바스크립트에서는 브라우저를 제어할 수 있다.

크게 다음 두 가지로 생각할 수 있다.

- DOM
- BOM

---

## 5. DOM

`DOM = Document Object Model`

DOM은 HTML 문서의 태그와 텍스트 등을 객체 모델로 만들어 자바스크립트에서 접근하고 조작할 수 있게 해준다.

예시:

    <h1 id="title">안녕하세요</h1>

    const $title = document.querySelector("#title");

    $title.textContent = "반갑습니다";

이처럼 자바스크립트로 HTML의 내용을 변경할 수 있다.

### 쉽게 기억하기

> DOM → HTML 문서를 제어

---

## 6. BOM

`BOM = Browser Object Model`

BOM은 브라우저 자체를 제어하기 위한 객체 모델이다.

예를 들어:

- 브라우저 창
- 주소
- 방문 기록
- 화면 정보
- 브라우저 정보

등을 다룰 수 있다.

### DOM과 BOM 차이

| 개념 | 의미 |
|---|---|
| DOM | HTML 문서를 제어 |
| BOM | 브라우저를 제어 |

---

## 7. 사용자와 대화하기

브라우저에서는 사용자와 대화할 수 있는 대화창을 사용할 수 있다.

### alert()

사용자에게 메시지를 보여준다.

    alert("안녕하세요!");

### confirm()

사용자에게 확인 여부를 물어본다.

    const result = confirm("삭제하시겠습니까?");

- 확인 → `true`
- 취소 → `false`

### prompt()

사용자에게 값을 입력받는다.

    const name = prompt("이름을 입력하세요.");

사용자가 입력한 값을 받을 수 있다.

---

## 8. 페이지 제어하기 - location

`location` 객체를 이용하면 현재 페이지의 주소와 관련된 정보를 확인하거나 페이지를 이동할 수 있다.

예시:

    location.href = "https://www.google.com";

다른 페이지로 이동할 수 있다.

### 쉽게 기억하기

> `location` → 현재 웹페이지의 주소와 이동을 관리

# ⭐ 여기까지 오늘 배운 앞부분 핵심

- 동기 → 앞의 작업이 끝나야 다음 작업 실행
- 비동기 → 기다리는 동안 다른 작업 실행 가능
- `setTimeout()` → 조금 이따가 한 번
- `setInterval()` → 일정 시간마다 반복
- Callback → 나중에 실행할 함수
- Web API → 브라우저가 비동기 작업을 처리하는 영역
- Task Queue → 실행할 콜백이 대기하는 곳
- Event Loop → Call Stack을 확인하고 콜백을 실행하도록 연결
- DOM → HTML 문서를 제어
- BOM → 브라우저를 제어
- `alert()` → 메시지 표시
- `confirm()` → 확인/취소
- `prompt()` → 사용자 입력
- `location` → 페이지 주소와 이동 제어

# 9. React

React는 사용자 인터페이스(UI)를 만들기 위한 JavaScript 라이브러리이다.

React에서는 화면을 여러 개의 컴포넌트로 나누어 만들 수 있다.

React에서 중요한 개념:

- `React.createElement()`
- 컴포넌트
- 함수형 컴포넌트
- JSX
- 컴포넌트 합성
- Props
- `ReactDOM.createRoot()`
- `render()`

---

## 10. React.createElement()

React에서는 JavaScript로 React 요소를 만들 수 있다.

    React.createElement(
        "태그명",
        { 속성객체 },
        "자식 내용"
    );

예시:

    React.createElement(
        "h1",
        { className: "title" },
        "안녕하세요"
    );

HTML로 생각하면 다음과 비슷하다.

    <h1 class="title">안녕하세요</h1>

구조:

    React.createElement(
        태그명,
        속성객체,
        자식 내용
    );

---

## 11. 컴포넌트란?

컴포넌트는 React에서 화면을 구성하는 하나의 독립적인 UI 단위이다.

쉽게 말하면:

> 화면을 여러 개의 부품으로 나누는 것

예시:

    App
     ├── Header
     ├── Profile
     ├── Content
     └── Footer

각각의 UI를 컴포넌트로 만들고 조합해서 하나의 화면을 만들 수 있다.

---

## 12. 함수형 컴포넌트

함수형 컴포넌트는 JavaScript 함수로 React 컴포넌트를 만드는 방식이다.

    function Hello() {
        return <h1>안녕하세요</h1>;
    }

사용할 때:

    <Hello />

처럼 사용할 수 있다.

즉:

    함수
     ↓
    컴포넌트
     ↓
    UI 표시

---

## 13. JSX

JSX는 JavaScript 안에서 HTML과 비슷한 문법으로 UI를 작성할 수 있게 해준다.

예시:

    function App() {
        return (
            <div>
                <h1>안녕하세요</h1>
                <p>React 공부 중입니다.</p>
            </div>
        );
    }

HTML처럼 보이지만 JSX는 JavaScript 안에서 사용하는 문법이다.

---

## 14. JSX의 `{}`

JSX의 `{}` 안에는 JavaScript 표현식을 넣을 수 있다.

예시:

    const name = "영동";

    function App() {
        return <h1>안녕하세요 {name}</h1>;
    }

결과:

    안녕하세요 영동

계산도 가능하다.

    const age = 29;

    function App() {
        return <p>{age + 1}살</p>;
    }

### 핵심

> JSX → `{}` 안에서 JavaScript 표현식 사용 가능

---

## 15. JSX와 HTML의 다른 규칙

JSX는 HTML과 비슷하지만 완전히 똑같지는 않다.

### class 대신 className

HTML:

    <div class="box"></div>

JSX:

    <div className="box"></div>

### 모든 태그는 반드시 닫아야 한다

    <div></div>

또는

    <img />

처럼 작성한다.

---

## 16. JSX 인라인 스타일

JSX에서 인라인 스타일은 객체 형태로 전달해야 한다.

예시:

    <div style={{ color: "red", fontSize: "20px" }}>
        안녕하세요
    </div>

스타일 객체:

    {
        color: "red",
        fontSize: "20px"
    }

JSX의 `{}` 안에 JavaScript 객체를 넣기 때문에

    style={{ color: "red" }}

처럼 중괄호가 두 개처럼 보인다.

---

## 17. 컴포넌트 합성

React에서는 컴포넌트 안에서 다른 컴포넌트를 사용할 수 있다.

예시:

    function Header() {
        return <header>Header</header>;
    }

    function Content() {
        return <main>Content</main>;
    }

    function App() {
        return (
            <div>
                <Header />
                <Content />
            </div>
        );
    }

작은 컴포넌트를 조합해서 하나의 큰 화면을 만들 수 있다.

이것을 컴포넌트 합성이라고 한다.

    작은 컴포넌트
         ↓
       조합
         ↓
    큰 컴포넌트
         ↓
      하나의 화면

# 18. Props

오늘 가장 이해하기 어려웠던 개념.

Props는 컴포넌트에 데이터를 전달하기 위한 방법이다.

처음에는 함수의 매개변수와 비슷하다고 생각하면 이해하기 쉽다.

---

## 일반 함수

    function hello(name) {
        console.log(name);
    }

    hello("영동");

여기서 `name`은 함수가 전달받는 값이다.

---

## React 컴포넌트

    function Hello(props) {
        return <h1>안녕하세요 {props.name}</h1>;
    }

    <Hello name="영동" />

여기서

    name="영동"

이라는 데이터를 컴포넌트에 전달하고

    props.name

으로 전달받는다.

---

## Props 쉽게 이해하기

    부모 컴포넌트
          ↓
        Props
          ↓
    자식 컴포넌트

즉, 부모가 자식에게 데이터를 전달하는 방법이다.

---

## Props 예시

    function App() {
        return <Hello name="영동" age={29} />;
    }

    function Hello(props) {
        return (
            <div>
                <h1>{props.name}</h1>
                <p>{props.age}살</p>
            </div>
        );
    }

App이 Hello에게

    name = "영동"
    age = 29

라는 데이터를 전달하는 것이다.

---

## Props는 함수와 비슷한가?

어느 정도 비슷하게 생각해도 된다.

일반 함수:

    function hello(name) {
        // name 사용
    }

    hello("영동");

React:

    function Hello(props) {
        // props 사용
    }

    <Hello name="영동" />

둘 다 외부에서 값을 전달받는다는 점에서 비슷하게 생각할 수 있다.

하지만 React에서는 부모 컴포넌트가 자식 컴포넌트에게 데이터를 전달하는 개념이다.

### Props 핵심

> Props = 컴포넌트 밖에서 컴포넌트 안으로 전달되는 데이터

    부모
     ↓
    데이터 전달
     ↓
    Props
     ↓
    자식

같은 컴포넌트라도 Props를 다르게 전달하면 다른 내용으로 표시할 수 있다.

예시:

    <User name="영동" />
    <User name="철수" />
    <User name="영희" />

하나의 `User` 컴포넌트를 여러 데이터에 재사용할 수 있다.

# 19. 시계 만들기

오늘 시계도 만들어 보았다.

시계는 시간이 계속 변경되기 때문에 `tick`을 실행하면서 현재 시간을 확인하고 화면을 다시 그리는 방식으로 만들 수 있다.

개념적인 흐름:

    시계 컴포넌트
         ↓
      tick 실행
         ↓
      현재 시간 확인
         ↓
      화면 다시 그리기
         ↓
      다시 tick 실행
         ↓
        반복

# 20. ReactDOM.createRoot()

React로 만든 UI를 실제 HTML 화면에 연결해야 한다.

이때 `ReactDOM.createRoot()`를 사용한다.

HTML:

    <div id="root"></div>

JavaScript:

    const root = ReactDOM.createRoot(
        document.getElementById("root")
    );

React가 관리할 HTML 영역을 지정하는 것이다.

---

# 21. render()

`render()`는 React에서 만든 컴포넌트나 요소를 실제 화면에 표시하는 역할을 한다.

예시:

    const root = ReactDOM.createRoot(
        document.getElementById("root")
    );

    root.render(<App />);

흐름:

    <App />
       ↓
    root.render()
       ↓
    HTML의 #root
       ↓
    화면에 App 표시

---

# 22. createRoot()와 render() 차이

### createRoot()

> React가 관리할 HTML 영역을 지정한다.

### render()

> 그 영역에 React 컴포넌트를 표시한다.

예시:

    const root = ReactDOM.createRoot(
        document.getElementById("root")
    );

    root.render(<App />);

---

# 23. 오늘 React 전체 흐름

    React
     ↓
    컴포넌트를 만든다
     ↓
    JSX로 UI를 작성한다
     ↓
    Props로 데이터를 전달한다
     ↓
    컴포넌트를 합성한다
     ↓
    ReactDOM.createRoot()로 React 영역을 만든다
     ↓
    render()로 화면에 표시한다

# 24. React 한 줄 요약

- `React.createElement()` → React 요소를 생성
- 컴포넌트 → 화면을 구성하는 UI 부품
- 함수형 컴포넌트 → JavaScript 함수로 만든 컴포넌트
- JSX → JavaScript 안에서 HTML과 비슷한 문법으로 UI 작성
- `{}` → JSX 안에서 JavaScript 표현식 사용
- 컴포넌트 합성 → 여러 컴포넌트를 조합해서 하나의 화면을 만드는 것
- Props → 부모 컴포넌트가 자식 컴포넌트에게 데이터를 전달하는 방법
- `ReactDOM.createRoot()` → React가 관리할 HTML 영역을 지정
- `render()` → React 컴포넌트를 실제 화면에 표시
