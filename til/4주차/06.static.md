## chap06 — section06: static

---

### 1. static 키워드

`static`은 객체마다 따로 생성되는 것이 아니라 **클래스에 소속되어 모든 객체가 공유하는 멤버**를 만드는 키워드.

- 인스턴스 변수: 객체마다 별도로 생성
- 클래스 변수(static): 모든 객체가 공유
- 클래스명으로 접근하는 것이 일반적

**핵심 문법**

    private int personalLockerCount;
    private static int sharedLockerCount;

    Student.sharedLockerCount++;  // 클래스명으로 접근 — 권장
    s1.sharedLockerCount++;       // 인스턴스로도 접근은 되지만 비권장

### 2. 인스턴스 변수 vs 클래스 변수

    Student s1 = new Student();
    Student s2 = new Student();

    s1.personalLockerCount++;       // s2에는 영향 없음
    Student.sharedLockerCount++;    // s1, s2 모두 같은 값 공유

**핵심:** 객체마다 다른 값은 인스턴스 변수, 모든 객체가 공유할 값은 static 변수.

### 3. static 메소드

`static` 메소드는 객체를 생성하지 않아도 클래스명으로 호출할 수 있음.

    public static void printCount() {
        System.out.println(sharedLockerCount);
    }

    Student.printCount();

**주의할 점**

- static 메소드는 객체 없이 호출되기 때문에, 어떤 객체의 인스턴스 변수를 참조해야 할지 알 수 없음.
  → 인스턴스 변수·인스턴스 메소드 직접 사용 불가
- 인스턴스 멤버를 써야 한다면 해당 객체를 매개변수로 받아서 접근해야 함.
- `this`는 현재 객체를 가리키는 키워드인데, static 메소드엔 객체가 없으므로 `this` 사용 불가.

### 4. static 초기화 블록

static 변수는 선언과 동시에 초기화하거나, static 초기화 블록에서 초기화할 수 있음.

    private static int count = 0;  // 선언과 동시에 초기화

    static {
        count = 10;  // static 초기화 블록
    }

**실행 시점:** 클래스가 처음 메모리에 로드될 때 딱 한 번만 실행됨 (생성자보다 먼저 실행).

**활용 예시 — final 배열 초기화**

    private static final Member[] members;

    static {
        members = new Member[10];   // OK — static 블록에서 최초 1회 초기화
    }

- `static`: 모든
