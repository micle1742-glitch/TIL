# PART 1. 값과 변수

## 1. 리터럴 (Literal)

리터럴은 코드에 직접 작성한 **값 자체**다. 변수에 담기 전의 값이라고 생각하면 된다.

| 종류 | 예시 | 표기 규칙 |
|---|---|---|
| 정수 | `123` | 그대로 |
| 실수 | `1.23` | 소수점 포함 |
| 문자 | `'a'` | 홑따옴표, **반드시 1글자** |
| 문자열 | `"abc"`, `""` | 쌍따옴표, 빈 문자열 가능 |
| 논리 | `true`, `false` | 소문자 |

### 주의

- `''` → ❌ 빈 문자는 존재하지 않는다 (컴파일 에러)
- `""` → ⭕ 빈 문자열은 가능하다
- `'A'`는 `char`, `"A"`는 `String` → 서로 다른 타입이다

### ➕ 보충: 리터럴 연산 결과 (암기)

| 식 | 결과 | 이유 |
|---|---|---|
| `123 / 10` | `12` | 정수끼리 나누면 소수점 버림 |
| `123 % 10` | `3` | 나머지 |
| `1 + 1.23` | `2.23` | 정수 + 실수 = **실수** |
| `'a' + 'b'` | `195` | 문자는 숫자(유니코드 값)로 계산: 97 + 98 |
| `'a' + '1'` | `146` | `'1'`은 숫자 1이 아니라 문자 코드 49 |
| `"a" + 'b'` | `"ab"` | 문자열이 끼면 이어 붙이기 |
| `"a" + 10` | `"a10"` | 문자열 + 숫자 = 문자열 |
| `"9" + 9` | `"99"` | 문자열이 먼저 나와서 바로 연결 |
| `9 + 9 + "9"` | `"189"` | 왼쪽부터: `9+9=18` 먼저, 그다음 `"18"+"9"` |

- `boolean`은 `+ - * /` 같은 산술 연산을 할 수 없다.
- 핵심: **`'a' + 'b'`는 `"ab"`가 아니다.** 문자끼리는 숫자 덧셈이 된다.

## 2. 변수와 자료형

변수는 **값을 저장해두는 공간**이다.

```java
int point;        // 선언: 자료형 변수명;
int point2 = 100; // 선언과 동시에 초기화
```

### 기본 자료형 8가지 (암기)

| 분류 | 자료형 | 크기 |
|---|---|---|
| 정수 | `byte` / `short` / `int` / `long` | 1 / 2 / 4 / 8 byte |
| 실수 | `float` / `double` | 4 / 8 byte |
| 문자 | `char` | 2 byte |
| 논리 | `boolean` | `true` / `false` |

- 문자열 `String`은 기본 자료형이 아니라 Java가 제공하는 **클래스(참조 자료형)** 다. 그래서 대문자 `S`로 시작한다.

### ➕ 보충: 기본 타입과 접미사

- 정수 리터럴의 기본 타입은 `int`, 실수 리터럴의 기본 타입은 `double`이다.
- 그래서 다른 타입으로 쓰려면 접미사를 붙인다.

```java
float f = 4.0f;           // f 없으면 double이라 에러
long big = 10000000000L;  // int 범위를 넘는 정수는 L 필수
```

### 변수 이름 규칙

**어기면 컴파일 에러**

| 규칙 | ❌ | ⭕ |
|---|---|---|
| 같은 범위에서 같은 이름 금지 | `int age` 두 번 선언 | |
| 예약어 사용 금지 | `int true`, `int for` | |
| 숫자로 시작 금지 | `int 1age` | `int age1` |
| 특수문자는 `_`, `$`만 | `int sh@rp` | `int sh$hp` |

- 대소문자를 구분한다 → `age`와 `Age`는 다른 변수
- `True`는 예약어 `true`가 아니라서 사용 가능하다 (쓰지는 말자)

**에러는 안 나지만 지키는 관례**

- 합성어는 **카멜 케이스** → `maxAge`, `userName` (`max_age`처럼 쓰지 않음)
- 이름에서 의미가 드러나게 → `s`보다 `name`
- 관례적인 이름은 그대로 → `sum`, `max`, `min`, `count`
- `boolean`은 질문형, 가급적 긍정형 → `isAlive`
- ➕ 한글 변수명(`int 나이;`)은 컴파일은 되지만 쓰지 않는다.

### ➕ 보충: 이름 표기법 한눈에

| 대상 | 표기법 | 예 |
|---|---|---|
| 변수, 메소드 | 카멜 케이스 | `maxAge`, `printAge()` |
| 상수 | 대문자 + `_` | `MAX_AGE` |
| 클래스 | 파스칼 케이스 (첫 글자 대문자) | `Calculator`, `Typecasting` |

> 수업 코드의 `typecasting` 클래스는 소문자로 시작했다. 관례상 `Typecasting`이 맞고, 파일명도 클래스명과 같아야 한다.

## 3. 상수 (Constant)

상수는 **한 번 값을 저장하면 변경할 수 없는 공간**이다. `final`을 붙인다.

```java
final int AGE;   // 선언만 먼저 해도 된다
AGE = 20;        // 최초 1번 대입 ⭕
// AGE = 30;     // 재대입 ❌ 컴파일 에러

int sum = AGE;   // 값을 읽어서 쓰는 것은 ⭕
```

### 주의: 중복 선언

```java
final int AGE;
int AGE = 20;    // ❌ AGE를 두 번 선언한 것
```

### ➕ 보충: 왜 쓰나

- 바뀌면 안 되는 값(기준 나이, 최대 인원 등)을 실수로 바꾸는 걸 **컴파일러가 막아준다.**
- 이름 관례: 전부 대문자, 단어 연결은 `_` → `MAX_AGE`, `PI_VALUE`

## 4. 오버플로우 (Overflow)

자료형이 저장할 수 있는 **범위를 넘어가면 값이 반대쪽 끝으로 넘어가는 현상**이다.

`byte` 범위: **-128 ~ 127**

```java
byte num = 127;
num++;            // ➕ 결과: -128 (최대 + 1 → 최소)

byte num2 = -128;
num2--;           // ➕ 결과: 127 (최소 - 1 → 최대)
```

> ➕ 참고: 수업에서는 최소 아래로 내려가는 것을 언더플로우라고 불렀다. 정확히는 정수에서는 두 경우 모두 오버플로우라고 하고, 언더플로우는 실수가 0에 너무 가까워 표현할 수 없게 되는 경우를 말하기도 한다.

### 가장 중요한 함정: 계산이 먼저, 저장은 나중

```java
int firstNum = 1000000;
int secondNum = 70000;

long longNum = firstNum * secondNum;        // ➕ 1280523264 (이미 int 계산에서 넘침)
long result = (long) firstNum * secondNum;  // ➕ 70000000000 (정답)
```

- `long` 변수에 담아도 해결되지 않는다. `firstNum * secondNum`이 **int끼리의 계산이라 int 범위에서 먼저 넘친다.**
- 계산 **전에** 하나를 `long`으로 바꾸면 계산 전체가 `long`으로 처리된다.

> **결과를 담는 변수의 자료형보다 계산에 참여하는 자료형이 중요하다.**

## 5. 형변환 (Type Casting)

서로 다른 자료형의 값을 변환하는 것.

### 자동 형변환 (작은 범위 → 큰 범위)

```java
byte b = 1;
short s = b;
int i = s;
long l = i;        // byte → short → int → long 전부 자동

long eight = 8;
float four = eight; // 정수 → 실수 자동 (출력: 8.0)
```

- 서로 다른 타입끼리 연산하면 **더 넓은 타입으로 맞춘 뒤** 계산한다.

```java
int n1 = 10;
long n2 = 10;
long r = n1 + n2;    // int + long → long
// int r2 = n1 + n2; // ❌ 결과가 long이라 int에 못 담음
```

### 강제 형변환 (큰 범위 → 작은 범위, 실수 → 정수)

문법: `(변환할자료형) 값`

```java
long num = 8;
int result = (int) num;   // 큰 → 작은

float f = 4.7f;
long n = (long) f;        // 실수 → 정수: 소수점 버림 → 4
```

- 값이 잘리거나 바뀔 수 있어서, 개발자가 **직접 책임지고 바꾼다**는 표시다.

### ➕ 보충: 자주 헷갈리는 부분

1. **`long`(8byte) → `float`(4byte)인데 왜 자동?**
   크기(byte)가 아니라 **표현할 수 있는 수의 범위** 기준이라서다. `float`이 `long`보다 범위가 넓다.

2. **`byte`, `short`끼리 계산하면 결과는 `int`**

   ```java
   byte b = 10;
   // b = b + 1;  // ❌ b + 1은 int
   b += 1;        // ⭕ 복합 대입은 자동으로 형변환해 준다
   ```

3. **수업 코드에서 결과가 4.0으로 나온 이유**

   ```java
   float lnum3 = (long) fnum2;  // long으로 바꿨다가 다시 float에 담음 → 4.0
   long lnum3 = (long) fnum2;   // 정수 결과를 보려면 변수도 long → 4
   ```

### 암기

- 작은 타입 → 큰 타입: **자동**
- 큰 타입 → 작은 타입, 실수 → 정수: **강제** `(자료형) 값`

## 6. 유니코드 표현

`\u` 뒤에 16진수 4자리를 쓰면 유니코드 문자를 표현할 수 있다.

```java
char a = '\u0041';                  // 'A'
char ga = '\uAC00';                 // '가'
String s = "\uAC00\uB098\uB2E4";    // "가나다"
```

### ➕ 보충: 문자와 숫자의 관계

- `char`는 내부적으로 **유니코드 숫자**를 저장한다. 그래서 `'A'`는 65이다.
- 이게 `'a' + 'b'`가 195가 되는 이유다.

```java
System.out.println('A' + 1);         // 66 (char + int → int)
System.out.println((char)('A' + 1)); // 'B' (다시 char로 바꾸면 문자)
```

### 암기

`\u` + 16진수 4자리

## 7. 산술 연산자

`+` `-` `*` `/` `%`

```java
10 / 3   // 3  (정수끼리 나누면 소수점 버림)
```

## 8. 복합 대입 연산자

기존 값에 연산한 뒤 다시 대입한다.

`+=` `-=` `*=` `/=` `%=`

```java
int num = 12;
num += 3;   // num = num + 3 → 15
```

- ➕ 단순히 줄여 쓰는 것만이 아니라, 자동으로 형변환까지 해 준다 (5번 형변환의 `b += 1` 참고).

## 9. 증감 연산자

| 표기 | 동작 | 기억법 |
|---|---|---|
| `num++` (후위) | 현재 값을 **사용한 후** 1 증가 | 사용 → 증가 |
| `++num` (전위) | **먼저 1 증가한 후** 사용 | 증가 → 사용 |

```java
int num = 10;
System.out.println(num++);  // 10 (출력 후 11이 됨)
System.out.println(num);    // 11

int num2 = 10;
System.out.println(++num2); // 11
```

### ➕ 보충: 수업 예제 계산

```java
int firstNum = 10;
int result = ++firstNum * 3;   // 11 * 3 = 33
// firstNum++ * 3 이었다면 10 * 3 = 30 (계산 후 firstNum은 11)
```

## 10. 비교 연산자

결과는 항상 `boolean`이다.

| 연산자 | 의미 | 예 | 결과 |
|---|---|---|---|
| `==` | 같다 | `10 == 20` | `false` |
| `!=` | 같지 않다 | `10 != 20` | `true` |
| `>` / `<` | 크다 / 작다 | `10 > 20` | `false` |
| `>=` / `<=` | 크거나 같다 / 작거나 같다 | `10 <= 20` | `true` |

- `boolean`끼리도 `==`, `!=`로 비교할 수 있다.

## 11. 문자열 비교

| 방법 | 비교하는 것 |
|---|---|
| `==` | 두 변수가 **같은 객체**를 가리키는지 |
| `equals()` | 문자열의 **내용**이 같은지 |

```java
String str1 = "java";
String str2 = "java";
str1.equals(str2)   // 내용 비교 ← 문자열은 항상 이걸 쓴다
```

### ➕ 보충: 수업에서 `==`도 true가 나온 이유

```java
String a = "java";
String b = "java";
String c = new String("java");

a == b        // true  (같은 리터럴은 자바가 객체 하나를 재사용)
a == c        // false (new로 만들면 새 객체)
a.equals(c)   // true  (내용은 같음)
```

- 결과가 경우에 따라 달라지니까, **문자열 내용 비교는 무조건 `equals()`**.

### Java와 JavaScript 차이

- Java에는 `===`가 없다.
- 타입이 정해져 있어서 `1 == "1"`처럼 느슨하게 비교하지 않는다. 타입이 안 맞으면 **컴파일 에러**다.

## 12. 논리 연산자

Java의 논리 연산에는 **`boolean` 값만** 쓸 수 있다. JS처럼 숫자·문자열을 truthy/falsy로 판단하지 않는다.

- **AND `&&`**: 둘 다 `true`여야 `true`
- **OR `||`**: 하나라도 `true`면 `true`
- **NOT `!`**: 결과를 반대로

```java
true && false   // false
true || false   // true
!false          // true

int num1 = 55;
num1 >= 1 && num1 <= 100   // ➕ 범위 검사: 1 이상 100 이하 → true
```

### 단락 평가 (Short-circuit)

- `&&`: 앞이 `false`면 뒤를 **실행하지 않는다**
- `||`: 앞이 `true`면 뒤를 **실행하지 않는다**

### ➕ 보충: 수업 예제

```java
int num2 = 10;
boolean result1 = false && ++num2 > 0;

System.out.println(result1);  // false
System.out.println(num2);     // 10 ← ++num2가 실행되지 않았다
```

> 연산 뒤쪽에 값을 바꾸는 코드가 있으면 실제로 실행됐는지 꼭 확인하자.

## 13. 삼항 연산자

조건에 따라 두 값 중 하나를 고른다.

```java
// (조건식) ? 참일 때 값 : 거짓일 때 값
String result = (num > 0) ? "양수다." : "양수가 아니다.";
```

- ➕ `if-else`를 한 줄로 줄인 형태다. **값을 고를 때** 쓴다.
- ➕ 수업의 `Calculator`도 삼항 연산자로 작은 값/큰 값을 골랐다: `(first < second) ? first : second`

# PART 3. 메소드와 패키지

## 14. 메소드 (Method)

메소드는 **특정 작업을 수행하기 위한 명령문의 집합**이다. 같은 작업을 필요할 때마다 호출해서 쓸 수 있다.

### ➕ 보충: 메소드 기본 구조

```java
public 반환타입 메소드명(자료형 매개변수, ...) {
    // 작업
    return 값;   // 반환타입이 void가 아니면 필수
}
```

### 객체를 통한 호출 (non-static)

```java
Application1 app1 = new Application1();  // 1. 객체 생성
app1.methodA();                          // 2. 메소드 호출
```

| 부분 | 의미 |
|---|---|
| `Application1` | 클래스 이름 |
| `app1` | 객체를 저장하는 변수 이름 |
| `methodA()` | 호출할 메소드 이름 |

---

## 15. 메소드 호출 흐름

메소드 안에서 다른 메소드를 호출할 수 있다. **들어간 순서의 반대로 끝난다.**

```
호출: main → methodA → methodB → methodC
종료: methodC → methodB → methodA → main
```

### ➕ 보충: 실제 출력 순서

```
main 호출됨
methodA() 호출함
methodB() 호출함
methodC() 호출함
methodC() 종료됨
methodB() 종료됨
methodA() 종료됨
main 종료됨
```

- 호출한 쪽은 호출된 메소드가 끝날 때까지 기다렸다가, 끝나면 **호출한 바로 다음 줄부터** 이어서 실행한다.

## 16. 전달인자 (Argument)와 매개변수 (Parameter)

| 용어 | 뜻 | 예 |
|---|---|---|
| 전달인자 (argument) | 호출할 때 **넘기는 값** | `printAge(5)`의 `5` |
| 매개변수 (parameter) | 값을 **받기 위해 선언한 변수** | `printAge(int age)`의 `age` |

```java
int myAge = 10;
app2.printAge(myAge);   // myAge의 값 10이 age에 전달된다
```

## 17. 여러 매개변수 전달

매개변수의 **개수, 순서, 타입**을 맞춰서 전달한다.

```java
public void printUserInfo(String name, int age, char gender) { ... }

app2.printUserInfo("판다", 3, '남');
// "판다" → name, 3 → age, '남' → gender
```

### 주의

```java
printUserInfo(name:"판다", age:3, gender:'남');  // ❌ Java에는 이름 붙여 넘기는 문법 없음
printUserInfo("판다", 3, '남');                  // ⭕ 순서대로
```

- ➕ 수업 코드의 출력은 `"이름:" + name + "나이 :" + age`처럼 공백이 없어서 `이름:판다나이 :3성별:남`으로 붙어 나온다. 문자열을 이어 붙일 때는 공백도 직접 넣어야 한다.

## 18. 반환값과 `void`

| 반환 타입 | 의미 |
|---|---|
| `void` | 반환값 없음. `return;` 생략 가능 |
| `String` | `String` 값을 반드시 `return` |
| `int` | `int` 값을 반드시 `return` |

```java
public void printAge(int age) {
    System.out.println("당신의 나이는 " + age + "세 입니다.");
}

public String createMessage() {
    return "hello world!!";
}

String message = app2.createMessage();   // 반환값을 변수에 저장
```

### ➕ 보충: 반환값 활용

```java
public String createString(String name, int age) {
    return name + "님의 나이는 " + age + "세 입니다.";
}
```

- 반환값은 변수에 저장하거나, 다른 메소드의 전달인자로 **바로** 넘길 수도 있다.

```java
System.out.println(app2.createMessage());
```

> 반환 타입과 `return`하는 값의 타입이 맞아야 한다.

## 19. static 메소드

`static` 메소드는 특정 객체가 아니라 **클래스에 속한다.** 그래서 객체 없이 클래스 이름으로 호출한다.

```java
public static int sumTwoNumbers(int first, int second) {
    return first + second;
}

Application3.sumTwoNumbers(10, 20);  // 클래스명.메소드명()
sumTwoNumbers(10, 20);               // 같은 클래스 안이면 클래스명 생략 가능
```

### non-static vs static

| 종류 | 호출 방법 |
|---|---|
| non-static | `Calculator calc = new Calculator();` → `calc.minNumberOf(10, 20);` |
| static | `Calculator.maxNumberOf(10, 20);` |

### ➕ 보충

- **다른 클래스**의 static 메소드는 클래스명을 **반드시** 적는다.
- `calc.maxNumberOf(3, 1)`처럼 객체로 static을 부르는 것도 되긴 하지만 **권장하지 않는다.** 객체와 상관없는 메소드라는 게 코드에서 안 보이기 때문이다.
- `main`도 `static`이다. 그래서 객체를 만들지 않아도 JVM이 바로 실행할 수 있다.

### 암기

- non-static → **객체 생성 → `객체.메소드()`**
- static → **`클래스명.메소드()`**

## 20. ➕ 패키지와 import

**패키지**는 클래스를 폴더처럼 묶는 이름 공간이다. 파일 맨 위에 `package` 선언을 쓴다.

```java
package com.ohgiraffers.section02.pakage_and_import;
```

다른 패키지의 클래스를 쓰는 방법은 세 가지다.

**1) 전체 이름 사용** — import 없이 가능하지만 길다

```java
com.ohgiraffers.section01.method.Calculator calc =
        new com.ohgiraffers.section01.method.Calculator();
```

**2) import 사용** — 클래스명만으로 쓸 수 있다

```java
import com.ohgiraffers.section01.method.Calculator;

Calculator calc = new Calculator();
int max = Calculator.maxNumberOf(30, 20);
```

**3) static import** — static 메소드를 클래스명 없이 쓴다

```java
import static com.ohgiraffers.section01.method.Calculator.maxNumberOf;

int max = maxNumberOf(30, 20);
```

### 자주 헷갈리는 부분

- `import`는 코드를 복사해 오는 게 아니라 **이름을 짧게 쓰게 해주는 것**이다.
- **같은 패키지**의 클래스는 import 없이 쓴다. (`Application4`가 `Calculator`를 import 없이 쓴 이유)
- static import는 편하지만 어느 클래스의 메소드인지 안 보이게 되니까 필요할 때만 쓴다.
- 패키지명 `pakage_and_import`는 오타지만 실행에는 문제없다. 예약어 `package` 자체는 이름으로 쓸 수 없다.

# 21. 오늘 자주 헷갈린 부분 모음

| 비교 | 정리 |
|---|---|
| `'A'` vs `"A"` | 문자 1개(`char`) vs 문자열(`String`). `''`는 ❌, `""`는 ⭕ |
| `'a' + 'b'` vs `"a" + "b"` | `195` vs `"ab"` |
| `==` vs `equals()` | 기본값·같은 객체 비교 vs **문자열 내용** 비교 |
| `++num` vs `num++` | 먼저 증가 vs 나중에 증가 |
| argument vs parameter | 넘기는 값 vs 받는 변수 |
| 클래스 이름 vs 객체 이름 | `Application1`(설계도) vs `app1`(만든 객체를 담은 변수) |
| `void` vs 반환 타입 | 반환 없음 vs 해당 타입 값을 반드시 반환 |
| static vs non-static | `클래스명.메소드()` vs `객체.메소드()` |
| 자동 vs 강제 형변환 | 작은→큰 자동 vs 큰→작은·실수→정수는 `(자료형)` |
| `long x = a * b` | int 계산이 먼저라 이미 넘친다 → `(long) a * b` |
| Java의 `===` | 없다 |

# 22. ➕ 셀프 체크 (OX)

1. `String`은 기본 자료형 8개 중 하나다.

5. 문자열 내용 비교는 `equals()`를 쓴다.
6. `false && (식)`에서 뒤의 식은 실행되지 않는다.

9. `long` → `float`은 강제 형변환이 필요하다.

# 오늘 배운 내용 전체 흐름

1. **값**: 코드에 직접 쓴 값이 리터럴이다.
2. **저장**: 값을 타입이 정해진 **변수**에 담는다. 바뀌면 안 되는 값은 `final` **상수**로 만든다.
3. **범위와 변환**: 타입마다 담을 수 있는 범위가 있어서 넘치면 **오버플로우**가 생기고, 타입이 다르면 **형변환**으로 맞춘다.
4. **계산과 판단**: 값을 **산술·대입·증감·비교·논리·삼항 연산자**로 계산하고 판단한다.
5. **작업 묶기**: 반복되는 작업은 **메소드**로 묶고, **전달인자 → 매개변수 → 반환값** 흐름으로 값을 주고받는다.
6. **호출 방식**: 메소드는 객체로 부르는 **non-static**과 클래스로 부르는 **static**으로 나뉜다.
7. **코드 정리**: 클래스는 **패키지**로 묶고, 다른 패키지의 클래스는 **import**로 가져와 쓴다.

> 한 줄 요약: **값 → 저장 → 계산 → 작업 묶기(메소드) → 코드 정리(패키지)** 순서로 프로그램의 단위가 커져 간 하루.
